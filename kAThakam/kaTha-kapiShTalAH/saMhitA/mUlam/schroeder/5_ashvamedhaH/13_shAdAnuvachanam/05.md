मित्रावरुणौ श्रोणिभ्यामिन्द्राग्री शिखण्डाभ्यामिन्द्राबृहस्पती ऊरुभ्यामिन्द्राविष्णू अष्ठीवद्भ्याँ सवितारं[^651_11] पुच्छेन गन्धर्वाञ्छेपेनाप्सरसो मुष्काभ्यां पवमानं पायुना पवित्रं पोत्राभ्यामाक्रमणँ स्थूराभ्यां प्रतिक्रमणं गृष्ठाभ्याम्[^651_12]॥५॥ cf. TS 5, 7, 15.

[^651_11]: So corr. Ch सवितानं; vgl. TS 5, 7, 15. (Thus emended; Ch reads सवितानं; cf. TS 5, 7, 15)

[^651_12]: So Ch; vgl. कु᳓ष्ठाभ्यां TS 5, 7, 15; MS 3, 15, 6. E.; VS 25, 6. (Thus Ch; cf. कु᳓ष्ठाभ्यां TS 5, 7, 15; MS 3, 15, 6. E.; VS 25, 6.)
