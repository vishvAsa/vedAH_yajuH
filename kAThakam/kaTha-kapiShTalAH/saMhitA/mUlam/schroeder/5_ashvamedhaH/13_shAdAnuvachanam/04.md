योक्त्रं गृध्राभिर्युगमानतेन चित्तं मन्याभिस्सङ्घोषात्प्राणैः[^651_7] प्रकाशेन त्वचं पराकाशेनान्तरां[^651_8] मशकान्केशैरिन्द्रँ[^651_9] स्वपसा वहेन[^651_10] बृहस्पतिँ शकुनिसादेन रथमुष्णिहाभिः॥४॥ cf TS 5, 7, 14

[^651_7]: So corr. Ch चित्तमान्याभिस्सङ्गोषान्प्रा॰ ; vgl. TS 5, 7, 14 चित्तम्म᳓न्याभिः सङ्क्रोशा᳓न् (Thus emended Ch चित्तमान्याभिस्सङ्गोषान्प्रा॰; cf. TS 5, 7, 14 चित्तम्म᳓न्याभिः सङ्क्रोशा᳓न्)

[^651_8]: So corr. Ch पाकाशे॰ ; vgl. TS 5, 7, 14 (Thus emended; Ch reads पाकाशे॰; cf. TS 5, 7, 14)

[^651_9]: So corr. Ch न्तरास्वशका॰ ; vgl. TS 5, 7, 24. (Thus emended; Ch reads न्तरास्वशका॰; cf. TS 5, 7, 24)

[^651_10]: So corr. Ch वहैन; vgl. TS 5, 7, 14 (Thus emended; Ch reads वहैन; cf. TS 5, 7, 14)
