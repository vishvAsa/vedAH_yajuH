पूष्णो वनिष्ठुरन्धाहेस्स्थूरगुदा[^652_1] सर्पान्गुदाभिर्ऋतून्पृष्टिभिर्दिवं[^652_2] पृष्ठेन वसूनां प्रथमा[^652_3] कीकसा रुद्राणां द्वितीयादित्यानां तृतीयाङ्गिरसां चतुर्थी साध्यानां पञ्चमी विश्वेषां देवानाँ षष्ठी॥७॥ cf. TS 5, 7, 17; MS 3, 15, 9; VS 25, 7.

[^652_1]: So corr. Ch न्ध्राहेस्थुरगुदा; vgl. TS 5, 7, 17; MS 3, 15, 9; VS 25, 7. (Thus emended; Ch reads न्ध्राहेस्थुरगुदा; cf. TS 5, 7, 17; MS 3, 15, 9; VS 25, 7)

[^652_2]: So corr. Ch भृष्टि॰ (Thus emended; Ch reads भृष्टि॰)

[^652_3]: So corr. Ch पूध्वमा (Thus emended; Ch reads पूध्वमा)
