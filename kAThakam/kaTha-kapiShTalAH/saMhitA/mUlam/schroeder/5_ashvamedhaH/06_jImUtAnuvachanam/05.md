**यत्ते गात्रादग्निना पच्यमानादभि शूलं निहतस्यावधावति।  
मा तद्भूम्यामाश्रिषन्मा तृणेषु देवेभ्यस्तदुराझो रातमस्तु॥**

**ये वाजिनं परिपश्यन्ति पक्वं य ईमाहूस्सुरभिर्निहेरेति।  
ये चार्वतो माँसिभिक्षामुपासत उतो तेषामभिगूर्तिर्न[^642_1] इन्वतु॥**

[^642_1]: So corr. Ch गूर्तित्र ; vgl. RV 1, 162, 12. (Thus emended; Ch reads गूर्तित्र; cf. RV 1, 162, 12)

**मा त्वाग्निर्ध्वनयेद्वमगन्धिर्मोखा[^642_2] भ्राजन्त्यभिविक्त जघ्रिः[^642_3]।  
इष्टं वीतमभिगूर्तं वषट्कृतं तं देवासः प्रतिगृभ्णन्त्यश्वम्॥**

[^642_2]: Ch र्ध्वनयेद्धूपग॰; erste Hand ध्वनाये; vgl. RV 1, 162, 15 ध्वनयोद्धू॰ ; ebenso VS 25, 37: in MS 3, 16, 1 a. E. schwanken die Mss.; TS 4, 6, 9 2 ध्वनयिद्धू॰ (Ch र्ध्वनयेद्धूपग॰; first hand ध्वनाये; cf. RV 1, 162, 15 ध्वनयोद्धू॰; likewise VS 25, 37: in MS 3, 16, 1 at the end the mss. fluctuate; TS 4, 6, 9 2 ध्वनयिद्धू॰)

[^642_3]: So corr. Ch जघृ ; vgl. RV 1, 162, 15; MS 3, 16, 1 a. E.; TS 4, 6, 9, 2. (Thus emended Ch जघृ; cf. RV 1, 162, 15; MS 3, 16, 1 at the end; TS 4, 6, 9, 2.)

**निक्रमणं निषदनं विवर्तनं यच्च पड्वीशमर्वतः[^642_4]।  
यच्च पपौ यच्च[^642_5] घासिं जघास सर्वा ता ते अपि देवेष्वस्तु॥**

[^642_4]: So corr. Ch यश्च पड्वोश॰ ; vgl. RV 1, 162, 14; MS 3, 16, 1; TS 4, 6, 9, 1; VS 25, 38. (Thus emended; Ch reads यश्च पड्वोश॰; cf. RV 1, 162, 14; MS 3, 16, 1; TS 4, 6, 9, 1; VS 25, 38)

[^642_5]: So corr. Ch यश्व पापी यश्च; vgl. RV 1, 162, 14; MS3, 16, 1; TS 4, 6, 9, 1; VS 25, 38. (Thus emended; Ch reads यश्व पापी यश्च; cf. RV 1, 162, 14; MS3, 16, 1; TS 4, 6, 9, 1; VS 25, 38)

**यत्ते सादे महसा शूकृतस्य पार्ष्ण्या वा कश्या वा[^642_6] तुतोद \।  
सुचेव ता हविषो अध्वरेषु सर्वा ता ते ब्रह्मणा सूदयामि॥**

[^642_6]: Dies a fehlt in Ch und ist von mir ergänzt; vgl. RV 1, 162, 17; TS 4, 6, 9, 3; VS 25, 40. (This a missing in Ch and is supplied by me; cf. RV 1, 162, 17; TS 4, 6, 9, 3; VS 25, 40.)

**यदश्वाय वास उपस्तृणन्त्यधीवासं या हिरण्यान्यस्मै।  
सन्दानमर्वन्तं पड्वीशं प्रिया देवेष्वायामयन्ति॥**

**चतुस्त्रिँशद्वाजिनो देवबन्धोर्वङ्गीरश्वस्य स्वधितिस्तमेति।  
अच्छिद्रा[^642_7] गात्रा वयुना कृणोत परुष्परुरनुघुष्या[^642_8] विशस्त॥**

[^642_7]: So corr. Ch अक्छिद्र; vgl. RV 1, 162, 18;TS 4, 6, 9, 3; VS 25, 41. (Thus emended; Ch reads अक्छिद्र; cf. RV 1, 162, 18;TS 4, 6, 9, 3; VS 25, 41)

[^642_8]: So corr. Ch रुरन्न॰ ; vgl. RV 1, 162, 18; TS 4, 6, 9, 3; VS 25, 41. (Thus emended; Ch reads रुरन्न॰; cf. RV 1, 162, 18; TS 4, 6, 9, 3; VS 25, 41)

**एकस्त्वष्टुरश्वस्य[^642_9] विशस्ता वा यन्तारा[^642_10] भवतस्तथर्तुः।  
या ते गात्राणामृतुथा कृणोमि ता ता[^642_11] पिण्डानां प्रजुहोम्यग्नौ॥**

[^642_9]: RV 162, 19 und die andern Texte रंश्वस्या (RV 162, 19 and the other texts read रंश्वस्या)

[^642_10]: So corr. Ch युन्तारा; vgl. RV 1, 162, 19 u. s. w. (Thus emended; Ch reads युन्तारा; cf. RV 1, 162, 19, etc.)

[^642_11]: So corr. Ch त्राता ; vgl. RV 1, 162, 19 u. s. w. (Thus emended; Ch reads त्राता; cf. RV 1, 162, 19, etc.)

**मा त्वा तपत्प्रिय आत्मापियन्तं मा[^642_12] स्वधितिस्तन्व अतिष्ठिपत्ते।  
मा ते गृध्नुरविशस्तातिहाय च्छिद्रा गात्राण्यसिना मिथू कः॥**

[^642_12]: So. corr. Ch सा ; vgl. RV 1, 162, 20. (Thus emended; Ch सा; cf. RV 1, 162, 20.)

**न वा उ एतन्म्रियसे[^642_13] न रिष्यसि देवाँ इदेषि पथिभिस्सुगेभिः।**

[^642_13]: So corr. Ch उँ एतत्प्रियसे; vgl. RV 1, 162, 21; MS 1, 2, 15; TS 4, 6, 9, 4; VS 25, 44. (Thus emended; Ch reads उँ एतत्प्रियसे; cf. RV 1, 162, 21; MS 1, 2, 15; TS 4, 6, 9, 4; VS 25, 44)

**हरी ते युञ्जा पृषती अभूतामुपास्याद्वाजी धुरि रासभस्य॥  
सुगव्यं[^643_1] नो वाजी स्वश्व्यं पुँसः पुत्राँ उत विश्वपुषं रयिम्।**

[^643_1]: So corr. Ch स्वगव्यन्नो; vgl. RV 1, 162, 22; TS 4, 6, 9, 1; VS 25, 45. (Thus emended; Ch reads स्वगव्यन्नो; cf. RV 1, 162, 22; TS 4, 6, 9, 1; VS 25, 45)

**अनागास्त्वं[^643_2] नो अदितिः कृणोतु क्षत्रं नो अश्वो वनते[^643_3] हविष्मान्॥ ॥५॥**  
cf. RV 1, 162, 11 – 22; MS 3, 16, 1; TS 4, 6, 8, 4, 4, 6, 9, 1 fig. ; VS 25, 34. 35. 37-45.
