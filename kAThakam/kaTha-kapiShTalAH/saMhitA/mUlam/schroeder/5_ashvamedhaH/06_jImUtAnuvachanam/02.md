**समिद्वो अञ्जन्कृदरं[^638_3] मतीनां घृतमग्रे मधुमत्पिन्वमानः।  
वाजी वहन्वाजिनं जातवेदो देवानां वक्षि प्रियमा सधस्थम्॥**

[^638_3]: Ch कदर

**घृतेनाञ्जन्सं पथो देवयानान्प्रजानन्वाज्यप्येतु[^638_4] देवान्।  
अनु त्वा सप्ते प्रदिशस्मचन्ताँ स्वधामस्मै यजमानाय धेहि॥**

[^638_4]: So corr. Ch वाजप्येतु; vgl. MS 3, 16, 2; TS 5, 1, 11, 1; VS 29, 2 (Thus emended; Ch reads वाजप्येतु; cf. MS 3, 16, 2; TS 5, 1, 11, 1; VS 29, 2)

**ईझश्चासि[^638_5] वन्द्यश्च वाजिन्नाशुश्चासि मेध्यश्च सप्ते।  
अग्निष्ट्वा देवैर्वसुभिस्सजोषाः प्रीतं वह्निं वहतु जातवेदाः॥**

[^638_5]: So corr. Ch श्चास्मि ; vgl. MS 3, 16, 2; TS 5, 1, 11, 1; VS 29, 3. (Thus emended; Ch reads श्चास्मि; cf. MS 3, 16, 2; TS 5, 1, 11, 1; VS 29, 3)

**स्तीर्णं बर्हिस्सुष्टरीमा जुषाणोरु पृथु[^638_6] प्रथमानं पृथिव्याम्।  
देवेभिरक्तमदितिस्सजोषास्स्योनं कृण्वाना[^638_7] सुविते दधातु[^638_8]॥**

[^638_6]: So corr. Ch पृथुम्प्र॰; vgl. MS3, 16, 2; TS 5, 1, 11, 2; VS 29, 4. (Thus emended; Ch reads पृथुम्प्र॰; cf. MS3, 16, 2; TS 5, 1, 11, 2; VS 29, 4)

[^638_7]: So corr. Ch कृण्वान (Thus emended; Ch reads कृण्वान)

[^638_8]: So corr. Ch दधात (Thus emended; Ch reads दधात)

**एता उ[^638_9] वस्तुभगा विश्ववारा वि पक्षोभिश्श्रयमाणा[^638_10] उदातैः।**

[^638_9]: So corr. Ch एवा तवस्सु॰ ; vgl. MS 3, 16, 2; TS 5, 1, 11, 2; VS 29, 5. (Thus emended; Ch reads एवा तवस्सु॰; cf. MS 3, 16, 2; TS 5, 1, 11, 2; VS 29, 5)

[^638_10]: So corr. Ch श्रियमाणा (Thus emended; Ch reads श्रियमाणा)

**ऋष्वास्सतीः कवयश्शुम्भमाना[^639_1] द्वारो देवीस्सुप्रयाणा[^639_2] भवन्तु॥**

[^639_1]: So Ch; vgl. v. l. in TS 5, 1, 11, 2 neben कव᳓षः, was auch MS 3, 16, 2; VS 29, 5. (Thus Ch; cf. variant reading in TS 5, 1, 11, 2 alongside कव᳓षः, which is also in MS 3, 16, 2; VS 29, 5.)

[^639_2]: So Ch; dagegen सुप्रायणा᳓ in MS 3, 16, 2; TS 5, 1, 11, 2; VS 29, 5. (Thus Ch; sincegegen सुप्रायणा᳓ in MS 3, 16, 2; TS 5, 1, 11, 2; VS 29, 5.)

**अन्तरा मित्रावरुणा चरन्ती मुखं यज्ञानामभिसंविदाने।  
उषासा वाँ सुहिरण्ये सुशिल्पे ऋतस्य योना इह सादयामि[^639_3]॥**

[^639_3]: So corr. mit Caland; Ch साधयामि; dagegen सादयामि in MS 3, 16, 2; TS 5, 1, 11, 3; VS 29, 6. (Thus emended with Caland; Ch reads साधयामि; on the other hand, सादयामि in MS 3, 16, 2; TS 5, 1, 11, 3; VS 29, 6.)

**प्रथमा वाँ सरथिना सुवर्णा देवौ पश्यन्तौ भुवनानि विश्वा।  
अपिप्रयं चोदना वां[^639_4] मिमाना होतारा ज्योतिः प्रदिशा दिशन्ता॥**

[^639_4]: So corr. Ch चोदनानाम्मि॰ ; vgl. MS 3, 16, 2; TS 5, 1, 11, 3; VS 29, 7. (Thus emended; Ch reads चोदनानाम्मि॰; cf. MS 3, 16, 2; TS 5, 1, 11, 3; VS 29, 7)

**आदित्यैर्नो भारती वष्टु यज्ञँ सरस्वती सह[^639_5] रुद्रैर्न आवीत्।  
इडोपहूता वसुभिस्सजोषा यज्ञं नो देवीरमृतेषु धत्त॥**

[^639_5]: So corr. Ch मह; vgl. MS 3, 16, 2; TS 5, 1, 11, 3; VS 29, 8. (Thus emended; Ch reads मह; cf. MS 3, 16, 2; TS 5, 1, 11, 3; VS 29, 8)

**त्वष्टा वीरं देवकामं जजान त्वष्टुरर्वा जायत आशुरश्वः।  
त्वष्टेदं विश्वं भुवनं जजान बहोः कर्तारमिह यक्षि होतः॥**

**अश्वो घृतेन त्मन्या समक्त उप देवाँ ऋतुशः पाथ एतु।  
वनस्पतिर्देवलोकं[^639_6] प्रजानन्नग्निना हव्या स्वदितानि वक्षत्॥**

[^639_6]: So corr. Ch लोकः ; vgl. MS 3, 16, 2; TS 5, 1, 11, 4; VS 29, 10. (Thus emended; Ch reads लोकः; cf. MS 3, 16, 2; TS 5, 1, 11, 4; VS 29, 10)

**प्रजापतेस्तपसा वावृधानस्सद्यो जातो ममिषे[^639_7] यज्ञमग्ने।  
स्वाहाकृतेन हविषा पुरोगा याहि सख्या[^639_8] हविरदन्तु देवाः॥ ॥२॥**  
cf. MS 3, 16, 2; TS 5, 1, 11; VS 29, 1–11.

[^639_8]: So Ch; dagegen साध्या MS 3, 16, 2; TS 5, 1, 11, 4; VS 29, 11. (Thus Ch; on the other hand साध्या MS 3, 16, 2; TS 5, 1, 11, 4; VS 29, 11.)
