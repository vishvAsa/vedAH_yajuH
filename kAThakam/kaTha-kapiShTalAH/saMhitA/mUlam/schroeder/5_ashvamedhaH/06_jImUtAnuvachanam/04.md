**मा नो मित्रो वरुणो अर्यमायुरिन्द्र ऋभुक्षा मरुतः परिख्यन्।  
यद्वाजिनो देवजातस्य सप्तेः प्रवक्ष्यामो विदथे वार्याणि॥**

**यन्निर्णिजा रेक्णसा प्रावृतस्य रातिं गृभीतां मुखतो नयन्ति।  
सुप्राङजो मेम्यद्विश्वरूप[^640_8] इन्द्रापूष्णोः प्रियमप्येतु[^640_9] पाथः॥**

[^640_8]: So corr. Ch मेस्य॰ ; vgl. RV 1, 162, 2; MS 3, 16, 1; TS 4, 6, 8, 1; VS 25, 25. (Thus emended; Ch reads मेस्य॰; cf. RV 1, 162, 2; MS 3, 16, 1; TS 4, 6, 8, 1; VS 25, 25)

[^640_9]: So auch MS 3, 16, 1; in RV 1, 162, 2 प्येति; desgl. TS 4, 6, 81; VS 25, 25. (Thus also MS 3, 16, 1; in RV 1, 162, 2 प्येति; likewise TS 4, 6, 81; VS 25, 25.)

**एष च्छागः[^640_10] पुरो अश्वेन वाजिना पूष्णो भागो नीयते विश्वदेवः[^640_11]।  
अभिप्रियं यत्पुरोडाशमर्वता त्वष्टेदेनँ सौश्रवसाय जिन्वति॥**

[^640_10]: Ch च्छागः

[^640_11]: So Ch; wohl in विश्वदेव्यः zu corr. mit RV 1, 162, 3; MS 3, 16, 1; TS 4, 6, 8, 1; VS 25, 26. (Thus Ch; probably to be emended to विश्वदेव्यः with RV 1, 162, 3; MS 3, 16, 1; TS 4, 6, 8, 1; VS 25, 26.)

**यद्वविष्यमृतुशो देवयानं त्रिर्मानुषाः पर्यश्वं नयन्ति।  
तत्रा पूष्णः प्रथमो भाग एति यज्ञं देवेभ्यः[^641_1] परिवेदयन्नजः॥**

[^641_1]: So corr. Ch देवेश्यः vgl. RV 1, 162, 4 u. s. w. (Thus emended Ch देवेश्यः cf. RV 1, 162, 4 etc.)

**होताध्वर्युरावया[^641_2] अग्निमिन्धो[^641_3] ग्रावग्राभ उत शँस्ता सुविप्रः।  
तेन यज्ञेन स्वरङ्कृतेन स्विष्टेन वक्षणा आपृणध्वम्॥**

[^641_2]: So corr. Ch रवया; vgl. RV 1, 162, 5; MS 3, 16, 1; TS 4, 6, 8, 2; VS 25, 28. (Thus emended; Ch reads रवया; cf. RV 1, 162, 5; MS 3, 16, 1; TS 4, 6, 8, 2; VS 25, 28)

[^641_3]: So corr. Ch मिन्दो; vgl. RV 1, 162, 5 u. s. w. (Thus emended; Ch reads मिन्दो; cf. RV 1, 162, 5, etc.)

**यूपव्रस्का उत ये यूपवाहाश्चषालं ये अश्वयूपाय तक्षति।  
ये चार्वते पचनँ सम्भरन्त्युतो तेषामभिगूर्तिर्न[^641_4] इन्वतु॥**

[^641_4]: So corr. Ch र्तिन्न; vgl. RV 1, 162, 6; MS 3, 16, 1; TS 4, 6, 8, 2; VS 25, 29. (Thus emended; Ch reads र्तिन्न; cf. RV 1, 162, 6; MS 3, 16, 1; TS 4, 6, 8, 2; VS 25, 29)

**उप प्रागात्सुमन्मेऽधायि मन्म देवानामाशा उप वीतपृष्ठः।  
अन्वेनं विप्रा ऋषयो मदन्तु[^641_5] देवानां पुष्टे चकृमा सुबन्धुम्॥**

[^641_5]: So Ch; vgl. dagegen मदन्ति in RV 1, 162, 7; MS 3, 16, 1; TS 4, 6, 8, 3; VS 29, 30. (Thus Ch; cf. on the other hand मदन्ति in RV 1, 162, 7; MS 3, 16, 1; TS 4, 6, 8, 3; VS 29, 30.)

**यद्वाजिनो दाम सन्दानमर्वतो या शीर्षण्या रशना रज्जुरस्य।  
यद्वा घास्य प्रभृतमास्ये तृणँ सर्वा ता ते अपि देवेष्वस्तु॥**

**यदश्वस्य क्रविषो मक्षिकाश यद्वा स्वरौ स्वधितौ रिप्तमस्ति।  
यद्वस्तयोश्शमितुर्यन्नखेषु[^641_6] सर्वा ता ते अपि देवेष्वस्तु॥**

[^641_6]: So corr. Ch शमितर्य॰ ; vgl. RV 1, 162, 9 u. s. w. (Thus emended; Ch reads शमितर्य॰; cf. RV 1, 162, 9, etc.)

**यदूवध्यमुदरस्यापवाति[^641_7] य आमस्य क्रविषो गन्धो अस्ति।  
सुकृता तच्छमितारः कृण्वन्तूत[^641_8] मेधँ शृतपाकं पचन्तु॥**

[^641_7]: So corr. Ch यदूवस्तमुद॰; vgl. RV 1, 162, 10; TS 4, 6, 8, 4; VS 25, 33. (Thus emended; Ch reads यदूवस्तमुद॰; cf. RV 1, 162, 10; TS 4, 6, 8, 4; VS 25, 33)

[^641_8]: So corr. Ch तछमितारं कण्वन्तुत; vgl. RV 1, 162, 10; TS 4, 6, 8, 4; VS 25, 33. (Thus emended; Ch reads तछमितारं कण्वन्तुत; cf. RV 1, 162, 10; TS 4, 6, 8, 4; VS 25, 33)

**यन्नीक्षणं माँस्पचन्या[^641_9] उखाया या पात्राणि यूष्ण आसेचनानि।  
ऊष्मण्यापिधाना चरूणामङ्कास्मनाः परिभूषन्त्यश्वम्॥ ॥४॥**  
cf. RV 1, 162, 1-10. 13; MS 3, 16, 1; TS 4, 6, 8. 9; VS 25, 24-33. 36.

[^641_9]: So corr. Ch माँपच॰ ; vgl. RV 1, 162, 13; MS 3, 16, 1; TS 4, 6, 9, 1; VS 25, 36. (Thus emended; Ch reads माँपच॰; cf. RV 1, 162, 13; MS 3, 16, 1; TS 4, 6, 9, 1; VS 25, 36)
