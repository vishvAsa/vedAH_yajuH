सोमाय स्वराजेऽनोवाहा अनड्वाहा इन्द्राग्निभ्यामोजोदाभ्यामोष्टारा इन्द्राग्निभ्यां बलदाभ्याँ सीरवाहा अवी द्वे धेनू भौमी दिग्भ्यो वडवे द्वे धेनू भौमी वैराजे[^647_5] पुरुषी द्वे धेनू भौमी वायव आरोहण्वाहा अनड्वाहौ[^647_5] वारुणी[^647_6] कृष्णे वशे आराड्यौ[^647_7] दिव्या ऋषभौ परिमरौ[^647_8]॥१॥ cf. TS 5, 6, 21.

[^647_5]: So corr. Ch अनु॰ (Thus emended; Ch reads अनु॰)

[^647_6]: So corr. Ch वारुणे ; vgl. TS 5, 6, 21. (Thus emended; Ch reads वारुणे; cf. TS 5, 6, 21)

[^647_7]: So corr. Ch अरात्र्यो; vgl. TS 5, 6, 21. (Thus emended; Ch reads अरात्र्यो; cf. TS 5, 6, 21)

[^647_8]: So corr. Ch परिपरी ; vgl. TS 5, 6, 21. (Thus emended; Ch reads परिपरी; cf. TS 5, 6, 21)
