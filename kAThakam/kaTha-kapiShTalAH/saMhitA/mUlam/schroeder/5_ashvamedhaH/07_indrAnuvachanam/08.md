शका भौमी पाङ्क्तः[^644_15] कशो मन्थीलवस्ते पितॄणामृतूनां जहका संवत्सराय लोपा कपोत उलूकश्शशस्ते[^644_16] नैर्ऋताः[^644_17] कृकवाकुस्सावित्रः॥८॥    
cf. TS 5, 5, 18; MS 3, 14, 19; VS 24, 26. 38.

[^644_15]: So corr. Ch पान्त्र; vgl. TS 5, 5, 18; MS 3, 14, 7; VS 24, 26; in mehreren Mss. der TS पान्त्र vol. (Thus emended; Ch reads पान्त्र; cf. TS 5, 5, 18; MS 3, 14, 7; VS 24, 26; in several mss. of the TS पान्त्र vol.)

[^644_16]: So corr. Ch उलूकश्शस्ते (Thus emended; Ch reads उलूकश्शस्ते)

[^644_17]: So corr. Ch नैनृताः (Thus emended; Ch reads नैनृताः)
