सौरी बलाकर्श्यो[^644_10] मयूरश्श्येनस्ते गन्धर्वाणां वसूनां कपिञ्जलो रुद्राणां तित्तिरी रोहित्कुण्डृणाची[^644_11] गोलत्तिका ता अप्सरसामरण्याय॥६॥    
cf. TS 5, 5, 16; MS 3, 14, 18; VS 24, 37.

[^644_10]: So corr. Ch बिलाकार्श्यो; vgl. TS 5, 5, 16. (Thus emended; Ch reads बिलाकार्श्यो; cf. TS 5, 5, 16)

[^644_11]: So corr. Ch कुनृणाचा; vgl. TS 5, 5, 16; MS 5, 14, 18; VS 24, 37. (Thus emended; Ch reads कुनृणाचा; cf. TS 5, 5, 16; MS 5, 14, 18; VS 24, 37)
