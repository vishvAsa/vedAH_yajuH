बलायाजगर आखुस्सृजया श्याण्डकस्ते[^644_3] मैत्रा[^644_4] मृत्यवेऽसितो मन्यवे स्वजः[^644_5] कौम्भीनसः पुष्करसादो लोहिताहिस्ते त्वाष्ट्राः[^644_6] प्रतिश्रुत्कायै वाहसः॥४॥ cf TS 5, 5, 14; MS 3, 14, 14; VS 24, 33.

[^644_3]: So corr. Ch शयाण्डकास्ते (Thus emended; Ch reads शयाण्डकास्ते)

[^644_4]: So corr. Ch मैत्र्या (Thus emended; Ch reads मैत्र्या)

[^644_5]: So corr. Ch स्रजः ; vgl. TS 5, 5, 14 स्वजः᳓ (Thus emended Ch स्रजः; cf. TS 5, 5, 14 स्वजः᳓)

[^644_6]: So corr. Ch त्वाष्ट्रः (Thus emended; Ch reads त्वाष्ट्रः)
