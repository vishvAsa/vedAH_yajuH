इन्द्राय राज्ञे सूकरो वरुणाय राज्ञे कृष्णो यमाय राज्ञ[^643_5] ऋश्य ऋषभाय राज्ञे गवयश्शार्दूलाय राज्ञे गौरः पुरुषराजाय मर्कटः क्षिप्रश्येनस्य[^643_6] वर्तिका नीलङ्गोः[^643_7] कृमिस्सोमाय राज्ञे कुलुङ्गस्सिन्धोश्शिशूमारो[^643_8] हिमवतो हस्ती॥१॥     
cf. TS 5, 5, 11; MS 3, 14, 11; VS 24, 30.

[^643_5]: So corr. Ch राज्ञे ; vgl. TS 5, 5, 11. (Thus emended; Ch reads राज्ञे; cf. TS 5, 5, 11)

[^643_6]: So corr. Ch क्षिप्रः श्येनस्य (Thus emended; Ch reads क्षिप्रः श्येनस्य)

[^643_7]: So corr. Ch नीलङ्गो (Thus emended; Ch reads नीलङ्गो)

[^643_8]: So Ch für शिशुमारो (Thus Ch for शिशुमारो)
