विभुर्मात्रा प्रभुः पित्राश्वो[^616_1]ऽसि हयोऽसि मयोऽस्यत्योऽसि नरोऽस्यर्वासि सप्तिरसि वाज्यसि वृषासि नृमणा[^616_2] असि ययुर्नामास्यादित्यानां पत्वान्वेह्यग्नये स्वाहा स्वाहेन्द्राग्निभ्याँ स्वाहा विश्वेभ्यो देवेभ्यस्स्वाहा प्रजापतये स्वाहा सर्वाभ्यो देवताभ्य इह धृतिस्स्वाहेह विधृतिस्स्वाहेह रन्तिस्स्वाहेह रमतिस्स्वाहा भूरसि भुवे त्वा भव्याय त्वा भविष्यते त्वा विश्वेभ्यस्त्वा भूतेभ्यो देवा आशापाला एतं देवेभ्योऽश्वं मेधाय प्रोक्षितं गोपायत॥३॥  
cf. MS 3, 12, 4; TS 7, 1, 12, 1; VS 22, 19.

[^616_1]: So corr. Ch पित्रासो; vgl. MS 3, 12, 4; 7, 1, 12, 1; VS 22, 19 = Corr. (Thus emended; Ch reads पित्रासो; cf. MS 3, 12, 4; 7, 1, 12, 1; VS 22, 19, which agrees with the emendation)

[^616_2]: So corr. Ch नृपणा (Thus emended; Ch reads नृपणा)
