पृथिव्यै स्वाहान्तरिक्षाय स्वाहा दिवे स्वाहा सम्प्लोष्यते[^630_4] स्वाहा सम्प्रवमानाय स्वाहा सम्प्लुताय स्वाहा मेघायिष्यते स्वाहा मेघायते स्वाहा मेघायिताय स्वाहा मेघिताय स्वाहा मेघाय स्वाहा नीहाराय स्वाहा निहाकायै स्वाहा प्रासचाय स्वाहा प्रचलाकायै[^630_5] स्वाहा विद्योतिष्यते स्वाहा विद्योतमानाय स्वाहा संविद्योतमानाय स्वाहा स्तनयिष्यते स्वाहा स्तनयते स्वाहोग्नँ[^631_1] स्तनयते स्वाहा वर्षियते स्वाहा वर्षिष्यते स्वाहा वर्षते स्वाहाभिवर्षते स्वाहा परिवर्षते स्वाहा संवर्षते स्वाहानुवर्षते स्वाहा प्रोषिष्यते स्वाहा पुष्णते स्वाहा परिप्रुष्णते स्वाहा शीकायिष्यते स्वाहा शीकायते स्वाहा शीतिकाय स्वाहोद्ग्रहीष्यते स्वाहोद्गृह्णते स्वाहोद्गृहीताय स्वाहा विप्लोष्यते स्वाहा विप्लवमानाय स्वाहा विप्लुताय स्वाहातप्स्यते स्वाहातपते स्वाहोग्रमातपते[^631_2] स्वाहर्ग्भ्यस्स्वाहा[^631_3] यजुर्भ्यस्स्वाहा सामभ्यस्स्वाहाङ्गिरोभ्यस्स्वाहा वेदेभ्यस्स्वाहा गाथाभ्यस्स्वाहा नाराशँसीभ्यस्स्वाहा रैभीभ्यस्स्वाहा सर्वस्मै स्वाहा॥२॥ cf. TS 7, 5, 11.

[^630_4]: So corr. Ch सम्प्लोषते; vgl. TS 7, 5, 11, 1 = Corr. (Thus emended; Ch reads सम्प्लोषते; cf. TS 7, 5, 11, 1, which agrees with the emendation)

[^630_5]: So corr. Ch प्रचलोकायै; vgl. TS 7, 5, 11, 1. (Thus emended; Ch reads प्रचलोकायै; cf. TS 7, 5, 11, 1)

[^631_1]: So corr. Ch स्वाहोग्राँ; vgl. TS 7, 5, 11, 1. (Thus emended; Ch reads स्वाहोग्राँ; cf. TS 7, 5, 11, 1)

[^631_2]: So corr. Ch स्वाहा उप्स्यते स्वाहा उपते स्वाहोग्रमा उपते; vgl. TS 7, 5, 11, 2 = Corr. (Thus emended; Ch reads स्वाहा उप्स्यते स्वाहा उपते स्वाहोग्रमा उपते; cf. TS 7, 5, 11, 2, which agrees with the emendation)
