कस्त्वा युनक्ति स त्वा युनक्तु विष्णुस्त्वा युनक्त्वस्य यज्ञस्यद्व्यै मह्यँ सन्नत्या अमुष्मै कामायायुषे त्वा प्राणाय त्वा व्यानाय त्वापानाय त्वा व्युष्ट्यै त्वा रय्यै त्वा राधसे त्वा पोषाय त्वा घोषाय त्वाराद्घोषाय त्वा प्रच्युत्यै[^632_11] त्वा कस्त्वा विमुञ्चति स त्वा विमुञ्चतु विष्णुस्त्वा विमुञ्चत्वस्य यज्ञस्यद्व्यै[^632_12] मह्यँ सन्नत्या अमुष्मै कामायायुषे त्वा प्राणाय त्वा व्यानाय त्वापानाय त्वा व्युष्ट्यै त्वा रय्यै त्वा राधसे त्वा पोषाय त्वा घोषाय त्वाराद्घोषाय त्वा प्रतिष्ठित्यै त्वा॥९॥ cf. TS 7, 5, 13; (VS 1, 6; 2, 23 ).

[^632_11]: So corr. Ch प्रच्यत्यै, erste Hand प्रच्यै; vgl. TS 7, 5, 13. (Thus emended Ch प्रच्यत्यै, first hand प्रच्यै; cf. TS 7, 5, 13.)

[^632_12]: So corr. यज्ञस्यव्यै (Thus emended from यज्ञस्यव्यै)
