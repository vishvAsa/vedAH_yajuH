आयासाय स्वाहावयासाय स्वाहा वियासाय स्वाहा प्रयासाय[^632_6] स्वाहा संयासाय स्वाहोद्यासाय[^632_7] स्वाहा शोकाय स्वाहा शुचे स्वाहा शुचये स्वाहा तपसे स्वाहा तप्यत्यै स्वाहा क्षुधे स्वाहा भ्रूणहत्यायै स्वाहा सर्वस्मै स्वाहा॥६॥[^632_8] cf. TS 1, 4, 35; VS 39, 11. 12.

[^632_6]: So corr. Ch स्वाहायप्रयासाय (Thus emended; Ch reads स्वाहायप्रयासाय)

[^632_7]: So corr. Ch स्वाहोद्वासाय ; vgl. TS 1, 4, 35. (Thus emended; Ch reads स्वाहोद्वासाय; cf. TS 1, 4, 35)

[^632_8]: Die Zahl corr. Ch hat hier ॥८॥ (The number emended; Ch has here ॥८॥)
