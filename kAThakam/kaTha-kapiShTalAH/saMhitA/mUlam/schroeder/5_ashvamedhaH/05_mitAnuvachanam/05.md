द्यौस्ते पृष्ठं पृथिवी सधस्थमात्मान्तरिक्षँ समुद्रो[^632_2] योनिस्सूर्यस्ते चक्षुर्वातः प्राणश्चन्द्रमाश्श्रोत्रं दिशः[^632_3] पादा अवान्तरदिशाः पशवो नक्षत्राणि रूपं मासाश्चार्धमासाश्च परूँष्यृतवो[^632_4]ऽङ्गानि संवत्सरो महिमा॥५॥[^632_5] cf. TS 5, 7, 25.

[^632_2]: So corr. Ch समुद्र; vgl. TS 5, 7, 25 (Thus emended; Ch reads समुद्र; cf. TS 5, 7, 25)

[^632_3]: So corr. Ch दिशाः (Thus emended; Ch reads दिशाः)

[^632_4]: Ch ष्यतवो

[^632_5]: Die Zahl corrigirt; Ch setzt hier irrigerweise 9, woraus im Folgenden noch einige Fehler hervorgehen, die erst mit Cap. 9 ein Ende haben. (The number emended; Ch erroneously puts 9 here, from which several further errors arise in what follows, ending only with ch. 9.)
