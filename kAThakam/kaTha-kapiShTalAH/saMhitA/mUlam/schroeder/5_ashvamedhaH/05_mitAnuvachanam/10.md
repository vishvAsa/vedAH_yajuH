अग्नये गायत्राय विवृते राथन्तराय[^633_1] वासन्तायाष्टाकपाल इन्द्राय वैष्टुभाय पञ्चदशाय बार्हताय ग्रैष्मायैकादशकपालो विश्वेभ्यो देवेभ्यो जागतेभ्यस्सप्तदशेभ्यो वैरूपेभ्यो वार्षिकेभ्यो द्वादशकपालो मित्रावरुणाभ्यामानुष्टुभाभ्यामेकविँशाभ्यां[^633_2] वैराजाभ्याँ शारदाभ्यां पयस्या बृहस्पतये पाङ्क्ताय त्रिणवाय शाक्वराय हैमन्तिकाय चरुस्सवित्र[^633_3] आतिच्छन्दसाय त्रयस्त्रिँशाय[^633_4] रैवताय शैशिराय द्वादशकपालोऽदित्यै विष्णुपत्न्यै चरुरग्नये वैश्वानराय द्वादशकपालोऽनुमत्यै चरुः काय एककपालः॥१०॥ cf. TS 7, 5, 14.

[^633_1]: So cor. Ch रथ॰ (Thus cor. Ch रथ॰)

[^633_2]: So corr. Ch मनुष्टु॰ (Thus emended; Ch reads मनुष्टु॰)

[^633_3]: So corr. Ch सावित्र (Thus emended; Ch reads सावित्र)

[^633_4]: Ch त्रियस्वि॰
