पृश्निस्तिरश्चीनपृश्निरूर्ध्वपृश्निस्ते मारुताः फल्गुर्लोहितोर्णी बलक्षी[^645_9] तास्सारस्वत्यः पृषती क्षुद्रपृषती स्थूलपृषती ता वैश्वदेव्यस्तिस्रश्श्यामा वशाः पौष्ण्यस्तिस्रो[^645_10] रोहिण्यो[^645_11] वशा मैत्र्य ऐन्द्राबार्हस्पत्या अरुणललामास्तूपराः॥२॥ cf. TS 5, 6, 12; MS 8, 13, 5. 3; VS 24, 4, 2.

[^645_9]: So corr. Ch वलक्षोस्ता॰ ; vgl. TS 5, 6, 12; MS 3, 13, 5. (Thus emended; Ch reads वलक्षोस्ता॰; cf. TS 5, 6, 12; MS 3, 13, 5)

[^645_10]: So corr. Ch पाष्णय॰; vgl. TS 5, 6, 12. (Thus emended; Ch reads पाष्णय॰; cf. TS 5, 6, 12)

[^645_11]: So corr. Ch रौहिण्यो; vgl. TS 5, 6, 12 रोहिणीर्व॰ (Thus emended Ch रौहिण्यो; cf. TS 5, 6, 12 रोहिणीर्व॰)
