उन्नत ऋषभो वामनस्त ऐन्द्रावरुणाश्शितिककुच्छितिपृष्ठश्शितिभसत्त[^646_3] ऐन्द्राबार्हस्पत्याश्शितिपाच्छित्योष्ठश्शितिभ्रूस्त[^646_4] ऐन्द्रावैष्णवास्तिस्रस्सिध्मा वशा वैश्वकर्मण्यस्तिस्रो धात्रे पृषोदराः पौष्णाश्श्येतललामास्तूपराः[^646_5]॥४॥ cf. TS 5, 6, 14; (MS 3, 16, 7. 8); (VS 24, 6. 7).

[^646_3]: So corr. Ch ककुश्छिति॰ भसतु (Thus emended; Ch reads ककुश्छिति॰ भसतु)

[^646_4]: So corr. Ch पाश्छित्योष्टश्शि॰ (Thus emended; Ch reads पाश्छित्योष्टश्शि॰)

[^646_5]: So corr. Ch श्येताललामा॰ (Thus emended; Ch reads श्येताललामा॰)
