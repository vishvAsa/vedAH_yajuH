रोहितो धूम्रलोहितः कर्कन्धुरोहितस्ते प्राजापत्या बभ्रुररुणबभ्रुश्शुकबभ्रुस्ते रौद्राश्श्येतश्श्येताक्षश्श्येतग्रीवस्ते पितृदेवत्यास्तिस्रः[^645_6] कृष्णा वशा वारुण्यस्तिस्रश्श्वेता[^645_7] वशास्सौर्यो मैत्राबार्हस्पत्या धूम्रललामास्तूपराः[^645_8]॥१॥ cf. TS 5, 6, 11; (MS 3, 13, 3); (VS 24, 2).

[^645_6]: So corr. Ch देवत्यस्ति॰ ; vgl. TS 5, 6, 11. (Thus emended; Ch reads देवत्यस्ति॰; cf. TS 5, 6, 11)

[^645_7]: So corr. Ch वारुण्यास्ति॰ ; vgl. TS 5, 6, 11. (Thus emended; Ch reads वारुण्यास्ति॰; cf. TS 5, 6, 11)

[^645_8]: So corr. Ch मस्तू॰ ; vgl. TS 5, 6, 12. (Thus emended; Ch reads मस्तू॰; cf. TS 5, 6, 12)
