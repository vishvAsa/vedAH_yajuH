भूर्भुवस्स्वर्वसवस्त्वाञ्जन्तु गायत्रेण च्छन्दसा रुद्रास्त्वाञ्जन्तु त्रैष्टुभेन च्छन्दसादित्यास्त्वाञ्जन्तु जागतेन च्छन्दसा॥

**यद्वातो अपो अगमदिन्द्रस्य तन्वं प्रियाम्[^629_9]।  
एतँ स्तोतरेतेन पथा पुनरश्वमावर्तयासि[^629_10] नः॥**

[^629_9]: So corr. Ch प्रियम् (Thus emended; Ch reads प्रियम्)

[^629_10]: So corr. Ch श्वसावर्तयामि ; vgl. TS 7, 4, 20; MS 3, 12, 18; VS 23, 7. (Thus emended; Ch reads श्वसावर्तयामि; cf. TS 7, 4, 20; MS 3, 12, 18; VS 23, 7)

लाजी३ञ्छाची३न्यशो[^629_11] ममा३[^629_12] यव्यायै गव्याया एतद्देवा अन्नमत्तैतदन्नमद्वि प्रजापते॥

[^629_11]: So corr. Ch ञ्छातीन्यशो; vgl. TS 7, 4, 20; MS 3, 12, 19. (Thus emended; Ch reads ञ्छातीन्यशो; cf. TS 7, 4, 20; MS 3, 12, 19)

[^629_12]: Die ३ von mir ergänzt; vgl. TS 7, 4, 20. (The ३ supplied by me; cf. TS 7, 4, 20.)

**युञ्जन्ति बध्नमरुषं चरन्तं परि तस्थुषः।  
रोचन्ते रोचना दिवि॥**

**युञ्जन्त्यस्य काम्या[^630_1] हरी विपक्षसा रथे।  
शोणा धृष्णू[^630_2] नृवाहसा॥  
केतुं कृण्वन्नकेतवे पेशो मर्या अपेशसे।  
समुषद्भिरजायथाः॥ ॥९॥**  
cf. TS 7, 4, 20; MS 3, 12, 18. 19; VS 23, 5-8; RV 1, 6, 1-3.

[^630_1]: So corr. Ch कामा (Thus emended; Ch reads कामा)

[^630_2]: So corr. Ch धृष्णु (Thus emended; Ch reads धृष्णु)
