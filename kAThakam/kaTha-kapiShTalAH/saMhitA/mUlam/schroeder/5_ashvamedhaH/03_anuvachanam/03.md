**आ मे गृहा भवन्त्वा प्रजा म आ मा यज्ञो विशतु वीर्यावान्।  
आपो देवीर्यज्ञिया माविशन्तु सहस्रस्य मा भूमा मा प्रहासीत्॥**

**आ मे ग्रहा[^623_1] भवन्त्वा पुरोहकस्तुतशस्त्रे[^623_2] माविशताँ समीची[^623_3]।  
आदित्या रुद्रा वसवो मे सदस्यास्सहस्रस्य मा भूमा मा प्रहासीत्॥**

[^623_1]: In Ch, wie es scheint ग्रहा (so erste Hand) in ग्राहा corr. (In Ch, as it seems, ग्रहा (so first hand) emended to ग्राहा.)

[^623_2]: So corr. Ch पुरोरुक्त्तुत॰ ; vgl. TS 7, 3, 13 = Corr. (Thus emended; Ch reads पुरोरुक्त्तुत॰; cf. TS 7, 3, 13, which agrees with the emendation)

[^623_3]: So corr. Ch ममोची; vgl. TS 7, 8, 13. (Thus emended; Ch reads ममोची; cf. TS 7, 8, 13)

**आ माग्निष्टोमो विशतूक्थ्यश्चातिरात्रो मा विशत्वापिशर्वरः।  
तिरोअह्या मा सुहुता[^623_4] आविशन्तु सहस्रस्य[^623_5] मा भूमा मा प्रहासीत्॥ ॥३॥ cf. TS 7, 3, 13.**

[^623_4]: So corr. Ch तिरोअह्वा मा सुवता; vgl. TS 7, 3, 13. (Thus emended; Ch reads तिरोअह्वा मा सुवता; cf. TS 7, 3, 13)

[^623_5]: So corr. Ch सहस्यस्य; vgl. TS 7, 3, 13. (Thus emended; Ch reads सहस्यस्य; cf. TS 7, 3, 13)
