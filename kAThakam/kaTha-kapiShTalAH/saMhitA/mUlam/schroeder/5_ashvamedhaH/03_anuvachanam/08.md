कृष्णाय स्वाहा श्वेताय स्वाहा पिशङ्गाय[^624_10] स्वाहा सारङ्गाय स्वाहारुणाय स्वाहा गौराय स्वाहा बभ्रुवे स्वाहा नकुलाय स्वाहा शोणाय स्वाहा रोहिताय स्वाहा श्यावाय स्वाहा श्यामाय स्वाहा पालवाय[^625_1] स्वाहा सुरूपाय स्वाहा सरूपाय स्वाहा विरूपाय स्वाहानुरूपाय स्वाहा प्रतिरूपाय स्वाहा शबलाय स्वाहा कमलाय स्वाहा पृश्नये स्वाहा पृश्निसक्थाय[^625_2] स्वाहा सर्वस्मै स्वाहा॥८॥ cf. TS 7, 3, 18.

[^624_10]: So corr. Ch fatima (Thus emended Ch fatima)

[^625_1]: So Ch; in TS 7, 3, 18 पाकला᳓य (Thus Ch; in TS 7, 3, 18 पाकला᳓य)

[^625_2]: So corr. Ch सक्ताय (Thus emended; Ch reads सक्ताय)
