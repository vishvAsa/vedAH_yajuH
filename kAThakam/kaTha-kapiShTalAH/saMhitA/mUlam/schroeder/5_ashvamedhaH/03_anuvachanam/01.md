**अर्वाङ् यज्ञस्सङ्क्रामत्वमुष्मादधि[^621_5] मामभि।  
ऋषीणां यः पुरोहितः॥**

[^621_5]: So corr. Ch सङ्क्रामत्वममुष्मा॰; vgl. TS 7, 3, 11, 1. (Thus emended; Ch reads सङ्क्रामत्वममुष्मा॰; cf. TS 7, 3, 11, 1)

**निर्देवं[^621_6] निर्वीर्यं कृत्वा विष्कन्धं[^621_7] तस्मिन्हीयतां योऽस्मान्द्वेष्टि।  
शरीरं यज्ञशमलं[^621_8] कुसीदं तस्मिन्सीदतु[^621_9] योऽस्मान्द्वेष्टि॥**

[^621_8]: So corr. Ch यज्ञममलं; vgl. TS 7, 3, 11, 1. (Thus emended; Ch reads यज्ञममलं; cf. TS 7, 3, 11, 1)

**यज्ञ यज्ञस्य यत्तेजस्तेन सङ्क्राम मामभि।  
ब्राह्मणानृत्विजो[^622_1] देवान्यज्ञस्य तपसा तेऽसा अहमाहुवे॥**

[^622_1]: So corr. Ch ब्राह्मणा ऋत्विजो; vgl. TS 7, 3, 11, 1. (Thus emended; Ch reads ब्राह्मणा ऋत्विजो; cf. TS 7, 3, 11, 1)

**इष्टेन पक्वमुप ते हुवेऽसा अहम्।  
सं ते वृञ्जे सुकृतँ[^622_2] सं प्रजां पशून्॥[^622_3]**

[^622_2]: So corr. Ch सुकतो; vgl. TS 7, 3, 11, 2. (Thus emended; Ch reads सुकतो; cf. TS 7, 3, 11, 2)

[^622_3]: Das Zeichen 11 fehlt in Ch; von mir gesetzt. Vgl. TS 7, 3, 11, 2. (The sign 11 is missing in Ch; supplied by me. Cf. TS 7, 3, 11, 2.)

**प्रैषान्सामिधेनीराधारा[^622_4] आज्यभागा आश्रुतं प्रत्याश्रुतमाशृणामि ते।  
प्रयाजानुयाजान्स्विष्टकृतमिडामाशिष[^622_5] आवृञ्जे स्वः॥**

[^622_4]: So corr. Ch रागारा ; vgl. TS 7, 3, 11, 2. (Thus emended; Ch reads रागारा; cf. TS 7, 3, 11, 2)

[^622_5]: So corr. Ch याजान्द्विष्टकत॰ ; vgl. TS 7, 3, 11, 2. (Thus emended; Ch reads याजान्द्विष्टकत॰; cf. TS 7, 3, 11, 2)

**अग्निनेन्द्रेण[^622_6] सोमेन सरस्वत्या विष्णुना देवताभिः।  
याज्यानुवाक्याभ्यामुप ते हुवेऽसा अहं यज्ञमाददे[^622_7] ते वषट्कृतम्॥**

[^622_6]: So corr. Ch देन (Thus emended; Ch reads देन)

[^622_7]: So corr. Ch मादद; vgl. TS 7, 3, 11, 2. (Thus emended; Ch reads मादद; cf. TS 7, 3, 11, 2)

**स्तुतँ शस्त्रं प्रतिगरं ग्रहमिडामाशिष आवृञ्जे स्वः।[^622_8]  
पत्नीसंयाजानुप[^622_9] ते हुवेऽसा अहँ समिष्टयजुराददे[^622_10] तव॥**

देवान्सेन्द्रानुप ते हुवेऽसा अहमग्निमुखान्सोमवतो ये च विश्वे॥ ॥१॥ cf. TS 7, 3, 11.**
