title = "०७"

अञ्ज्येताय स्वाहाञ्जिषक्थाय स्वाहा शितिपदे स्वाहा शितिककुदे स्वाहा शितिन्ध्राय स्वाहा शितिपृष्ठाय स्वाहा शित्यँसाय  
स्वाहा पुष्पकर्णाय स्वाहा शित्योष्ठाय स्वाहा शितिभ्रवे स्वाहा शितिभसदे स्वाहा श्वेतानूकाशाय स्वाहाञ्जये स्वाहा ललामाय स्वाहासितज्ञवे[^624_8] स्वाहा कृष्णैताय स्वाहा रोहितैताय[^624_9] स्वाहारुणैताय स्वादेदृशाय स्वाहा कीदृशाय स्वाहा तादृशाय स्वाहा सदृशाय स्वाहा विसदृशाय स्वाहा सुसदृशाय स्वाहा रूपाय स्वाहा सर्वस्मै स्वाहा॥७॥ cf. TS 7, 3, 17.

[^624_8]: So corr. Ch स्वाहासितिज्ञवे; vgl. TS 7, 3, 17. (Thus emended; Ch reads स्वाहासितिज्ञवे; cf. TS 7, 3, 17)

[^624_9]: So corr. Ch रोहिहैताय; vgl. TS 7, 3, 17. (Thus emended; Ch reads रोहिहैताय; cf. TS 7, 3, 17)
