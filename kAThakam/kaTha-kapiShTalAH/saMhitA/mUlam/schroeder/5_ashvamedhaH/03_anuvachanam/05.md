स्वाहाधिमाधीताय स्वाहा स्वाहाधीतं[^623_8] मनसे स्वाहा स्वाहा मनः प्रजापतये स्वाहा काय स्वाहा कस्मै स्वाहा कतमस्मै स्वाहादित्यै स्वाहादित्यै मह्यै स्वाहादित्यै सुमृडीकायै स्वाहा सरस्वत्यै स्वाहा सरस्वत्यै पावकायै स्वाहा सरस्वत्यै बृहत्यै स्वाहा पूष्णे स्वाहा पूष्णे प्रपथ्याय स्वाहा पूष्णे नरन्धिषाय स्वाहा त्वष्ट्रे[^623_9] स्वाहा त्वष्ट्रे[^623_10] तुरीपाय स्वाहा त्वष्ट्रे[^623_11] पुरुरूपाय स्वाहा विष्णवे स्वाहा विष्णवे निखुर्यपाय स्वाहा विष्णवे निभूयपाय स्वाहा विश्वो देवस्य नेतुः॥५॥ cf. TS 7, 3, 15.

[^623_8]: So corr. Ch स्वाहाधितं; vgl. TS 7, 3, 15. (Thus emended; Ch reads स्वाहाधितं; cf. TS 7, 3, 15)

[^623_11]: So corr. Ch त्वाष्ट्र (Thus emended; Ch reads त्वाष्ट्र)
