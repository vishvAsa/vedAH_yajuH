**त्वमग्ने बृहद्वयो ददासि देव दाशुषे।  
कविर्गृहपतिर्युवा हव्यवाडग्निरजरः॥**

पितरो विभुर्विभावा सुदृशीको अस्मे सुगार्हपत्यास्तमिषो दीदिह्यस्मद्य्रक्सम्मिमीहि अवाँसि य इमा विश्वा जातानि विश्वा रूपाणि॥

**त्वं च सोम नो वशो जीवातुं न[^366_1] मरामहे।  
प्रियस्तोत्रो वनस्पतिः॥**

[^366_1]: So corr. Ch जीवातुर्न; cf. RV 1, 91, 6. (Thus emended; Ch reads जीवातुर्न; cf. RV 1, 91, 6)

**ब्रह्मा[^366_2] देवानां पदवीः कवीनामृषिर्विप्राणां महिषो मृगाणाम्।  
श्येनो गृध्राणाँ स्वधितिर्वनानाँ[^366_3] सोमः पवित्रमत्येति रेभन्॥**

[^366_2]: Dieser Vers auch Brl fol. 10. 11. (This verse also Brl fol. 10, 11.)

[^366_3]: Ch गृद्ध्राणाँ स्वदिति ; cf. RV 9, 96, 6.

**उदप्नुतो न वयो रक्षमाणा वावदतो अभ्रियस्येव[^366_4] घोषाः।  
गिरिभ्रजो नोर्मयो मदन्तो[^366_5] बृहस्पतिमभ्यर्का अनावन्॥**

[^366_4]: So corr. Ch स्यव; cf. RV 10, 68, 1. (Thus emended; Ch reads स्यव; cf. RV 10, 68, 1)

[^366_5]: So corr. Ch यो दन्तो (Thus emended; Ch reads यो दन्तो)

**हँसैरिव सखिभिर्वावदद्भिरश्मन्मयानि नहना व्यस्यन्[^366_6]।  
बृहस्पतिरभिकनिक्रदद्गा उत प्रास्तौदुच्च[^366_7] विद्वाँ अगायत्॥**

[^366_6]: So corr. Ch व्यसन; of. RV 10, 67, 3. (Thus emended Ch व्यसन; of. RV 10, 67, 3.)

[^366_7]: So corr. Ch भिकनद्गात उत प्रास्तोदुश्च (Thus emended; Ch reads भिकनद्गात उत प्रास्तोदुश्च)

**त्वँ सुतस्य पीतये सद्यो वृद्धो[^366_8] अजायथाः।  
इन्द्र ज्यैष्ठ्याय सुक्रतो॥**

[^366_8]: Ch erste Hand वृद्धी; cf. RV 1, 5, 6. (Ch first hand वृद्धी; cf. RV 1, 5, 6.)

**भुवस्त्वमिन्द्र ब्रह्मणा महान्भुवो विश्वेषु सवनेषु[^366_9] यज्ञियः।  
भुवो नॄँश्चौत्नो[^366_10] विश्वस्मिन्भरे ज्येष्ठश्च मन्त्रो विश्वचर्षणे॥**

[^366_9]: So corr. Ch सँवनेषु (Thus emended; Ch reads सँवनेषु)

[^366_10]: So corr. Ch न्यृश्च्योब्रो; cf. RV 10, 50, 4. (Thus emended; Ch reads न्यृश्च्योब्रो; cf. RV 10, 50, 4)

**मित्रस्य चर्षणीधृतश्श्रवो देवस्य सानसि।  
सत्यं चित्रश्रवस्तमम्॥**

**मित्रो जनान्यातयति ब्रुवाणो मित्रो दाधार पृथिवीमुत द्याम्।  
मित्रः कृष्टीरनिमिषाभिचष्टे सत्याय हव्यं घृतवद्विधेम[^366_11]॥**

[^366_11]: cf. RV 3, 59, 1.

**प्र स मित्र मर्तो अस्तु प्रयस्वान्यस्त आदित्य शिक्षते[^366_12] व्रतेन।  
न हन्यते न जीयते त्वोतो नैनमँहो अश्नोत्यन्तितो न दूरात्॥**

[^366_12]: So Ch; cf. RV 3, 59, 2. (Thus Ch; cf. RV 3, 59, 2.)

**यत्किञ्चेदं वरुण दैव्ये जनेऽभिद्रोहं मनुष्याश्चरामसि।  
अचित्ती यत्तव धर्मा युयोपिम मा नस्तस्मादेनसो देव रीरिषः[^367_1]॥**

[^367_1]: cf, RV 7, 89, 5.

**कितवासो यद्रिरिपुर्न दीवि[^367_2] यद्वा घा सत्यमुत यन्न विद्म।  
सर्वा ता विष्य[^367_3] शिथिरेव देवाधा[^367_4] ते स्याम वरुण प्रियासः॥**

[^367_2]: So corr. Ch तोवि; cf. RV 5, 85, 8. (Thus emended; Ch reads तोवि; cf. RV 5, 85, 8)

[^367_3]: So corr. Ch विध्य; cf. RV 5, 85, 8. (Thus emended; Ch reads विध्य; cf. RV 5, 85, 8)

[^367_4]: So corr. Ch देवधा (Thus emended; Ch reads देवधा)

**यथा नो अदितिः करत्पश्वे नृभ्यो यथा गवे।  
यथा तोकाय रुद्रियम्[^367_5]॥**

[^367_5]: cf. RV 1, 43. 2.

**मा[^367_6] स्तोके तनये मान आयौ मा नो गोषु मा नो अश्वेषु रीरिषः।  
वीरान्मा नो रुद्र भामितो[^367_7] वधीर्हविष्मन्तो नमसा विधेम[^367_8] ते॥१२॥**

[^367_6]: Dieser Vers T7 fol. 16ª. (This verse T7 fol. 16ª.)

[^367_7]: T7 भामिथो; cf. RV 1, 114, 8.

[^367_8]: So T7; Ch विधोम; cf. RV 1, 114, 8. (Thus T7; Ch विधोम; cf. RV 1, 114, 8.)

इति श्रीयजुषि काठके चरकशाखायां मध्यमिकायां दीक्षितन्नाम[^367_9] त्रयोविंशं स्थानकं सम्पूर्णम्[^367_10]॥

[^367_9]: So Ch; cf. Kap. S. am Schlus von 37, 1 दीक्षितनाम पञ्च प्रपाठकः॥ (sic). (Thus Ch; cf. Kap. S. at the end of 37, 1: दीक्षितनाम पञ्च प्रपाठकः॥ (sic).)

[^367_10]: So die Unterschrift des Capitels in Ch. (Thus the colophon of the chapter in Ch)
