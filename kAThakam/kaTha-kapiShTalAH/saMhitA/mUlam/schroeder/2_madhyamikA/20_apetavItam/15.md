वैश्वानरो न ऊतये॥ पृष्टो दिवि॥

**पर्जन्याय प्रगायत दिवस्पुत्राय मीढुषे।  
स नो यवसमिच्छतु॥**

**इदं वचः[^315_5] पर्जन्याय स्वराजे हृदो अस्त्वन्तरं तज्जुजोषत्।  
मयोभुवो वृष्टयस्सन्त्वस्मै सुपिप्पला[^315_6] ओषधी र्देवगोपाः॥**

[^315_5]: So corr. Ch **वाचः** (Thus emended; Ch reads वाचः)

[^315_6]: So corr. Ch **सपि**° (Thus emended; Ch reads सपि)

समिधो अग्न आज्यस्य व्यन्तु[^315_7] तनूनपादग्न आज्यस्य वेत्विडो अग्न आज्यस्य व्यन्तु बर्हिरग्न आज्यस्य वेतु दुरो अग्न आज्यस्य व्यन्तु[^315_8] दुरो अग्न आज्यस्य व्यन्त्विडो[^315_9] अग्न आज्यस्य व्यन्तु बर्हिरग्न आज्यस्य वेतु दुरो अग्न आज्यस्य व्यन्तूषासानक्ताग्न आज्यस्य वीतां दैव्या होताराग्न आज्यस्य वीतां तिस्रो देवीरग्न आज्यस्य व्यन्तु॥ स्वाहाग्निँ स्वाहा सोमँ स्वाहाग्निँ स्वाहा सोमँ[^315_10] स्वाहा सवितारँ स्वाहा सरस्वँती स्वाहा पूषणँ स्वाहा मरुतस्स्वतवसस्स्वाहा विश्वान्देवान्स्वाहा द्यावापृथिवी स्वाहाग्निँ होतारँ स्वाहा देवा आज्यपा जुषाणा आज्यस्य व्यन्तु त्वमग्ने सप्रथा असि त्वँ सोम महे भगमग्निर्मूर्धा भुवो यज्ञस्य वृषा सोम या ते धामानि तद्विश्वा रूपाणि पावका न आ नो दिवः पूषा गा अन्वेतु नश्शुक्रं ते अन्यत्॥ **इहेह वस्स्वतवसो मरुतस्सूर्यत्वचः।  
शर्मा सप्रथा आवृणे॥  
प्र चित्रमर्कं[^316_1] गृणते तुराय मारुताय स्वतवसे भरध्वम्।  
ये सहाँसि सहसा सहन्ते[^316_2] रेजते अग्ने पृथिवी मखेभ्यः[^316_3]॥**

[^315_7]: So corr. Ch **व्यर्तु** (Thus emended; Ch reads व्यर्तु)

[^315_8]: So corr. Ch **वेतु**; cf. unten (Thus emended; Ch reads वेतु; cf. below)

[^315_9]: So corr. Ch **वेत्वि**°; cf. unten. (Thus emended Ch वेत्वि°; cf. below.)

[^315_10]: Von der ersten Hand nur ein Mal **स्वाहाग्निँ स्वाहा सोमँ **gesetzt; dann die Repetition eingeschaltet. (Written only once by the first hand: स्वाहाग्निँ स्वाहा सोमँ; then the repetition was inserted.)

[^316_1]: So corr. Ch **मर्कां ** (Thus emended; Ch reads मर्कां)

[^316_2]: So corr. Ch **सहन्ति**; cf. RV 6,66, 9. (Thus emended; Ch reads सहन्ति; cf. RV 6,66, 9)

[^316_3]: So corr. Ch **सखेभ्यः**; cf. RV 6, 66, 9. (Thus emended; Ch reads सखेभ्यः; cf. RV 6, 66, 9)

विश्वे देवा ये केच ज्मा मही द्यौर्घृतवती पिप्रीहि देवाना[^316_4] देवानां देवं बर्हिर्वसुवने वसुधेयस्य वेतु देवीर्द्वारो वसुवने वसुधेयस्य व्यन्तु देवी उषासानक्ता वसुवने वसुधेयस्य वीतां देवी जोष्ट्री वसुवने वसुधेयस्य वीतां देवी ऊर्जाहुती वसुवने वसुधेयस्य वीतां देवा दैव्या होतारा वसुवने वसुधेयस्य वीतां देवीस्तिस्रस्तिस्रो देवीर्वसुवने वसुधेयस्य व्यन्तु देवो नराशँसो वसुवने वसुधेयस्य वेतु[^316_5] देवो अग्निस्स्विष्टकृच्छं[^316_6] नो भवन्तु वाजे वाजे॥१५॥ cf. Mâitr. S. 4, 10, 3.

[^316_4]: So corr. Ch **देवानां**; cf. oben 2, 15. (Thus emended; Ch देवानां; cf. above 2, 15.)

[^316_5]: So corr. Ch **व्यन्तु ** (Thus emended; Ch reads व्यन्तु)

[^316_6]: So corr. Ch **कृछन्नो ** (Thus emended; Ch reads कृछन्नो)

इति श्रीयजुषि काठके चरकशाखायां मध्यमिकायामपेतवीतं[^316_7] नाम विंशं स्थानकं सम्पूर्णम्[^316_8]॥
