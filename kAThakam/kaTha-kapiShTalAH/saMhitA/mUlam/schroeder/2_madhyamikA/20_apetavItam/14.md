एह्यू षु ब्रवाणि ते॥

**यत्रो[^314_1] क्वच ते मनो दक्षं दधस उत्तरम्।  
तत्रा सदः कृणवसे॥**

[^314_1]: So Ch; cf. RV 6, 16, 17 **यत्र ** (Thus Ch; cf. RV 6, 16, 17 यत्र)

**नहि ते पूर्तमक्षिपद्भुवन्नेमानां वसो।  
अथा दुवो वनवसे॥**

**आग्निरगामि भारतो वृत्रहा[^314_2] पुरुचेतनः।  
दिवोदासस्य सत्पतिः॥**

[^314_2]: So corr. Ch **वृत्रभा**; cf. RV 6, 16, 19. (Thus emended; Ch reads वृत्रभा; cf. RV 6, 16, 19)

**स हि विश्वाति पार्थिवा रयिं दाशन्महित्वना[^314_3]।  
वन्वन्नवातो अस्तृतः॥**

[^314_3]: So corr. Ch **दाशर्म**°; cf. RV 6, 16,20. ** ** (Thus emended; Ch reads दाशर्म°; cf. RV 6, 16,20.)

**स प्रत्नवन्नवीयसाग्ने द्युम्नेन संयता[^314_4]।  
बृहत्ततन्थ भानुना॥**

[^314_4]: So corr. Ch **संयतः**; cf. RV 6,16, 21 = Corr. (Thus emended; Ch reads संयतः; cf. RV 6,16, 21, which agrees with the emendation.)

**अग्न आयाहि वीतये गृणानो हव्यदातये।  
नि होता सत्सि बर्हिषि[^314_5]॥**

[^314_5]: So corr. Ch **बर्हिषे**; cf. RV 6, 16, 10 (Thus emended; Ch reads बर्हिषे; cf. RV 6, 16, 10)

**अग्निं दूतं वृणीमहे होतारं विश्ववेदसम्।  
अस्य यज्ञस्य सुक्रतुम्॥**

अग्निर्वृत्राणि जङ्घनदग्निनाग्निस्समिध्यते ऽग्निँ स्तोमेन बोधयाग्निर्मूर्धा प्रेद्धो अग्ने ऽग्निँ होतारं मन्ये॥

**एभिर्नो अर्कैर्भवा नो अर्वाङ् स्वर्ण ज्योतिः।  
अग्ने विश्वेभिस्सुमना अनीकैः॥**

**अध ह्यग्ने क्रतोर्भद्रस्य दक्षस्य साधोः।  
रथीर्ऋतस्य[^315_1] बृहतो बभूय॥**

[^315_1]: So corr. Ch **रथीनृतस्य**; cf. RV 4, 10, 2. (Thus emended; Ch reads रथीनृतस्य; cf. RV 4, 10, 2)

**अग्ना यो मर्त्यो दुवो धियं जुजोष धीतिभिः।  
भसन्नु ष प्र पूर्व्यम् इषं[^315_2] वुरीतावसे॥**

[^315_2]: Ch **इषब्वु**°

**अग्नेस्स्तोमं मनामहे सिध्रमद्य दिवस्पृशः[^315_3]।  
देवस्य द्रविणस्यवः[^315_4]॥ ॥१४॥** cf. Mâitr. S.4,10,2.

[^315_3]: So Ch. (Thus Ch.)

[^315_4]: So corr. Ch **प्रविण**° (Thus emended; Ch reads प्रविण)
