यदि मन्येत पूर्वो मातिक्रान्तो भ्रातृव्य इति बहिष्पवमानस्य पुरस्तादष्टौ लोकम्पृणयोपदध्यान्माध्यन्दिनस्य[^345_2] पवमानस्य पुरस्तादेकादशार्भवस्य[^345_3] पवमानस्य पुरस्ताद्द्वादशायं वाव यः पवते स पवमानो वायुरस्तेजो य एवैनं पूर्वोऽतिक्रान्तो भ्रातृव्यस्तं तेजसा प्रणुदते यदि मन्येत पश्चान्मे भ्रातृव्य इति पश्चादेतेषां पवमानानामुपदध्यादयं वाव यः पवते स पवमानो वायुरस्तेजो य एवास्य पश्चाद्भ्रातृव्यस्तं तेजसापनुदते[^345_4] प्र श्रेयाँसं भ्रातृव्यं नुदते प्रति पापीयाँसं नुदते ॥ स एष सवनचित्प्रजापतिर्वा उख्यमग्निमबिभस्तस्य शिरः प्रावर्तत तेन देवा अश्राम्यँस्तस्यैतच्छिरः प्रत्यदधुर्यदुखा तत्संवत्सरमरोहदग्निः[^345_5] प्रजापतिर्यत्संवत्सरमुख्यं[^345_6] बिभर्ति प्रजापतेरेव शिरः प्रतिदधाति तस्मात्संवत्सरमुख्यो[^345_7] भर्तव्यो यदर्वाक्संवत्सरादरुश्चिदेव[^345_8] सः॥

[^345_2]: So corr. Ch लोकस्पृण॰ (Thus emended; Ch reads लोकस्पृण॰)

[^345_3]: So corr. Ch शान्भवस्य (Thus emended; Ch reads शान्भवस्य)

[^345_4]: So corr. Ch तेजसामपनुदते; Kap. S. 35, 4 = Corr. (Thus emended; Ch reads तेजसामपनुदते; Kap. S. 35, 4 agrees with the emendation)

[^345_5]: So corr. Ch संव्वरमरो° (Thus emended; Ch reads संव्वरमरो°)

[^345_6]: So corr. Ch संव्वरमु° (Thus emended; Ch reads संव्वरमु°)

[^345_7]: So corr. Ch संव्वरमु° (Thus emended; Ch reads संव्वरमु°)

[^345_8]: So corr. Ch यदर्वाक्तर्वाक्तंवत्सरादरुश्चिदेव oder दहश्चिदेव; Kap. S. 35, 4 deutlich संवत्सरादरुश्चिदेव; vielleicht अरु = Sonne. (Thus emended Ch यदर्वाक्तर्वाक्तंवत्सरादरुश्चिदेव or दहश्चिदेव; Kap. S. 35, 4 clearly संवत्सरादरुश्चिदेव; perhaps अरु = sun.)

**येन देवा ज्योतिषोर्ध्वा उदायन्येनादित्या वसवो येन रुद्राः।  
येनाङ्गिरसो महिमानमानश्रुस्तेनैतु यजमानस्स्वस्ति॥**

इति घृतेनाक्त्वा समिधमादधाति समिद्धिरेवैषाथो[^345_9] यजमानायैवैतत्स्वस्त्ययनं क्रियते॥ **येऽग्नयः पुरीषण आविष्टाः पृथिवीमनु।  
तेषामसि त्वमुत्तमः प्र नो जीवातवे सुव॥**

[^345_9]: So corr. Ch समिद्धिरेवैपाथो (Thus emended; Ch reads समिद्धिरेवैपाथो)

इति स्वमग्निं चितमुपतिष्ठेत सर्वमायुरेत्युप त्वाग्ने दिवे दिव इत्येतेन त्रिय्यृचेनान्येषामाशीरेव सा॥१०॥ cf. Kap. S. 35, 4.
