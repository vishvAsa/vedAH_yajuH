इयं वामस्य मन्मनश्शुचिं नु स्तोमं मरुतो यद्ध वो दिवो या वश्शर्मेमं मे वरुण तत्त्वायामि कया नश्चित्रः॥

**कया तच्छृण्वे शच्या शचिष्ठो यया कृणोति मुहु काचिदृष्वः[^332_14]।  
पुरु दाशुषे विचयिष्ठो अँहो ऽथा दधाति द्रविणं जरित्रे॥  
उदुत्तमं मुमुग्धि नो वि पाशं मध्यमं चृत[^332_15]।  
अवाधमानि[^332_16] जीवसे॥**

[^332_14]: So corr. Ch **दृष्टः**; vgl. RV 4, 20, 9. (Thus emended; Ch reads दृष्टः; cf. RV 4, 20, 9)

[^332_15]: So corr. Ch **मध्यमँ शृत ** (Thus emended; Ch reads मध्यमँ शृत)

[^332_16]: So corr. Ch **अबाधमान्नि** (Thus emended; Ch reads अबाधमान्नि)

**उदुत्तमं वरुण पाशमस्मत्त्वं नो अग्ने स त्वं नो अग्ने॥**

**अनेकवन्तमूतये ऽग्निं धीभिर्हवामहे।  
स नः पर्षदति द्विषः॥**

**सैनानीकेन सुविदत्रो[^333_1] अस्मे यष्टा देवाँ[^333_2] आयजिष्ठस्स्वस्ति।  
अदब्धो गोपा उत[^333_3] नः परस्या अग्ने द्युमदुत रेवद्दिदीहि॥**

[^333_1]: So corr. Ch **दात्रो** ; cf. RV 2,9,6. (Thus emended; Ch reads दात्रो; cf. RV 2,9,6)

[^333_2]: So corr. Ch **देवा**; cf. RV 2, 9, 6. (Thus emended; Ch reads देवा; cf. RV 2, 9, 6)

[^333_3]: So corr. Ch **उता ** (Thus emended; Ch reads उता)

**सान्तपना इदँ हविर्मरुतस्तज्जुजुष्टन[^333_4]।  
युष्माकोती रिशादसः॥**

[^333_4]: So corr. Ch **तं जुजुष्ठान**; cf. RV 7,59, 9. (Thus emended; Ch reads तं जुजुष्ठान; cf. RV 7,59, 9)

**यो नो मर्तो मरुतो दुर्हृणायुस्तिरश्चित्तानि वसवो जिघाँसति[^333_5]।  
द्रुहः[^333_6] पाशं प्रति षू मुचीष्ट[^333_7] तपिष्ठेन तपसा हन्तना तम्॥**

[^333_5]: So corr. Ch **श्चित्ता वोसवो जिघाँसत**; RV 7, 59, 8. (Thus emended; Ch श्चित्ता वोसवो जिघाँसत; RV 7, 59, 8.)

[^333_6]: So corr. Ch **दुहस**; cf. RV 7,59, 8. (Thus emended; Ch reads दुहस; cf. RV 7,59, 8)

[^333_7]: So corr. Ch **मुचित;** cf. RV 7, 59, 8; Mâitr. S. 4, 10, 5. (Thus emended; Ch reads मुचित; cf. RV 7, 59, 8; Mâitr. S. 4, 10, 5.)

**गृहमेधा रिशादसो मरुतो मापभूतन[^333_8]।  
प्रमुञ्चन्तो नो अँहसः॥**

[^333_8]: So corr. Ch **मामभू**°; cf. RV 7, 59, 10. (Thus emended; Ch reads मामभू; cf. RV 7, 59, 10)

**प्र बुध्न्या व ईरते महाँसि प्र नामानि प्रयज्यवस्तिरध्वम्[^333_9]।  
सहस्रियं दम्यं[^333_10] भागमेतं गृहमेधीयं मरुतो जुषध्वम्॥**

[^333_9]: So corr. Ch **प्रयुज्य**°; cf. RV 7, 56, 14. (Thus emended; Ch reads प्रयुज्य; cf. RV 7, 56, 14)

[^333_10]: So corr. Ch **दस्यम्भा**°; cf. RV 7, 56, 14. (Thus emended; Ch reads दस्यम्भा; cf. RV 7, 56, 14)

**क्रीडं वश्शर्धो मारुतमनर्वाणं[^333_11] रथेशुभम्।  
कख्वा अभिप्रगायत॥**

[^333_11]: So corr. Ch **मरुतम**°; cf. RV 1, 37, 1. (Thus emended; Ch reads मरुतम; cf. RV 1, 37, 1)

**अत्यासो न ये मरुतस्त्वञ्चो यक्षदृशो न शुभयन्त मर्याः।  
ते हर्म्येष्ठाश्शिशवो न शुभ्रा वत्सासो न[^333_12] प्रक्रीडिनः पयोधाः॥**

[^333_12]: So corr. Ch **नः**; cf. RV 7, 56, 16. (Thus emended; Ch reads नः; cf. RV 7, 56, 16)

**इन्द्राग्नी श्नथद्वृत्रमा तू न इन्द्र त्वं महाँ इन्द्र॥**

**विश्वकर्मन्हविषा वावृधानस्स्वयं यजस्व पृथिवीमुत द्याम्।  
मुह्यन्त्वन्ये[^333_13] अभितो जनास इहास्माकं मघवा सूरिरस्तु॥**

[^333_13]: So corr. Ch **मुह्यान्त्व**°; cf. RV 10, 81, 6. (Thus emended; Ch reads मुह्यान्त्व; cf. RV 10, 81, 6)

**वाचस्पतिं विश्वकर्माणमूतये मनोजुवं वाजे अद्याहुवेम।  
स नो नेदिष्टँ हवनानि जोषद्विश्वशम्भूरवसे[^334_1] साधुकर्मा॥१३॥**

[^334_1]: So corr. Ch **हवनाराणोषद्विश्वशम्भूवसे**; cf. RV 10, 81, 7; Mâitr. S. 2, 10, 2; in Çâradâ ist das Zeichen für **ज** demjenigen für ण sehr ähnlich. (Thus emended; Ch हवनाराणोषद्विश्वशम्भूवसे; cf. RV 10, 81, 7; Mâitr. S. 2, 10, 2; in Śāradā the sign for ज is very similar to that for ण very similar.)
