**क्रत्वा दा अस्तु श्रेष्ठो ऽद्य त्वा वर्धन्सुरेक्णाः[^412_13]।  
मर्त आनाश सुवृक्तिम्॥**

[^412_13]: So Ch; RV 6, 16, 26 वन्व᳓न्त्सुº (Thus Ch; RV 6, 16, 26 reads वन्व᳓न्त्सुº)

**इमा ब्रह्म[^413_1] ब्रह्मवाहः क्रियन्त आ बर्हिस्सीद।  
वीहि श्रुर पुरोडाशम्॥**

[^413_1]: ब्रह्म fehlt in Ch; ergänzt nach RV 3, 41, 3. (ब्रह्म is missing in Ch; supplied after RV 3, 41, 3.)

**उप नस्सूनवो गिरश्शृण्वन्त्वमृतस्य ये।  
सुमृडीका भवन्तु नः॥[^413_2]**

[^413_2]: cf. RV 6, 52, 9.

**ता नश्शक्तं[^413_3] पार्थिवस्य महो रायो दिव्यस्य।  
महि वां क्षत्रं[^413_4] देवेषु॥**

[^413_3]: So corr. Ch र्शाº; cf. RV 5, 68, 3. (Thus emended; Ch reads र्शाº; cf. RV 5, 68, 3)

[^413_4]: So corr. Ch क्षेत्रं; cf. RV 5, 68, 3. (Thus emended; Ch reads क्षेत्रं; cf. RV 5, 68, 3)

**बृहस्पते जुषस्व नो अग्न आयाहि वीतय एन्द्र सानसिं रयिम्॥**

**आ नो भद्राः क्रतवो यन्तु विश्वतो ऽदब्धासो अपरीतास उड्मिदः।  
देवा नो यथा सदमिद्वृधे असन्नप्रायुवो रक्षितारो दिवे दिवे॥[^413_5]**

[^413_5]: cf. RV 1, 89, 1.

आ नो मित्रावरुणा॥

**आ विबाध्या परिरापस्तमाँसि च ज्योतिष्मन्तं रथमृतस्य तिष्ठसि।  
बृहस्पते भीमममित्रदम्भनं रक्षोहणं गोत्रभिदँ स्वर्विदम्॥[^413_6]**

[^413_6]: cf. RV 2, 23, 3.

पञ्च व्युष्टीः॥

**सखे सखायमभ्याववृत्स्वाशुर्न चक्रं रथे ऽवरोह्यास्मभ्यं[^413_7] दस्म रँह्या।**

[^413_7]: So Ch; cf. dagegen RV 4, 1, 3. (Thus Ch; cf. sincegegen RV 4, 1, 3.)

**अग्ने मृडीकं वरुणे सचा विदो मरुत्सु विश्वभानुषु।  
तोकाय तुजे शुशुचान शं कृध्यस्मभ्यं दस्म[^413_8] शं कृधि॥**

[^413_8]: So corr. Ch दम; cf, RV 4, 1, 3. (Thus emended; Ch दम; cf, RV 4, 1, 3.)

**अग्निँ होतारं मन्ये दास्वन्तं वसुँ सूनुँ सहसो जातवेदसं विप्रं न जातवेदसम्।**

**य ऊर्ध्वया स्वध्वरो देवो देवाच्या कृपा।  
घृतस्य विभ्राष्टिमनु वष्टि शोचिषाजुव्हानस्य सर्पिषः॥[^413_9] ॥११॥**

[^413_9]: cf. RV 1, 127, 1.
