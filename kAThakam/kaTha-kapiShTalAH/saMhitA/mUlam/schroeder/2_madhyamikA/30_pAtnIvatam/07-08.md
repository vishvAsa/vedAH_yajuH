देवाश्च वा असुराश्च समावदेव यज्ञेऽकुर्वत यदेव देवा अकुर्वत तदसुरा अकुर्वत ते देवा एतमदाभ्यमपश्यँस्तमगृह्णताग्नये त्वा प्रवृहामि गायत्रेण च्छन्दसेति देवताश्चैव तच्छन्दाँसि चाप्नुवन्नग्निः प्रातस्सवने पात्वस्मानिति सवनान्येव तदाप्नुवँश्छुक्रं[^464_11] ते शुक्रेण गृह्णामी**प्रजानन्तः प्रतिगृह्णन्ति पूर्वे प्राणमङ्गेभ्यो[^465_1] अधिनिश्चरन्तम्।  
हुतो याहि पथिभिर्देवयानैरोषधीषु प्रतितिष्ठा शरीरैः॥**

[^464_11]: So corr. Ch प्नवञ्छुक्रं (Thus emended; Ch reads प्नवञ्छुक्रं)

[^465_1]: So corr. Ch **प्रणस्सङ्गेभ्यो;** cf. TS 3, 1, 4, 1. (Thus emended; Ch reads प्रणस्सङ्गेभ्यो; cf. TS 3, 1, 4, 1.)

**ये बध्यमानमनुबध्यमाना अन्वैक्षन्त मनसा चक्षुषा च।  
अग्निष्टाँ अग्रे प्रमुमोक्तु देवः प्रजापतिः प्रजया संविदानः[^465_2]॥**

[^465_2]: cf. Mâitr. S. 1, 2, 15; TS 3, 1, 4, 2; AV 2, 34, 3.

**य आरण्याः पशवो विश्वरूपा विरूपास्सन्तो बहुधैकरूपाः।  
वायुष्टाँ[^465_3] अग्रे प्रमुमोक्तु देवो विश्वकर्मा प्रजया संरराणः॥**

[^465_3]: So corr. Ch **वायुष्टा**; cf. TS 3, 1, 4, 2. (Thus emended; Ch reads वायुष्टा; cf. TS 3, 1, 4, 2)

**येषामीशे पशुपतिः पशूनां चतुष्पाद उत ये द्विपादः।  
निष्क्रीतास्ते यज्ञियं भागं यन्तु रायस्पोषा यजमानं विशन्तु॥**

**प्रमुञ्चमाना[^465_4] भुवनस्य रेतो गातुं[^465_5] धत्त यजमानाय देवाः।  
उपाकृतँ शशमानं यदस्थात्प्रियं[^465_6] देवानामप्येतु पाथः॥**

[^465_4]: So corr. Ch **प्रमुचमानो**; cf. TS 3, 1, 4, 2. (Thus emended; Ch reads प्रमुचमानो; cf. TS 3, 1, 4, 2)

[^465_5]: So corr. Ch **गा**त्तं; cf. TS 3, 1, 4, 3. (Thus emended Ch गात्तं; cf. TS 3, 1, 4, 3.)

[^465_6]: So corr. Ch **यदस्रात्प्रियं** oder **यदस्ता॰**; cf. TS 3, 1, 4, 3. (Thus emended Ch यदस्रात्प्रियं or यदस्ता॰; cf. TS 3, 1, 4, 3.)

**नाना प्राणो यजमानस्य पशुना यज्ञो देवेभिस्सह देवयानः।  
सम्यगायुर्यज्ञो यज्ञपतौ दधातु॥**

**उपेत शमितारो देवानां दसितँ हविः।  
पशोः पाशं[^465_7] प्रमुञ्चत पाशं यज्ञपतेरधि॥**

[^465_7]: So corr. Ch **पाशः**; vgl. denselben Vers richtig unten im folgenden Capitel. Anders TS 3, 1, 4, 4. Mâitr. S. 1, 2, 15 a. E. (Thus emended; Ch reads पाशः; cf. the same verse correctly below in the following chapter. Differently TS 3, 1, 4, 4. Mâitr. S. 1, 2, 15 at the end.)

**अदितिः पाशात्प्रमुमोक्त्वेन्नमः पशुभ्यः पशुपतयेऽस्तु।  
यो नो द्वेष्ट्यधरस्स पदीष्ट[^465_8] तस्मिन्पाशात्प्रतिमुञ्चाम एतान्॥**

[^465_8]: So corr. Ch **सस्पदीष्ट;** Mâitr. S. 1, 2, 15 **स᳓ प्रद्यतांः** anders TS 3, 1, 4, 4. (Thus emended; Ch reads सस्पदीष्ट; Mâitr. S. 1, 2, 15 reads स᳓ प्रद्यतांः, differently TS 3, 1, 4, 4.)

**त्वामु ये दधिरे प्रथमं विचक्ष्यँ[^465_9] शृतङ्कर्तारमुत[^465_10] यज्ञियं च।  
अग्ने सदक्षस्सतनूर्हि भूत्वाथ वह हव्यं देवेभ्यो जातवेदः॥**

[^465_9]: So corr. Ch **विचक्ष्यो**; cf. unten im folgenden Capitel denselben Pâda. (Thus emended; Ch reads विचक्ष्यो; cf. below in the following chapter the same Pâda.)

[^465_10]: cf. TS 3, 1, 4, 4.

**जातवेदो वपया गच्छ देवाँस्त्वँ[^466_1] हि होता प्रथमो बभूथ।  
घृतस्याग्ने[^466_2] तन्वा सम्भव सत्यास्सन्तु यजमानस्य कामाः॥८॥**

[^466_1]: So corr. Ch स्त्व (Thus emended; Ch reads स्त्व)

[^466_2]: So corr. Ch स्याग्रे (Thus emended; Ch reads स्याग्रे)

cf. TS 3,1, 4; (Mâitr. S. 1, 2, 15).
