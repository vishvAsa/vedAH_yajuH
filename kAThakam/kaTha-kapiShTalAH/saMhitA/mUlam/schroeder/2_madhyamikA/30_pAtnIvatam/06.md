अग्नये त्वा प्रवृहामि गायत्रेण च्छन्दसेन्द्राय त्वा प्रवृहामि त्रैष्टुभेन च्छन्दसा विश्वेभ्यस्त्वा देवेभ्यः प्रवृहामि जागतेन च्छन्दसा॥ **अग्निः प्रातस्सवने पात्वस्मान्वैश्वानरो विश्वकृद्विश्वशम्भूः।  
स नः पावको[^464_1] द्रविणं दधात्वायुष्मन्तस्सहभक्षास्स्याम[^464_2]॥**

[^464_1]: So corr. Ch पावता; cf. TS 3, 1, 9, 1. (Thus emended; Ch reads पावता; cf. TS 3, 1, 9, 1)

[^464_2]: So corr. Ch भक्षस्स्याम (Thus emended; Ch reads भक्षस्स्याम)

**विश्वे देवा मरुत इन्द्रो अस्मानस्मिन्द्वितीये सवने न जह्युः।  
सुमेधसः प्रियमेषां वदन्तो वयँ स्याम पतयो रयीणाम्[^464_3]॥**

[^464_3]: cf. TS 3, 1, 9, 2.

**इदं तृतीयसवनं[^464_4] कवीनामृतेन ये चमसमैरयन्त[^464_5]।  
सौधन्वना[^464_6] अमृतमानशानास्स्विष्टं नोऽभि वस्यो नयन्तु॥**

[^464_4]: So Ch; TS 3, 1, 9, 2 तृतीयँ सवनं (Thus Ch; TS 3, 1, 9, 2 reads तृतीयँ सवनं)

[^464_5]: So corr. Ch मेरयन्त; TS 3, 1, 9, 2 = Corr. (Thus emended; Ch reads मेरयन्त; TS 3, 1, 9, 2 agrees with the emendation)

[^464_6]: So corr. Ch सौधन्वाना (Thus emended; Ch reads सौधन्वाना)

शुक्रं ते शुक्रेण गृह्णाम्यहूो रूपे सूर्यस्य रश्मिषु रेशीनां त्वा पत्मन्नाधूनोमि मान्दानां त्वा पत्मन्नाधूनोमि कूतनानां त्वा पत्मन्नाधूनोमि भन्दनानां त्वा पत्मन्नाधूनोमि देवयानीनां त्वा पत्मन्नाधूनोमि॥

**आ सीमुग्रा[^464_7] अचुच्यवुर्दिवो[^464_8] धारामसश्चत[^464_9]।  
ककुभं रूपमृषभस्य रोचते बहत्॥**

[^464_7]: So Ch; Mâitr. S. 1, 3, 36 आ᳓ समुद्रा᳓ (Thus Ch; Mâitr. S. 1, 3, 36 reads आ᳓ समुद्रा᳓)

[^464_8]: So corr. Ch च्यवुन्दिवो (Thus emended; Ch reads च्यवुन्दिवो)

[^464_9]: So corr. Ch श्वत् (Thus emended; Ch reads श्वत्)

सोमस्सोमस्य पुरोगाश्शुक्रश्शुक्रस्य पुरोगा यत्ते सोमादाभ्यं नाम जागृवि तस्मै ते सोम सोमाय स्वाहा॥ त्रिर्वसुभ्यो अवपथास्त्री[^464_10] रुद्रेभ्यो अवपथास्त्रिरादित्येभ्यो अवपथा येन रूपेण प्रजापतयेऽवपथास्तेन मह्यं पवस्वोशिक्त्वं देव सोम गाच्छन्दसानेः पाथ उपेहि वशी त्वं देव सोम त्रैष्टुभेन च्छन्दसेन्द्रस्य पाथ उपेयस्मत्सखा देव सोम ग..ण च्छन्दसाग्ने पाथ उपेहि वशी त्वं देव सोम त्रैष्टुभेण च्छन्दसेन्द्रस्य पाथ उपेह्यस्मत्याखा देव सोम जागतेन च्छन्दसा विश्वेषां देवानां पाथ उपेहि॥६॥

[^464_10]: So corr. Ch अपवथा॰ (Thus emended; Ch reads अपवथा॰)

cf. Mâitr. S. 1, 3, 36; TS 3, 1, 9.
