उपयामगृहीतोऽसि प्रजापतये त्वा प्रजाभ्य एष ते योनिः प्रजापतये त्वा प्रजाभ्य उपयामगृहीतोऽसि प्रजाभ्यस्त्वा प्रजापतय एष ते योनिः प्रजाभ्यस्त्वा प्रजापत उपयामगृहीतोऽस्यन्तरिक्षाय त्वा वनस्पतिभ्य एष ते योनिरन्तरिक्षाय त्वा वनस्पतिभ्य उपयामगृहीतोऽसि वनस्पतिभ्यस्त्वान्तरिक्षायैष ते योनिर्वनस्पतिभ्यस्त्वान्तरिक्षायोपयामगृहीतोऽस्याद्भस्त्वौषधीभ्य एष ते योनिरद्भस्त्वौषधीभ्य उपयामगृहीतोऽस्योषधीभ्यस्त्वाद्भ एष ते योनिरोषधीभ्यस्त्वाद्मः॥

**उदुत्यं जातवेदसं देवं वहन्ति केतवः।  
दृशे विश्वाय सूर्यम्॥**

उपयामगृहीतोऽसि सूर्याय त्वैष ते योनिस्सूर्याय त्वा॥

**वाचस्पतिं विश्वकर्माणमूतये मनोयुजं[^462_6] वाजे अद्या हुवेम।  
स नो नेदिष्ठँ हवनान्यागमद्विश्वशम्भूरवसे साधुकर्मा॥**

[^462_6]: So Ch; RV 10, 81, 7 मनोजु᳓वं (Thus Ch; RV 10, 81, 7 reads मनोजु᳓वं)

उपयामगृहीतोऽसीन्द्राय त्वा विश्वकर्मण[^462_7] एष ते योनिरिन्द्राय त्वा विश्वकर्मणे॥

[^462_7]: So corr. Ch कर्माण (Thus emended; Ch reads कर्माण)

**महीमू षु मातरँ सुव्रतानामृतस्य पत्नीमवसे हुवेम।  
तुविक्षत्रामजरन्तीमुरूचीँ सुशर्माणमदितिँ सुप्रणीतम्॥**

उपयामगृहीतोऽस्यदित्यै त्वैष ते योनिरदित्यै त्वा॥ सन्ततिर्वा एते ग्रहा यथा वै शालैवँ[^463_1] संवत्सरो यथा शालायाः पक्षसी एवँ संवत्सरस्य पक्षसी यथा मध्यमो वँश एवं दिवाकीर्त्यं यदेते न गृह्येरन्विषूची संवत्सरस्य पक्षसी व्यवस्रँसेयातामार्तिमार्छेयुर्यदेते[^463_2] गृह्यन्ते यथा शालायाः पक्षसी मध्यमं वँशमभिसमायच्छन्त्येवमेवैतत्संवत्सरस्य[^463_3] पक्षसी दिवाकीर्त्यमभिसन्तन्वन्ति ते सर्वे सह[^463_4] दिवाकीर्त्ये गृह्यन्ते यथा वै मध्यमो वँश एवं दिवाकीर्त्यं यद्वै सौबलस्स्यादवशीर्येत॥ यदेते न गृह्यन्ते द्रढिम्न एवानुनद्ध्या अशिथिलत्वाय शुक्राग्रा एतदर्गृह्यन्ते त्रैष्टुभो वै शुक्रस्त्रैष्टुभमेतदहः प्रत्युत्तब्ध्यै सयत्वाय सौर्य एतदहः पशुरालभ्यते सौर्यो ग्रहो गृह्यतेऽसौ वा आदित्य एतदहस्तमेव प्रत्यक्षमृध्नुवन्ति[^463_5] षडेतदहरतिग्राह्या गृह्यन्ते पशुस्सप्तमस्सप्त प्राणा असा आदित्यश्शिरः प्रजानाँ शीर्षन्नेव प्राणान्दधाति तस्मात्सप्त शीर्षण्याः प्राणा इन्द्रो वै वृत्रँ हत्वा स इमांल्लोकानभ्यजयत्तस्यासौ लोकोऽनभिजित आसीत्तं विश्वकर्मा भूत्वाभ्यजयद्यद्वैश्वकर्मणो गृह्यतेऽमुष्य लोकस्याभिजित्यै यन्ति वा एतेऽस्माल्लोकाद्ये वैश्वकर्मणं गृह्णते पराञ्च इव ह्येते न रोहन्ति त ईश्वराः प्रमेतोरादित्यँ[^463_6] श्वो गृह्णीरन्नियमदितिरस्यामेव तेन प्रतितिष्ठन्त्या परार्धात्संवत्सरस्यान्यमन्यं गृह्णीरन्विश्वान्यन्येन कर्माणि कुर्वाणा यन्त्यस्यामन्येन प्रतितिष्ठन्ति ता उभौ सह महाव्रते गृह्येते अन्तमेवागत्योभयोर्लोकयोर्ऋृध्नुवन्ति वैश्वकर्मणेनामुष्मिन्नादित्येनास्मिन्नर्क्यमुक्थं[^463_7] भवत्यन्नं वा अर्क्यमन्नाद एव तेन प्रतितिष्ठन्ति॥५॥

[^463_1]: So corr. Ch शालैँर्ध (Thus emended; Ch reads शालैँर्ध)

[^463_2]: So corr. Ch व्यवस्रँसीयतामा॰; cf. TBr 1, 2, 3, 1. (Thus emended; Ch reads व्यवस्रँसीयतामा॰; cf. TBr 1, 2, 3, 1)

[^463_3]: So corr. Ch भिममा॰ (Thus emended; Ch reads भिममा॰)

[^463_4]: So corr. Ch मह (Thus emended; Ch reads मह)

[^463_5]: So corr. mit Caland; Ch मृब्नोवति (Thus emended with Caland; Ch reads मृब्नोवति)

[^463_6]: So corr. Ch प्रमीतोर॰ (Thus emended; Ch reads प्रमीतोर॰)

[^463_7]: So corr. Ch; मुक्तं die Ligatur र्क्य nicht ganz deutlich. (Thus emended; Ch reads मुक्तं; the ligature र्क्य is not quite clear.)
