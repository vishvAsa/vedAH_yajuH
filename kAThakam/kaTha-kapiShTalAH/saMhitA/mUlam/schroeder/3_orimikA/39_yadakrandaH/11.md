अग्निनर्ताषाट्[^592_18] क्रत्वा शचीपतिस्सौहार्द्येन[^592_19] स्वर्गो यज्ञेन मघवान्मन्युना वृत्रहा वृषभेन त्वष्टा वषट्कारेणार्धभाक् पृथिव्या स्तृणीको[^592_20]ऽन्नेन गयस्साम्ना तनूमानृग्भिरन्नादस्तपसानाधृष्टस्सूर्येण विराडृतुभिः प्राभवत्संवत्सरेण पर्यभवदभीषाट्[^593_1] चाभीषाह्यश्चाभिवयाश्चोर्ध्ववयाश्च सवयाश्च बृहद्वयाश्च सासव्हाँश्च सहीयाँश्च सहमानश्च सहस्वाँश्चाभि त्वा शूर नोनुमस्त्वामिद्वि हवामहे॥११॥ cf. TS 4, 4, 8.

[^592_18]: So corr. Ch अग्निनन्ताषाट् (Thus emended; Ch reads अग्निनन्ताषाट्)

[^592_19]: So corr. Ch सौहार्म्येन; aber cf. TS 4, 4, 8. (Thus emended Ch सौहार्म्येन; but cf. TS 4, 4, 8.)

[^592_20]: So Ch. (Thus Ch.)

[^593_1]: So corr. Ch दभीषाश्वाभीषाह्यश्चा॰ (Thus emended; Ch reads दभीषाश्वाभीषाह्यश्चा॰)
