भूमस्कृदसि वरिवस्कृदसि प्राच्यस्यूर्ध्वास्यन्तरिक्षमसि तेजोदां त्वा[^590_3] तेजसि सादयामि वर्चोदां त्वा[^590_4] वर्चसि सादयामि पयोदां त्वा पयसि सादयामि यशोदां त्वा यशसि सादयामि द्रविणोदां त्वा द्रविणे सादयामि पृथिव्यास्त्वा द्रविणे सादयाम्यन्तरिक्षस्य त्वा द्रविणे सादयामि दिवस्त्वा द्रविणे सादयामि दिशां त्वा द्रविणे सादयामि द्रविणोदां त्वा द्रविणे सादयाम्यप्सुषदसि वयस्सदसि श्येनसदसि गृध्रसदसि[^590_5] सुपर्णसदसि॥

[^590_3]: So corr. Ch तेजोदत्त्वा (Thus emended; Ch reads तेजोदत्त्वा)

[^590_4]: So corr. Ch वर्चोदत्त्वा (Thus emended; Ch reads वर्चोदत्त्वा)

[^590_5]: So corr. Ch गृद्धृ॰ (Thus emended; Ch reads गृद्धृ॰)

**या देव्यसीष्टक आयुर्दा उपशीवरी[^590_6]।  
सा मामुपशेष्व[^590_7] जायेव पतिमित्सदा॥**

[^590_6]: So corr. Ch तपसोवरो (Thus emended; Ch reads तपसोवरो)

[^590_7]: So corr. Ch पशेषु (Thus emended; Ch reads पशेषु)

या देव्यसीष्टके प्राणदा व्यानदा अपानदाश्चक्षुर्दाश्श्रोत्रदा वाग्दा आत्मदाः पृथिविदा अन्तरिक्षदा द्यौर्दास्स्वर्दाः[^590_8] कुमारीदाः प्रफर्वीदाः प्रथमौपशदा युवतिदा उपशीवरी॥ सा[^590_9] मामुपशेष्व जायेव पतिमित्सदा॥९॥ cf. MS 2, 13, 18 und 16; TS 4,4,7 und 6. (cf. MS 2, 13, 18 and 16; TS 4,4,7 and 6.)
