**यददस्सम्प्रयतीरहा अनदता[^583_8] हते।  
तस्मादा नद्यो[^583_9] नाम स्थ ता वो नामानि सिन्धवः॥**

[^583_8]: So corr. Ch अनदहता; aber cf. MS 2, 13, 1; TS 5, 6, 1, 2; AV 3, 13, 1. (Thus emended Ch अनदहता; but cf. MS 2, 13, 1; TS 5, 6, 1, 2; AV 3, 13, 1.)

[^583_9]: Ch schreibt zwei Mal nach einander नद्यो नद्यो (Ch writes two times in succession नद्यो नद्यो)

**यत्प्रेषिता वरुणेनाच्छीभँ[^583_10] समवल्गत।  
तदिन्द्र आप्नोद्यतीर्वस्तस्मादापो अनुष्ठन॥**

[^583_10]: Ch वरुणेनाश्छोभँ; vgl. AV 3, 13, 2; anders MS 2, 13, 1; TS 5, 6, 1, 2. (Ch वरुणेनाश्छोभँ; cf. AV 3, 13, 2; otherwise MS 2, 13, 1; TS 5, 6, 1, 2.)

**अपकामँ स्यन्दमाना अवीवरत[^584_1] वो हिकम्[^584_2]।  
इन्द्रो वश्शक्तिभिर्देवीस्तस्माद्वार्नाम[^584_3] वः प्रियम्॥**

[^584_1]: So corr. Ch श्रवोरवत; vgl. AV 3, 13, 3; MS 2, 13, 1; TS 5, 6, 1, 3. (Thus emended; Ch reads श्रवोरवत; cf. AV 3, 13, 3; MS 2, 13, 1; TS 5, 6, 1, 3)

[^584_2]: Vgl. TS 5, 6, 1, 3. (Cf. TS 5, 6, 1, 3)

[^584_3]: So corr. Ch र्देवो तस्माद्वान्नाम (Thus emended; Ch reads र्देवो तस्माद्वान्नाम)

**एको देवो अप्यतिष्ठत्स्यन्दमाना उपेत्य।  
उदानिषुर्महीरिति तस्मादुदकमुच्यते॥[^584_4]**

[^584_4]: Vgl. AV 3, 13, 4; MS 2, 13, 1. (Cf. AV 3, 13, 4; MS 2, 13, 1)

**आपो[^584_6] देवीर्घृतमिदाप आसन्नग्नीषोमौ बिभ्रत्याप इत्ताः।  
तीव्रा रसो मधुपृचामरङ्गम[^584_5] आ मा प्राणेन सह वर्चसागन्॥**  
** तपो योनिरस प्राजापत्यं विश्वाभिस्त्वा धीभिरुपदधामि॥[^584_7]**

[^584_6]: So corr. Ch प्राप्तः; aber vgl. oben 35, 3; MS 2, 13, 1; AV 3, 13, 5; TS 5, 6, 1, 3. (Thus emended; Ch प्राप्तः; but cf. above 35, 3; MS 2, 13, 1; AV 3, 13, 5; TS 5, 6, 1, 3.)

[^584_5]: So corr. Ch मधुप्रेचा॰; vgl. oben 35, 3; MS 2, 13, 1; AV 3, 13, 5; TS 5, 6, 1, 3. (Thus emended Ch मधुप्रेचा॰; cf. above 35, 3; MS 2, 13, 1; AV 3, 13, 5; TS 5, 6, 1, 3.)

[^584_7]: Vgl. MS 2, 13, 2. (Cf. MS 2, 13, 2)

**ये यज्ञँ समगृभ्णन्देवा देवेभ्यस्परि।  
तान्गायत्री नयतु प्रजानती स्वर्गे लोके अमृतं दुहाना॥**

**ये ज्योतीँषि सन्दधति स्वरारोहन्तो अमृतस्य लोकम्।  
ते यन्तु प्रजानन्तो यज्ञं दधानास्सुकृतस्य लोकम्॥**

**यः पन्था विततो देवयानश्छन्दोभिर्विगृहीत एति।  
तेनातिष्ठ दिवमन्तरिक्षं यज्ञं गृहीत्वा सुकृतस्य लोकम्॥**

**ये पशवो मेध्यासो यज्ञस्य योनिमभिसम्बभूवुः।  
तान्ददन्ते कवयो विपश्चितो यज्ञं दुहानास्सुकृतस्य लोके॥**

**यो यज्ञस्सहस्रधारो द्यावापृथिव्योरधि निर्मितः।  
तेनैतु यजमानस्स्वस्त्या दिवोऽधि पृष्ठमस्थात्॥**

** आयवे स्वाहायुष्कृते[^584_8] स्वाहायोः पत्मने स्वाहा विष्णवे स्वाहा बृहस्पतये स्वाहा॥**

[^584_8]: So corr. Ch स्वाहायुष्टते (Thus emended; Ch reads स्वाहायुष्टते)

**अद्धस्सम्भृतः पृथिव्या रसो विश्वकर्मणस्समवर्तताधि।  
तस्य त्वष्टा विदधद्रूपमेति तन्मर्त्यस्य देवमाजानमग्रे॥[^584_9]**

[^584_9]: Vgl. MS 2, 7, 15; VS 31, 17; TAr. 3, 13; 10, 1, 3. (Cf. MS 2, 7, 15; VS 31, 17; TAr. 3, 13; 10, 1, 3.)

त्रिवृत्ते अग्ने शिरस्तन्मे अग्ने शिरः पञ्चदशौ ते अग्ने[^585_1] बाहू तौ मे अग्ने[^585_2] बाहू सप्तदशस्त्रे अग्न आत्मा स मे अग्न आत्मैकविँशौ ते अग्न ऊरू तौ मे अग्न ऊरू त्रिणवौ ते अग्ने अष्ठीवन्तौ तौ[^585_3] मे अग्ने[^585_4] अष्ठीवन्तौ त्रयस्त्रिँशं ते अग्ने प्रतिष्ठानं तन्मे अग्ने प्रतिष्ठानं त्रिवृत्ते अग्ने शिरस्तेन माभिपाहि पञ्चदशौ ते अग्ने बाहू ताभ्यां माभिपाहि सप्तदशस्ते अग्न आत्मा तेन माभिपाह्येकविँशौ ते अग्न ऊरू ताभ्यां माभिपाहि त्रिणवौ ते अग्ने अष्ठीवन्तौ ताभ्यां माभिपाहि त्रयस्त्रिँशं ते अग्ने प्रतिष्ठानं तेन माभिपाहि॥२॥
