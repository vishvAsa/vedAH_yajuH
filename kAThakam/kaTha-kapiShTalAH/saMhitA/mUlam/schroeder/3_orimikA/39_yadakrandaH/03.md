प्रजापतिस्त्वा[^585_5] सादयतु पृथिव्याः पृष्ठे ज्योतिष्मतीं व्यचस्वतीं प्रथस्वतीं प्रथोऽसि पृथिव्यसि भूरसि भूमिरस्यदितिरसि विश्वधाया विश्वस्य भुवनस्य धर्त्री पृथिवीं यच्छ पृथिवीं दृँह पृथिवीं मा हिँसीर्विश्वस्मै प्राणाय व्यानायापानायोदानाय प्रतिष्ठायै चरित्रायाग्निष्ट्वाभिपातु मह्या स्वस्त्या छर्दिषा शन्तमेन तया देवतयाङ्गिरस्वद्ध्रुवा सीद॥

[^585_5]: Vgl. MS 4, 9, 16; VS 13, 17; TS 4, 4, 6; 4, 4, 3, 3. (Cf. MS 4, 9, 16; VS 13, 17; TS 4, 4, 6; 4, 4, 3, 3.)

**चितिं जुहोमि मनसा यथा देवा इहागमन्।  
वीतिहोत्रा ऋतावृधः॥[^585_6]  
समुद्रस्य वयुनस्य पत्मञ्जुहोमि[^585_7] विश्वकर्मणे।  
विश्वाहादाभ्यँ हविः॥**

[^585_6]: Vgl. MS 2, 10, 6; TS 5, 5, 4, 3; VS 17, 78. (Cf. MS 2, 10, 6; TS 5, 5, 4, 3; VS 17, 78)

[^585_7]: Ch schreibt पत्मन्॥ जुहोमि; im Folgenden dagegen fehlen die Versabtheilungen und sind daher von mir gesetzt; vgl. MS 2, 10, 6 a. E.; TS 5, 5, 4, 3; VS 17, 78. (Ch writes पत्मन्॥ जुहोमि; in the following on the other hand the verse divisions are missing and have therefore been set by me; cf. MS 2, 10, 6 at the end; TS 5, 5, 4, 3; VS 17, 78.)

स्वाहोदपुरा[^585_8] नामास्यन्नेन विष्टा वसवो रक्षितारोऽग्निरधि वियत्तो अस्यां तां[^585_9] त्वा प्रपद्ये सा मे शर्म च वर्म च भव तया देवतयाङ्गिरस्वद्ध्रुवा सीद ज्योतिरसि[^586_1] ज्योतिर्मे यच्छ पृथिवीं हँह पृथिव्या मा पाहि तया देवतयाङ्गिरस्वद्ध्रुवा सीद भूरसि भुवनस्य रेत इष्टका स्वर्गो लोको मनसा त्वान्वारोहामि सूरसि स्वरसीष्टका स्वर्गे लोके वाचा त्वान्वारोहामि[^586_2] यास्ते अग्न आर्द्रा[^586_3] योनयो याः कुलायिनीर्ये ते अग्न इन्दवो या उ नाभयो यास्ते अग्ने तन्व ऊर्जा नाम ताभिस्त्वमुभयीभिस्संविदानास्स्वयञ्चिन्वानास्तन्वो[^586_4] निषीद॥

[^585_8]: Vgl. MS 2, 8, 14; TS 4, 4, 5. (Cf. MS 2, 8, 14; TS 4, 4, 5)

[^585_9]: So corr. Ch ता (Thus emended; Ch reads ता)

[^586_1]: So corr. Ch ज्ज्यो° (Thus emended; Ch reads ज्ज्यो°)

[^586_2]: So corr. Ch हासि (Thus emended; Ch reads हासि)

[^586_3]: So corr. Ch आन्दा (Thus emended; Ch reads आन्दा)

[^586_4]: So corr. Ch स्वयश्चिन्वानास्त॰ (Thus emended; Ch reads स्वयश्चिन्वानास्त॰)

**मधु वाता[^586_5] ऋतायते मधु क्षरन्ति सिन्धवः।  
माध्वीर्नस्सन्त्वोषधीः॥**

[^586_5]: So corr. Ch वात; aber vgl. RV 1, 90, 6; MS 2, 7, 16; TS 4, 2, 9, 3; VS 13, 27. (Thus emended Ch वात; but cf. RV 1, 90, 6; MS 2, 7, 16; TS 4, 2, 9, 3; VS 13, 27.)

**मधु नक्तमुतोषसा मधुमत्पार्थिवं रजः।  
मधु द्योरस्तु नः पिता॥[^586_6]**

[^586_6]: Vgl. RV 1, 90, 7; zum folgenden Verse RV 1, 90, 8. (Cf. RV 1, 90, 7; to the following verse RV 1, 90, 8.)

**मधुमान्नो वनस्पतिर्मधुमाँ अस्तु सूर्यः।  
माध्वीर्गावो भवन्तु नः॥**

**सँसर्पन्त्रीन्समुद्रान्स्वर्गानपां[^586_7] पतिर्वृषभ[^586_8] इष्टकानाम्।  
तत्र गच्छ यत्र पूर्वे परेताः[^586_9] पुरीषं वसानस्सुकृतस्य[^586_10] लोकम्॥**

[^586_7]: Ch संसर्पतोन्समु॰; aber W 2 सं᳓सर्पन्त्री᳓न्समुद्रा᳓॰ ; vgl. MS 2, 7, 16; VS 13, 31. Dieser und die beiden folgenden Verse in W 2 vorhanden, doch mit so lückenhafter Accentuation, daß ich auf deren Wiedergabe verzichtet habe. (Ch संसर्पतोन्समु॰; but W 2 सं᳓सर्पन्त्री᳓न्समुद्रा᳓॰; cf. MS 2, 7, 16; VS 13, 31. This and the two following verses are present in W 2, yet with such lacunose accentuation that I have refrained from reproducing them.)

[^586_8]: W 2 पतिं᳓ वृषभं᳓ 2, 7, 16.

[^586_9]: W 2 प᳓रीताः

[^586_10]: W 2 नास्सु°; cf. aber MS 2, 7, 16. (W2 reads नास्सु°; cf., however, MS 2, 7, 16.)

**अपां गम्भीरं गच्छ मा त्वा सूर्यः परिताप्सीन्माग्निर्वैश्वानरः[^586_11]।  
अनु त्वा दिव्या वृष्टिस्सचतामखिद्राः[^586_12] प्रजा अभिविपश्य॥**

[^586_11]: So corr. Ch त्वा स्सूर्यः परेताप्सो॰; W 2 त्वा सू᳓र्यापोरिताप्सो॰; vgl. VS 13, 30. (Thus emended Ch त्वा स्सूर्यः परेताप्सो॰; W 2 त्वा सू᳓र्यापोरिताप्सो॰; cf. VS 13, 30.)

[^586_12]: Ch स्सचतासखि॰

**मही द्यौः पृथिवी च न इमं यज्ञं मिमिक्षताम्।  
पिपृतां नो भरीमभिः॥[^586_13]**

[^586_13]: Vgl. RV 1, 22, 13; MS 2, 7, 16. (Cf. RV 1, 22, 13; MS 2, 7, 16)

**स्यूता देवेभिरमृतेनागादुखा स्वसारमधि वेदिमस्थात्[^586_14]।**

[^586_14]: So corr. Ch वेधि॰; vgl. MS 2, 7, 16. (Thus emended; Ch reads वेधि॰; cf. MS 2, 7, 16)

**सत्यं पूर्वेभिर्ऋषिभिश्चाक्लृपानोऽग्निः प्रविद्वाँ इह तद्दधातु॥  
पृथिवि पृथिव्याँ सीद माता मातरि माता स्योना स्योनायाम्॥**

**क्रतुं देवानाममृतत्वमीमहे[^587_1]ऽग्निँ सधस्थे सदनेष्वच्युतम्।  
वैश्वानरं ब्रह्मणा विश्वव्यचसँ स्तोमस्य धामन्निदधे पुरीष्यम्॥**

[^587_1]: So corr. Ch क्रतुर्देवानाममतत्तमो॰; vgl. MS 2, 7, 16. (Thus emended; Ch reads क्रतुर्देवानाममतत्तमो॰; cf. MS 2, 7, 16)

**न्यधुर्मात्रया कवयो वयोधसमग्निँ सधस्थे सदनेषु सुक्रतुम्।  
वैश्वानरं ब्रह्मणा विश्वव्यचसँ स्तोमस्य धामन्न्यधां पुरीष्यम्॥[^587_2]**

[^587_2]: Vgl. MS 2, 7, 16. (Cf. MS 2, 7, 16)

**समिध्यमानँ समिधा समिन्धतेऽग्निँ सधस्थे सदनेष्वद्भुतम्।  
वैश्वानरं ब्रह्मणा विश्वव्यचसँ स्तोमस्य धामन्पवमानमाभृतम्॥**

समास्त्वाग्ने॥३॥ cf. MS 2, 7, 16; 2, 8, 14; 2, 10, 6; 4, 9, 16 etc.
