**अग्निं दीधितिभिररण्योर्हस्तच्युती जनयन्त प्रशस्तम्।  
दूरेदृशं गृहपतिमथर्युम्॥**

**तमग्रिमस्ते वसवो[^597_7] न्यृखन्सुप्रतिचक्षमवसे कुतश्चित्।  
दक्षाय्यो यो दम आस नित्यः[^597_8]॥**

[^597_7]: So corr. Ch, वमवो वसो; vgl. RV 7, 1, 2. (Thus emended; Ch reads वमवो वसो; cf. RV 7, 1, 2.)

[^597_8]: So corr. Ch दम आस निभ्यः ; vgl. RV 7, 1, 2. (Thus emended; Ch reads दम आस निभ्यः; cf. RV 7, 1, 2)

**प्रेद्वो अग्ने दीदिहि पुरो नोऽजस्रया सूर्म्या यविष्ठ।**

**त्वाँ शश्वन्त उपयन्ति वाजाः॥**

**एना वो अग्निं नमसोर्जो नपातमाहुवे।  
प्रियं चेतिष्ठमरतिँ स्वध्वरं विश्वस्य दूतममृतम्॥[^598_1]**

[^598_1]: Vgl. RV 7, 16, 1; MS 2, 13, 8; TS 4, 4, 4, 4; VS 15, 32. (Cf. RV 7, 16, 1; MS 2, 13, 8; TS 4, 4, 4, 4; VS 15, 32)

**अग्न आयाह्यग्निभिर्होतारं त्वा वृणीमहे।  
आ त्वामनक्तु प्रयता हविष्मती यजिष्ठं बर्हिरासदे॥**

**उदस्य शोचिरस्थादाजुव्हानस्य[^598_2] मीढुषः।  
उद्धूमासो अरुषासो दिविस्पृशस्समग्निमिन्धते नरः॥**

[^598_2]: So corr. Ch शुचिर॰ ; vgl. RV 7, 16, 3; TS 4, 4, 4, 5. (Thus emended; Ch reads शुचिर॰; cf. RV 7, 16, 3; TS 4, 4, 4, 5)

**अग्ने वाजस्य गोमत ईशानस्सहसो यहो।  
अस्मे धेहि जातवेदो महि श्रवः॥[^598_3] **

[^598_3]: Vgl. RV 1, 79, 4; MS 2, 13, 8; TS 4, 4, 4, 5; VS 15, 35. (Cf. RV 1, 79, 4; MS 2, 13, 8; TS 4, 4, 4, 5; VS 15, 35)

**स इधानो[^598_4] वसुष्कविरग्निरीडेन्यो[^598_5] गिरा।  
रेवदस्मभ्यं पुर्वणीक दीदिहि॥**

[^598_4]: So corr. Ch एधानो; vgl. RV 1, 79, 5; MS 2, 13, 8; TS 4, 4, 4, 5; VS 15, 36. (Thus emended; Ch reads एधानो; cf. RV 1, 79, 5; MS 2, 13, 8; TS 4, 4, 4, 5; VS 15, 36)

[^598_5]: So corr. Ch रेडेन्यो ; vgl. RV 1, 79, 5; MS 2, 13, 8 u. s. w. (Thus emended; Ch reads रेडेन्यो; cf. RV 1, 79, 5; MS 2, 13, 8, etc.)

**क्षपो राजन्नुत त्मनाग्ने वस्तोरुतोषसः।  
स तिग्मजम्भ रक्षसो दह प्रति॥[^598_6]**

[^598_6]: Vgl. RV 1, 79, 6; MS 2, 13, 8; TS 4, 4, 4, 5; VS 15, 37. (Cf. RV 1, 79, 6; MS 2, 13, 8; TS 4, 4, 4, 5; VS 15, 37)

**भद्रो नो अग्निराहुतो भद्रा रातिस्सुभग भद्रो अध्वरः।  
भद्रा उत प्रशस्तयः॥[^598_7]**

[^598_7]: Vgl. RV 8, 19, 19; MS 4, 12, 5; VS 15, 38. (Cf. RV 8, 19, 19; MS 4, 12, 5; VS 15, 38)

**यस्समिधा य आहुत्या[^598_8] यो वेदेन ददाश मर्तो अग्नये[^598_9]।  
यो नमसा स्वध्वरः॥**

[^598_8]: So Ch; vgl. RV 8, 19, 5 आ᳓हुतो (Thus Ch; cf. RV 8, 19, 5 आ᳓हुतो)

[^598_9]: So corr. Ch अग्नयो; vgl. RV 8, 19, 5. (Thus emended; Ch reads अग्नयो; cf. RV 8, 19, 5)

**तदग्ने[^598_10] द्युम्नमाभर यत्सासाहत्सदने कञ्चिदत्रिणम्।  
मन्यं जनस्य दूढ्यः॥**

[^598_10]: So corr. Ch उदग्ने; vgl. RV 8, 19, 15; in Ch öfters उ für त gesetzt. (Thus emended; Ch reads उदग्ने; cf. RV 8, 19, 15; in Ch उ is frequently put for त.)

**अग्निँ होतारं मन्ये दास्वन्तं वसुँ[^599_1] सूनुँ सहसो जातवेदसं विप्रं न जातवेदसम्।**

[^599_1]: So corr. Ch वसं (Thus emended; Ch reads वसं)

**य ऊर्ध्वया स्वध्वरो देवो देवाच्या[^599_2] कृपा।  
घृतस्य विभ्राष्टिमनुवष्टि शोचिषाजुव्हानस्य[^599_3] सर्पिषः॥**

[^599_2]: So corr. Ch देवाश्या (Thus emended; Ch reads देवाश्या)

[^599_3]: So corr. Ch जुव्हान स॰; vgl. RV 1, 127, 1; MS 2, 13, 8; TS 4, 4, 4, 8; VS 15, 47. (Thus emended; Ch reads जुव्हान स॰; cf. RV 1, 127, 1; MS 2, 13, 8; TS 4, 4, 4, 8; VS 15, 47)

**यजिष्ठं त्वा यजमाना हुवेम ज्येष्ठमङ्गिरसां विप्र मन्मभिर्विप्रेभिश्शुक्रमन्मभिः[^599_4]।  
परिज्मानमिव[^599_5] द्याँ होतारं चर्षणीनाम्।  
शोचिष्केशं वृषणं यमिमा विशः प्रावन्तु[^599_6] जूतये विशः॥**

[^599_4]: So corr. Ch मर्मभिर्विप्रोभिश्शुक्रमर्मभिः; vgl. RV 1, 127, 2 (Thus emended; Ch reads मर्मभिर्विप्रोभिश्शुक्रमर्मभिः; cf. RV 1, 127, 2)

[^599_5]: So corr. Ch परिङमान; vgl. RV 1, 127, 2. (Thus emended; Ch reads परिङमान; cf. RV 1, 127, 2)

[^599_6]: So corr. Ch विशन्प्रावर्तु; vgl. RV 1, 127, 2. (Thus emended; Ch reads विशन्प्रावर्तु; cf. RV 1, 127, 2)

**एवेन सद्यः[^599_7] पर्येषि[^599_8] पार्थिवं मुहुर्गीरितो[^599_9] वृषभः कनिक्रदद्दधद्रेतः कनिक्रदत्।  
शतं चक्षाणो[^599_10] अक्षभिर्देवो वनेषु तुर्वणिः।  
सदो दधान उपरेषु सानुष्वग्निः[^599_11] परेषु सानुषु॥**

[^599_7]: So corr. Ch मद्यः; vgl. RV 1, 128, 3. (Thus emended; Ch reads मद्यः; cf. RV 1, 128, 3)

[^599_8]: So Ch; RV 1, 128, 3 प᳓र्येति (Thus Ch; RV 1, 128, 3 reads प᳓र्येति)

[^599_9]: So Ch; vgl. RV 1, 128, 3. (Thus Ch; cf. RV 1, 128, 3.)

[^599_10]: So corr. Ch चक्षणो; vgl. RV 1, 128, 3. (Thus emended; Ch reads चक्षणो; cf. RV 1, 128, 3)

[^599_11]: So corr. Ch मानु॰ (Thus emended; Ch reads मानु॰)

**अचेत्यग्निश्चिकितिर्हव्यवाट् स सुमद्रथः[^599_12]।  
अग्निश्शुक्रेण शोचिषा बृहत्सूर्यो अरोचत॥**

[^599_12]: So corr. Ch कितिः हव्यवाट् समुद्रथः ; vgl. RV Vâl. 8, 5. (Thus emended; Ch reads कितिः हव्यवाट् समुद्रथः; cf. RV Vâl. 8, 5)

**घ्नन्मृध्राण्यप द्विषो[^599_13] दहनक्षाँसि विश्वहा।  
अग्निर्विश्वस्य राजति।[^599_14] अग्निर्विश्वं विराजति।  
अग्निस्सर्वं विराजति॥ ॥१५॥**  
cf. Mâitr. S. 2, 13, 8; TS 4, 4, 4; VS 15, 32 f lg.

[^599_14]: So corr. In Ch राजतिः श्र॰ (Thus emended in Ch राजतिः श्र॰)

**इति श्रीमद्यजुषि काठके चरकशाखायामोरिमिकायां यदक्रन्दो नामैकोनचत्वारिंशं स्थानकं सम्पूर्णम्॥[^599_15]**

[^599_15]: So die Unterschrift des Capitels in Ch. (Thus the colophon of the chapter in Ch)
