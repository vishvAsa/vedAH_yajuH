**यदक्रन्दः प्रथमं जायमान उद्यन्समुद्रादुत वा पुरीषात्।  
श्येनस्य पक्षा हरिणस्य बाहू उपस्तुत्यं[^582_4] महि जातं ते अर्वन्॥**

[^582_4]: So corr. Ch तपस्तुभ्यं; vgl. RV 1, 163, 1; in Kâṭh. selbst nur noch die Anfangsworte des Verses an zwei Stellen (40, 6; 5, 6, 3). (Thus emended; Ch reads तपस्तुभ्यं; cf. RV 1, 163, 1; in Kâṭh. itself only the opening words of the verse in two more passages (40, 6; 5, 6, 3).)

**अभ्यस्थाद्विश्वाः[^582_5] पृतना अरातीस्तदग्निराह तदु सोम आह।  
बृहस्पतिस्सवितेन्द्रस्तदाह पूषा माधात्सुकृतस्य लोके॥**

[^582_5]: So corr. Ch अभ्यस्ता॰ ; cf. TS 4, 2, 8, 1; MS 1, 5, 3; 1, 6, 2. (Thus emended; Ch reads अभ्यस्ता॰; cf. TS 4, 2, 8, 1; MS 1, 5, 3; 1, 6, 2.)

**आस्थादुदस्थादजनिष्ट विप्रो व्यास्थन्मृधो अशिशीत बाहू।  
समपृक्षि ज्योतिषा सूर्यस्य परा बाधस्व निर्ऋतिं पराचैः[^582_6]॥**

[^582_6]: Ch निनृतिम्य॰ ; kein Parallelvers. (Ch निनृतिम्य॰; no parallel verse.)

** प्रजापतिस्त्वा सादयतु॥**

**दिवो मूर्धासि पृथिव्या नाभिरूर्गपामोषधीनाम्[^582_7]।  
विश्वायुश्शर्म सप्रथा नमस्पथे वयस्स्वस्सदः[^582_8]॥**

[^582_7]: So corr. Ch नाभिऊर्ग॰ (Thus emended; Ch reads नाभिऊर्ग॰)

[^582_8]: Vgl. Kâṭh. 18, 15, wo der Vers anders abschliebt; cf. auch MS 2, 12, 3; VS 18, 54. (Cf. Kâṭh. 18, 15, where the verse concludes differently; cf. also MS 2, 12, 3; VS 18, 54.)

**प्राचीनमूर्ध्वमधरागपागुदग्देवाः[^583_1] पान्तु[^583_2] यजमानममृतमृतात्[^583_3]।  
तेन ब्रह्मणा तेन च्छन्दसा तया देवतयाङ्गिरस्वद्ध्रुवा सीद॥**

[^583_1]: So corr. Ch मूर्धाम॰ (Thus emended; Ch reads मूर्धाम॰)

[^583_2]: So corr. Ch पातु (Thus emended; Ch reads पातु)

[^583_3]: So Ch; kein Parallelvers. (Thus Ch; no parallel verse.)

**आपो रेवतीः क्षयथा हि वस्वः क्रतुं च भद्रं बिभृथामृतं च।  
रायश्च स्थ स्वपत्यस्य पत्नीस्सरस्वती तद्गृणते वयो धात्॥**

अर्थेतस्स्थान्वगतो[^583_4]ऽग्नेर्वस्तेजसा देवताभिर्गृह्णामि शर्म च स्थवर्म च स्थ देवस्य वस्सवितुः प्रसवे मधुमतीस्सादयामि ज्योतिषे वाँ शुक्रास्स्थ वीर्यावतीरिन्द्रस्य व इन्द्रियावतो देवताभिर्गृह्णाम्यमृतं च स्थ सत्यं च स्थ देवस्य वस्सवितुः प्रसवे मधुमतीस्सादयामि चक्षुषे वां मन्द्रास्स्थाभिभुवो⁵ विश्वेषां वो[^583_6] देवानां देवताभ्यो गृह्णामि रक्षोघ्नीश्च स्थारातिघ्नीश्च[^583_7] स्थ देवस्य वस्सवितुः प्रसवे मधुमतीस्सादयामि रेतसे वामधिपतिरस्यूर्जस्वानादित्यानां वो देवानां देवताभिर्गृह्णामि सपत्नघ्नीश्च स्थाभिमातिघ्नीश्च स्थ देवस्य वस्सवितुः प्रसवे मधुमतीस्सादयामि प्रजाभ्यो वां व्रजक्षितस्स्थोर्ध्वश्रितो बृहस्पतेर्वो ब्रह्मणा देवताभिर्गृह्णामि वसु च स्थ वामं च स्थ देवस्य वस्सवितुः प्रसवे मधुमतीस्सादयामि तेजसे वां क्षत्रभृतस्स्थौजस्विनीर्मित्रावरुणयोर्वो देवयोर्देवताभिर्गृह्णामि भूतं च स्थ भव्यं च स्थ देवस्य वस्सवितुः प्रसवे मधुमतीस्सादयामि वर्चसे वां दिवि श्रयस्वान्तरिक्षमापृण पृथिव्यां कल्पस्व॥१॥

[^583_4]: Ch अर्थेतस्थान्वगतो; vgl. TS 1, 8, 11, 5. So corr. Ch चक्ष्वषे वास्म॰ भूवो (Ch अर्थेतस्थान्वगतो; cf. TS 1, 8, 11, 5. Thus emended Ch चक्ष्वषे वास्म॰ भूवो)

[^583_6]: Dies वो fehlt in Ch und ist von mir ergänzt. (This वो missing in Ch, supplied by me.)

[^583_7]: So corr. Ch स्थराति॰ (Thus emended; Ch reads स्थराति॰)
