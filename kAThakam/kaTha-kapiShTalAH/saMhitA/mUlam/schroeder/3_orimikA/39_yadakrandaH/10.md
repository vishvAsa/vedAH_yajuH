**इयमेव सा या प्रथमा व्यौच्छत्सावास्वन्तश्चरति[^591_1] प्रविष्टा।  
वधूर्मिमाय नवगज्जनित्री[^591_2] त्रय एनां महिमानस्सचन्ते॥**

[^591_1]: So Ch; in MS 2, 13, 10 haben wir साप्स्वन्तश्चरति ; AV 8, 9, 11 व्यौछदास्वितरासु चरति; TS 4, 3, 11, 1 व्योच्छदन्तरस्यां चरति; keine dieser Lesungen liegt die von Ch so nahe, daß die Correctur evident wäre; vielleicht ist सा तास्व° zu lesen ? oder doch nach MS zu corrigiren? (Thus Ch; in MS 2, 13, 10 we have साप्स्वन्तश्चरति; AV 8, 9, 11 reads व्यौछदास्वितरासु चरति; TS 4, 3, 11, 1 reads व्योच्छदन्तरस्यां चरति; none of these readings is so close to that of Ch that the emendation would be obvious; perhaps सा तास्व° is to be read? or should it after all be emended after MS?)

[^591_2]: So corr. Ch जनित्रे; aber vgl. MS 2, 13, 10; TS 4, 3, 11, 1; AV 8, 9, 11. (Thus emended Ch जनित्रे; but cf. MS 2, 13, 10; TS 4, 3, 11, 1; AV 8, 9, 11.)

**छ्न्दस्वती उषसौ पेपिशाने समानं योनिमनुसञ्चरेते[^591_3]।  
सूर्यपत्नी विचरतः प्रजानती केतुमती अजरे भूरिरेतसा॥**

[^591_3]: So corr. Ch सञ्चरन्ते; MS 2, 13, 10 und AV 8, 9, 12 = Corr.; TS 4, 3, 11, 1 सञ्च᳓रन्ती; auch so liebe sich Ch leicht corrigiren. (Thus emended; Ch reads सञ्चरन्ते; MS 2, 13, 10 and AV 8, 9, 12 agree with the emendation; TS 4, 3, 11, 1 reads सञ्च᳓रन्ती; even thus Ch could easily be emended.)

**ऋतस्य पन्थामनु तिस्र आगुस्त्रयो घर्मासो अनु रेतसागुः।  
प्रजामेका रक्षत्यूर्जमेका क्षत्रमेका रक्षति देवयूनाम्॥[^591_4]**

[^591_4]: Vgl. MS 2, 13, 10; TS 4, 3, 11, 1; AV 8, 9, 13. (Cf. MS 2, 13, 10; TS 4, 3, 11, 1; AV 8, 9, 13)

**चतुष्टोममदधाद्या तुरीया यज्ञस्य पक्षा ऋषयो भवन्ती।  
गायत्री त्रिष्टुब्जगती विराडर्कं युञ्जानास्स्वराभरन्निदम्[^591_5]॥**

[^591_5]: So corr. Ch डकं य्यञ्जानास्स्व॰; vgl. MS 2, 13, 10; TS 4, 3, 11, 2; AV 8, 9, 14. (Thus emended; Ch reads डकं य्यञ्जानास्स्व॰; cf. MS 2, 13, 10; TS 4, 3, 11, 2; AV 8, 9, 14)

**पञ्चभिर्धाता विदधा इदं यत्रासाँ स्वसॄरजनन्पञ्च[^591_6] पञ्च।  
तासामु यन्ति प्रयवेण पञ्च नाना रूपाणि क्रतवो वसानाः[^591_7]॥**

[^591_6]: So corr. Ch स्वसूर॰; cf. TS 4, 3, 11, 2; anders MS 2, 13, 10. (Thus emended; Ch स्वसूर॰; cf. TS 4, 3, 11, 2; otherwise MS 2, 13, 10.)

[^591_7]: So corr. Ch वसान; cf. MS 2, 13, 10; TS 4, 3, 11, 2. (Thus emended; Ch reads वसान; cf. MS 2, 13, 10; TS 4, 3, 11, 2)

**पञ्च[^591_8] व्युष्टीरनु पञ्च दोहा गां पञ्चनाम्नीमृतवोऽनु पञ्च।  
पञ्च दिशः पञ्चदशेन कॢप्तास्समानमूर्ध्नीरभि लोकमेकम्॥**

[^591_8]: Hier beginnt ein Fragment in W 2, einige Verse mit unvollkommener Accentuation, auf deren Wiedergabe ich verzichtet habe; cf. oben 26, 11; MS 2, 13, 10; TS 4, 3, 11, 4; AV 8, 4, 15. (Here begins a fragment in W 2, several verses with imperfect accentuation, which I have refrained from reproducing; cf. above 26, 11; MS 2, 13, 10; TS 4, 3, 11, 4; AV 8, 4, 15.)

**ज्योतिष्मती प्रतिमुञ्चते नभ उषा देवी सूर्यस्य[^591_9] व्रतेन।  
विपश्यन्ति पशवो[^591_10] जायमाना नानारूपा मातुरस्या उपस्थे॥**

[^591_9]: So W 2; in Ch देवीस्सूर्यस्य; cf. MS 2, 13, 10; TS 4, 3, 11, 3. (Thus W2; in Ch देवीस्सूर्यस्य; cf. MS 2, 13, 10; TS 4, 3, 11, 3.)

[^591_10]: W 2 प्रथ᳓मो

**त्रिँशत्स्वसार उपयन्ति निष्कृतँ समानं केतुं प्रतिमुञ्चमानाः।  
ऋतूँस्तन्वते[^591_11] कवयः प्रजानतीर्मध्येछन्दसः[^591_12] परियन्ति भास्वतीः॥**

[^591_11]: So W 2; in Ch तन्वती; vgl. MS 2, 13, 10; TS 4, 3, 11, 3. (Thus W2; in Ch तन्वती; cf. MS 2, 13, 10; TS 4, 3, 11, 3.)

[^591_12]: So Ch; in W 2 मध्यच्छ॰ (Thus Ch; in W 2 मध्यच्छ॰)

**शुक्रर्षभा नभसा ज्योतिषागाद्विश्वरूपा शवल्यग्निकेतुः[^592_1]।  
समानमँर्थ स्वपस्यमाना[^592_2] बिभ्रती जरामजर[^592_3] उष आगाः॥**

[^592_1]: So Ch; in W 2 Lücke; vgl. TS 4, 3, 11, 5 शबली᳓र॰ (Thus Ch; in W 2 lacuna; cf. TS 4, 3, 11, 5 शबली᳓र॰)

[^592_2]: So corr. Ch स्वसस्यमाना; W 2 नमहस्तपस्यमाना; vgl. TS 4, 3, 11, 5. (Thus emended Ch स्वसस्यमाना; W 2 नमहस्तपस्यमाना; cf. TS 4, 3, 11, 5.)

[^592_3]: So corr. Ch ज्जरामज्जर॰ W 2 जराम उष (Thus emended Ch ज्जरामज्जर॰ W2 जराम उष)

**ऋतूनां पत्नी प्रथमेयमागादूहां नेत्री जनित्री[^592_4] प्रजानाम्।  
एका सती बहुधोषो[^592_5] व्युच्छाजीर्णा त्वं जरय सर्वमन्यत्॥**

[^592_4]: So corr. Ch जनित्रे; vgl. MS 2, 13, 10; TS 4, 3, 11, 5. (Thus emended; Ch reads जनित्रे; cf. MS 2, 13, 10; TS 4, 3, 11, 5)

[^592_5]: So corr. Ch धोषु (Thus emended; Ch reads धोषु)

**ऋतस्य धाम प्रथमा व्यूषुष्यपामेका[^592_6] महिमानं बिभर्ति।  
सूर्यस्यैका चरति निष्कृतानि धर्मस्यैका सवितैकां नियच्छते[^592_7]॥**

[^592_6]: So corr. Ch व्युषु॰ ; vgl. MS 2, 13, 10; TS 4, 3, 11, 5. (Thus emended; Ch reads व्युषु॰; cf. MS 2, 13, 10; TS 4, 3, 11, 5)

[^592_7]: Ch कान्निय॰

**एकाष्टका तपसा तप्यमाना जजान गर्भ महिमानमिन्द्रम्।  
तेन दस्यून्व्यसहन्त देवा हन्तासुराणामभवच्छचीभिः॥[^592_8]**

[^592_8]: Vgl. TS 4, 3, 11, 3. (Cf. TS 4, 3, 11, 3)

**अनानुजामनुजां मामकर्त[^592_9] सत्यं वदन्त्यनुयच्छ एतत्।  
भूयासमस्य सुमतौ यथा यूयमन्या वो[^592_10] अन्यामति मा प्रयुक्त[^592_11]॥**

[^592_9]: So corr. Ch जाममकन्त; W 2 मामकन्त; vgl. TS 4, 3, 11, 3. (Thus emended Ch जाममकन्त; W 2 मामकन्त; cf. TS 4, 3, 11, 3.)

[^592_10]: So W 2; in Ch नो (Thus W2; in Ch नो)

[^592_11]: W 2 मां प्रयुक्तः

**अभून्नु नस्सुमतौ विश्ववेदा आष्ट[^592_12] प्रतिष्ठामविदन्नु[^592_13] गाधम्।  
भूयासमस्य सुमतौ यथा यूयमन्या वो[^592_14] अन्यामति मा प्रयुक्त॥**

[^592_12]: So corr. nach Anleitung von TS 4, 3, 11, 4. Ch schreibt आष्ठाः (Thus emended following TS 4, 3, 11, 4. Ch writes आष्ठाः)

[^592_13]: So corr, Ch मविदे नु; W 2 hier nicht mehr vorhanden; TS 4, 3, 11, 4 म᳓विदद्धि᳓ (Thus emended;, Ch मविदे नु; W2 no longer present here; TS 4, 3, 11, 4 म᳓विदद्धि᳓)

[^592_14]: So corr. Ch नो (Thus emended; Ch reads नो)

**प्रथमा ह व्युवास[^592_15] सा धेनुरभवद्यमे।  
सा नः पयस्वती दुहामुत्तरामुत्तराँ[^592_16] समाम्॥ ॥१०॥[^592_17]**

[^592_15]: So corr. Ch व्यवास; vgl. MS 2, 13, 10 a. E.; TS 4, 3, 11, 5. (Thus emended Ch व्यवास; cf. MS 2, 13, 10 at the end; TS 4, 3, 11, 5.)

[^592_16]: Ch मुत्तरामुत्तरा

[^592_17]: So corr. Ch ॥99॥ (Thus emended Ch ॥99॥)
