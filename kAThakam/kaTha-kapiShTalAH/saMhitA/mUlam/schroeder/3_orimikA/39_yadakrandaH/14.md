**अग्निर्मूर्धायमग्निस्त्वामग्ने पुष्करादधि॥**

**हुवे वस्सुद्योत्मानँ सुवृक्तिं विशामग्निमतिथिँ सुप्रयसम्[^596_7]।  
मित्र इव यो दिधिषाय्यो भूद्देव आदेवे जने जातवेदाः॥**

[^596_7]: So corr. Ch सुप्रयासम्; aber vgl. RV 2, 4, 1. (Thus emended Ch सुप्रयासम्; but cf. RV 2, 4, 1.)

**पुरो वो मन्द्रं दिव्यँ सुवृक्तिं प्रयति यज्ञे अग्रिमध्वरे दधिध्वम्।  
पुर उक्थेभिस्स[^596_8] हि नो विभावा स्वध्वरा करति जातवेदाः॥**

[^596_8]: So corr. Ch उक्तेभि॰; vgl. RV 6, 10, 1. (Thus emended; Ch reads उक्तेभि॰; cf. RV 6, 10, 1)

**का त आकूतिर्मनसो वराय भुवदग्ने शन्तमा[^596_9] का मनीषा।  
को वा यज्ञैः परि दक्षं त आप केन वा ते मनसा दाशेम[^596_10]॥**

[^596_9]: So corr. Ch शन्तसा ; vgl. RV 1, 76, 1. (Thus emended; Ch reads शन्तसा; cf. RV 1, 76, 1)

[^596_10]: Erste Hand in Ch दशेम (First hand in Ch दशेम)

**जनस्य गोपा अजनिष्ट जागृविरग्निस्सुदक्षस्सुविताय नव्यसे।  
घृतप्रतीको बृहता दिविस्पृशा द्युमद्विभाति भरतेभ्यश्शुचिः[^596_11]॥**

[^596_11]: So corr. Ch भरतेद्यश्श्रु॰; vgl. RV 5, 11, 1; MS 2, 13, 7; TS 4, 4, 4, 2; VS 15, 27. (Thus emended; Ch reads भरतेद्यश्श्रु॰; cf. RV 5, 11, 1; MS 2, 13, 7; TS 4, 4, 4, 2; VS 15, 27)

**त्वामग्ने अङ्गिरसो गुहा हितमन्वविन्दञ्छिश्रियाणं[^597_1] वने वने।  
स जायसे मथ्यमानस्सहो महत्त्वामाहुस्सहसस्पुत्रमङ्गिरः[^597_2]॥**

[^597_1]: So corr. Ch यानं; vgl. RV 5, 11, 6; MS. 2, 13, 7; TS 4, 4, 4, 3; VS 15, 28. (Thus emended; Ch reads यानं; cf. RV 5, 11, 6; MS. 2, 13, 7; TS 4, 4, 4, 3; VS 15, 28)

[^597_2]: So corr. Ch स जायते पन्थ्यमानस्सहो महान्त्त्वामाहुस्सहस्रं पु॰; vgl. RV 5, 11, 6; MS 2, 3, 7 u. s. w. (Thus emended; Ch reads स जायते पन्थ्यमानस्सहो महान्त्त्वामाहुस्सहस्रं पु॰; cf. RV 5, 11, 6; MS 2, 3, 7, etc.)

**यज्ञस्य केतुं प्रथमं पुरोहितमग्निं नरस्त्रिषधस्थे समीधिरे।  
इन्द्रेण देवैस्सरथं स बर्हिषि सीदन्नि होता यजथाय सुक्रतुः॥[^597_3]**

[^597_3]: Vgl. RV 5, 11, 2. (Cf. RV 5, 11, 2)

**त्वामग्ने हविष्मन्तो देवं मर्तास ईडते।  
मन्ये त्वा जातवेदसँ स हव्या वक्ष्यानुषक्[^597_4]॥**

[^597_4]: So corr. Ch म हव्या वक्षानुषक; vgl. RV 5, 9, 1. (Thus emended; Ch reads म हव्या वक्षानुषक; cf. RV 5, 9, 1)

**त्वां चित्रश्रवस्तम हवन्ते विक्षु जन्तवः।  
शोचिष्केशं पुरुप्रियाग्ने हव्याय वोढवे॥**

**यद्वाहिष्ठं तदग्नये बृहदर्च विभावसो।  
महिषीव त्वद्रयिस्त्वद्वाजा[^597_5] उदीरते॥  
आ ते अन इधीमहि॥**

[^597_5]: So corr. Ch त्वदद्रियस्त्वद्वाजा; vgl. RV 5, 6, 4. (Thus emended; Ch reads त्वदद्रियस्त्वद्वाजा; cf. RV 5, 6, 4)

**आ ते अग्न ऋचा हविश्शुक्रस्य शोचिषस्पते।  
सुश्चन्द्र[^597_6] दस्म विश्पते हव्यवाट् तुभ्यँ हूयत इषँ स्तोतृभ्य आभर॥**

[^597_6]: So corr. Ch मश्वन्द्र; vgl. RV 5, 6, 5. (Thus emended; Ch reads मश्वन्द्र; cf. RV 5, 6, 5)

**अग्निं तं मन्ये यो वसुरस्तं यं यन्ति धेनवः।  
अस्तमर्वन्त आशवोऽस्तं नित्यासो वाजिन इषँ स्तोतृभ्य आभर॥ ॥१४॥  
cf. Mâitr. S. 2, 13, 7; TS 4, 4, 4; VS 15, 20 flg.** (cf. Mâitr. S. 2, 13, 7; TS 4, 4, 4; VS 15, 20 ff.)
