**यो अप्स्वन्तरग्निर्यो वृत्रे यः पुरुषे यो[^601_4] अश्मनि।  
य आविवेश भुवनानि विश्वा तेभ्यो अग्निभ्यो हुतमस्त्वेतत्॥**

[^601_4]: So corr. Ch ये ; vgl. MS 2, 13, 13. (Thus emended; Ch reads ये; cf. MS 2, 13, 13)

**पृष्टो दिवि पृष्टो अग्निः पृथिव्यां[^601_5] पृष्टो विश्वा ओषधीराविवेश।  
वैश्वानरस्सहसा पृष्टो अग्निस्स नो दिवा स रिषः पातु नक्तम्॥**

[^601_5]: So corr. Ch पृथिव्यास्पृष्टो, vgl. oben 4, 16; MS 2, 13, 11; RV 1, 98, 2. (Thus emended Ch पृथिव्यास्पृष्टो, cf. above 4, 16; MS 2, 13, 11; RV 1, 98, 2.)

**यस्तोमे अन्तर्यो गोष्वन्तर्वयाँसि[^601_6] य आविवेश यो मृगेषु।  
य आविवेश द्विपदो यश्चतुष्पदस्तेभ्यो[^601_7] अग्निभ्यो हुतमस्त्वेतत्॥**

[^601_6]: So corr. Ch गेष्वं॰ ; vgl. MS 2, 13, 13; AV 3, 21, 2. (Thus emended; Ch reads गेष्वं॰; cf. MS 2, 13, 13; AV 3, 21, 2)

[^601_7]: So corr. Ch याञ्चतु°; vgl. MS 2, 13, 13; AV 3, 21, 2. (Thus emended; Ch reads याञ्चतु°; cf. MS 2, 13, 13; AV 3, 21, 2)

विश्वकर्मा त्वा सादयत्वन्तरिक्षस्य पृष्ठे ज्योतिष्मतीमन्तरिक्षं यछान्तरिक्षं दृँहान्तरिक्षं मा हिँसीर्विश्वस्मै प्राणाय व्यानायापानायोदानाय प्रतिष्ठायै चरित्राय वायुष्ट्वाभिपातु मह्या स्वस्त्या छर्दिषा शन्तमेन तया देवतयाङ्गिरस्वद्ध्रुवा सीदान्तरिक्षमधिद्यौर्ब्रह्मणा विष्टं रुद्रा रक्षितारो वायुरधिवियत्तो अस्यां तां त्वा[^601_8] प्रपद्ये सा मे शर्म च वर्म च भव तया देवतयाङ्गिरस्वद्ध्रुवा सीद तेजोऽसि तेजो मे यच्छान्तरिक्षं दृँहान्तरिक्षं मा पाहि तया देवतयाङ्गिरस्वद्ध्रुवा सीद॥

[^601_8]: Erste Hand in Ch तत्त्वा; dann corr, in तात्वा ; vgl. TS 4, 4, 5, 1 and 2. (First hand in Ch reads तत्त्वा; then emended to तात्वा; cf. TS 4, 4, 5, 1 and 2.)

**हुतादमग्निं[^601_9] यमु काममाहुर्यं दातारं प्रतिग्रहीतारमाहुः।  
यं जोहवीमि[^601_10] पृतनासु सासहिं तेभ्यो अग्निभ्यो हुतमस्त्वेतत्॥**

[^601_9]: Ch यो हुताद॰ ; das यो ist von mirgestrichen; vgl. MS 2, 13, 13 विश्वा᳓दम॰ (Ch यो हुताद॰; the यो has been deleted by me; cf. MS 2, 13, 13 विश्वा᳓दम॰)

[^601_10]: So corr. Ch माहु यं ज्योहवीँषि vgl. MS 2, 13, 13 a. E. (Thus emended Ch माहु यं ज्योहवीँषि cf. MS 2, 13, 13 at the end.)

**येनेन्द्रस्य रथँ सम्बभूवुर्वैश्वानर उत विश्वदाव्यः।  
धीरो यश्शक्रः परिभूरदाभ्यस्तेभ्यो[^602_1] अग्निभ्यो हुतमस्त्वेतत्॥**

[^602_1]: So corr. Ch यश्चक्रः परिभूरिदाभ्य॰; vgl. MS 2, 13, 13. (Thus emended; Ch reads यश्चक्रः परिभूरिदाभ्य॰; cf. MS 2, 13, 13)

वेदिरसि सुधां मे धेहि वरुणस्य कुक्षी स्थो मा मा सन्ताप्तं तार्क्ष्यरिष्टनेमेऽभि मा सच स्वस्त्या छर्दिषा शन्तमेन नमोऽग्नेर्वैश्वानरस्य हरसे नमश्शरवे त्रायमाण त्रायस्व नो हन्तरधि नो ब्रूहि॥

**वर्च आधायि मे तनूस्सह ओजो महद्बलम्।  
त्रयस्त्रिँशद्वीर्याणि तान्यग्निः प्रददातु मे॥**

**आ मा वर्चोऽग्निना दत्तमेतु महि राधस्मह ओजो महद्बलम्।  
दीर्घायुत्वाय शतशारदाय प्रतिगृह्णामि महत इन्द्रियाय॥**

**अग्ने दुधाग्ने[^602_2] ह्या किँशिलाग्ने वन्याग्ने कक्ष्य या त इषुर्युवा  
नाम तस्यै ते विधेम तया नः पाहि तस्यै ते स्वाहा॥३॥**  
cf. Mâitr. S. 2, 13, 13; TS 4, 4, 5; 5, 5, 9, 1.

[^602_2]: So Ch; vgl. in TS 5, 5, 9, 1 गह्य (Thus Ch; cf. in TS 5, 5, 9, 1 गह्य)
