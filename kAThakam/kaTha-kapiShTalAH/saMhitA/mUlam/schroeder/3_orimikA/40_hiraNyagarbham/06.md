पिता मातरिश्वाच्छिद्रा पदा धादच्छिद्रोशिजः कवयः पदानुतक्षिषुस्सोमो[^604_6] विश्वविन्नेता नेषद्बृहस्पतिरुक्थामदानि[^604_7] शँसिषत्॥ यदक्रन्दः॥

[^604_6]: So Calands Correctur ; Ch नितक्षिष्वत्सोमो; TS 5, 6, 86 पदा᳓नुतक्षः सो᳓मो (Thus Caland's emendation; Ch reads नितक्षिष्वत्सोमो; TS 5, 6, 86 reads पदा᳓नुतक्षः सो᳓मो)

[^604_7]: So corr. Ch रुक्तासदानि; vgl. TS 5, 6, 8, 6. 8 So (Thus emended; Ch reads रुक्तासदानि; cf. TS 5, 6, 8, 6. 8; thus)

**यमेन दत्तं त्रित एनमायुनगिन्द्र एनं प्रथमो अध्यतिष्ठत्।  
गन्धर्वो अस्य रशनामगृभ्णात्सूरादश्वं वसवो निरतष्ट[^604_8]॥**

[^604_8]: So corr. Ch निरतिष्ठ᳓; vgl. RV 1, 163, 2; TS 4, 6, 7, 1. (Thus emended; Ch reads निरतिष्ठ᳓; cf. RV 1, 163, 2; TS 4, 6, 7, 1)

**असि[^604_9] यमो अस्यादित्यो अर्वन्नसि चितो गुह्येन व्रतेन।  
असि सोमेन समया विपृक्त[^604_10] आहुस्ते त्रीणि दिवि बन्धनानि॥**

[^604_9]: So corr. Ch अस्य ; vgl. RV 1, 163, 3; TS 4, 6, 7, 1. (Thus emended; Ch reads अस्य; cf. RV 1, 163, 3; TS 4, 6, 7, 1)

[^604_10]: So corr. Ch विपृक्ता ; vgl. RV 1, 163, 3; TS 4, 6, 7, 1. (Thus emended; Ch reads विपृक्ता; cf. RV 1, 163, 3; TS 4, 6, 7, 1)

**त्रीणि त आहुर्दिवि बन्धनानि त्रीण्यप्सु त्रीण्यन्तस्समुद्रे।**

**उतेव मे वरुणश्छन्त्स्यर्वन्यत्रा[^605_1] त आहुः परमं जनित्रम्॥**

[^605_1]: So corr. Ch वरुणश्छन्दा ; vgl. aber RV 1, 163, 4; TS 4, 6, 7, 2; VS 29, 15. (Thus emended; Ch reads वरुणश्छन्दा; cf. however RV 1, 163, 4; TS 4, 6, 7, 2; VS 29, 15.)

**इमा ते वाजिन्नवमार्जनानीमा शफनाँ[^605_2] सवितुर्निधाना[^605_3]।  
अत्रा ते भद्रा वृषणा[^605_4] अगृभ्णामृतस्य या अभिरक्षन्ति गोपाः॥**

[^605_2]: So corr. Ch शप्तानाँ; vgl. RV 1, 163, 5; TS 4, 6, 7, 2; VS 29, 16. (Thus emended; Ch reads शप्तानाँ; cf. RV 1, 163, 5; TS 4, 6, 7, 2; VS 29, 16)

[^605_3]: So Ch ! vgl. RV 1, 163, 5 सनितु᳓नि॰ ; desgl. TS 4, 6, 7, 2; VS 29, 16. (Thus Ch ! cf. RV 1, 163, 5 सनितु᳓नि॰; likewise TS 4, 6, 7, 2; VS 29, 16.)

[^605_4]: So Ch; vgl. RV 1, 163, 5 रशना; desgl. TS 4, 6, 7, 2; VS 29, 16. (Thus Ch; cf. RV 1, 163, 5 रशना; likewise TS 4, 6, 7, 2; VS 29, 16.)

संवत्सरोऽसि परिवत्सरोऽसीदावत्सरो[^605_5]ऽस्यनुवत्सरोऽस्युत्सरोऽसि देवस्य त्वा सवितुः प्रसवेऽश्विनोर्बाहुभ्यां पूष्णो हस्ताभ्यामिन्द्रवन्तं त्वा सादयामि धामच्छदसि स्वे योनौ सीद स्वे पृथिव्या योनौ सीदर्तवस्ते[^605_6] कल्पन्तां मासास्ते कल्पन्तामर्धमासास्ते कल्पन्तामहोरात्राणि ते कल्पन्तामङ्गानि ते कल्पन्तां परूँषि ते कल्पन्ताँ शरीराणि ते कल्पन्तामेत्या प्रेत्या सं चा च प्र च सारयाग्निर्ज्योतिर्ज्योतिरग्निरिन्द्रो ज्योतिर्ज्योतिरिन्द्रस्सूर्यो ज्योतिर्ज्योतिस्सूर्यः॥

[^605_5]: So corr. Ch परिवत्सरं सोदव॰ (Thus emended; Ch reads परिवत्सरं सोदव॰)

**इमँ स्तनमूर्जस्वन्तं धयापां प्रपीनमग्ने[^605_7] सरिरस्य मध्ये।  
उत्सं जुषस्व मधुमन्तमूर्मिँ समुद्रियँ सदनमाविशस्व॥॥६॥**
