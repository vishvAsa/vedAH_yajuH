**समुद्रादूर्मिर्मधुमाँ उदारदुपाँशुना सममृतत्वमानट्[^605_8]।  
घृतस्य नाम गुह्यं यदस्ति जिव्हा देवानाममृतस्य नाभिः॥**

[^605_8]: So corr. Ch मानाट् ; vgl. RV 4, 58, 1; MS 1, 6, 2. (Thus emended; Ch reads मानाट्; cf. RV 4, 58, 1; MS 1, 6, 2)

**वयं नाम प्रब्रवाम[^605_9] घृतस्यास्मिन्यज्ञे धारयामा नमोभिः।  
उप ब्रह्मा शृणवच्छस्यमानं[^605_10] चतुश्शृङ्गोऽवमीद्गौर[^605_11] एतत्॥**

[^605_9]: So corr. Ch प्रववाम; vgl. RV 4, 58, 2 प्र᳓ब्रवामा; auch MS 1, 6, 2. (Thus emended; Ch reads प्रववाम; cf. RV 4, 58, 2 reads प्र᳓ब्रवामा; also MS 1, 6, 2.)

[^605_10]: So corr. Ch शृणुवछस्य॰; vgl. RV 4, 58, 2; MS 1,6, 2. (Thus emended; Ch reads शृणुवछस्य॰; cf. RV 4, 58, 2; MS 1,6, 2)

[^605_11]: So corr. Ch वमेद्गौर vgl. RV 4, 58, 2. (Thus emended Ch वमेद्गौर; cf. RV 4, 58, 2.)

**चत्वारि शृङ्गा त्रयो अस्य पादा द्वे शीर्षे सप्त हस्तासो अस्य।  
त्रिधा बद्धो वृषभो रोरवीति[^605_12] महो देवो मर्त्याँ आविवेश॥**

[^605_12]: So corr. Ch रोरवीति ; vgl. RV 4, 58, 3; MS 1,6, 2. (Thus emended; Ch reads रोरवीति; cf. RV 4, 58, 3; MS 1,6, 2)

**त्रिधा हितं पणिभिर्गुह्यमानं[^606_1] गवि[^606_2] देवासो घृतमन्वविन्दन्।  
इन्द्र एकँ सूर एकं जजान वेनादेकँ स्वधया निष्टतक्षुः॥**

[^606_1]: So corr. Ch पाणि॰; vgl. RV 4, 58, 4. (Thus emended; Ch reads पाणि॰; cf. RV 4, 58, 4)

[^606_2]: So corr. Ch गवे; vgl. RV 4, 58, 4. (Thus emended; Ch reads गवे; cf. RV 4, 58, 4)

**एता अर्षन्ति हृद्यात्समुद्राच्छतव्रजा रिपुणा नावचक्षे[^606_3]।  
घृतस्य धारा अभिचाकशीमि हिरण्ययो वेतसो मध्य आसाम्॥**

[^606_3]: So corr. Ch नवचक्षि; vgl. RV 4, 58, 5. (Thus emended; Ch reads नवचक्षि; cf. RV 4, 58, 5)

**सम्यक्स्रवन्ति सरितो न धेना अन्तर्हृदा मनसा पूयमानाः।  
एते अर्षन्त्यूर्मयो घृतस्य मृगा इव क्षिपणोरीषमाणाः॥**

**सिन्धोरिव प्राध्वने शूघनासो वातप्रमियः पतयन्ति यव्हाः।  
घृतस्य धारा अरुषो न वाजी काष्ठा भिन्दन्नूर्मिभिः पिन्वमानः॥**

**अभि प्रवन्त समनेव योषाः कल्याण्यस्स्मयमानासो[^606_4] अग्निम्।  
घृतस्य धारास्समिधो नसन्त ता जुषाणो हर्यति जातवेदाः॥**

[^606_4]: So corr. Ch कल्याणस्म्मय॰; vgl. RV 4, 58, 8. (Thus emended; Ch reads कल्याणस्म्मय॰; cf. RV 4, 58, 8)

**कन्या इव वहतुमेतवा उ अञ्ज्यञ्जाना अभिचाकशीमि।  
यत्र सोमस्तूयते यत्र यज्ञो घृतस्य धारा अभि तत्पवन्ते॥**

**अभ्यर्षत सुष्टुतिं गव्यमाजिमस्मासु भद्रा द्रविणानि धत्त।  
इमं यज्ञं नयत देवता नो घृतस्य धारा मधुमत्पवन्ते॥**

**धामन्ते विश्वं भुवनमधिश्रितमन्तस्समुद्रे हृद्यन्तरायुषि।  
अपामनीके समिथे य आभृतस्तमश्याम मधुमन्तं त ऊर्मिम्॥ ॥७॥**

**cf. RV 4, 58.**
