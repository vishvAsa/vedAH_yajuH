**यदाकूतात्समसुस्रोद्धृदो[^611_4] वा मनसस्सम्भृतं चक्षुषो वा।  
तमनुप्रेहि सुकृतस्य लोकं यत्रर्षयो जग्मुः प्रथमाः पुराणाः॥**

[^611_4]: So corr. Ch समसुस्रुधृदो; vgl. TS 5, 7, 7, 1. (Thus emended; Ch reads समसुस्रुधृदो; cf. TS 5, 7, 7, 1)

**एतँ[^611_5] सधस्थाः परि वो ददामि यमावहाच्छेवधिं[^611_6] जातवेदाः।  
अन्वागन्ता यजमानस्स्वस्ति तँ स्म जानीत परमे व्योमन॥**

[^611_5]: So corr. Ch एताँ; vgl. TS 5, 7, 7, 1. (Thus emended; Ch reads एताँ; cf. TS 5, 7, 7, 1)

[^611_6]: So corr. Ch श्छेवधिं (Thus emended; Ch reads श्छेवधिं)

**एतं जानीत परमे व्योमन्नग्ने सधस्था[^611_7] विद लोकमस्य।  
यदागच्छात्पथिभिर्देवयानैरिष्टापूर्तं कृणुतादाविरस्मै॥  
इमँ स्तनमिष्टो यज्ञः॥**

[^611_7]: So corr. Ch साधस्था; vgl. TS 5, 7, 7, 1; vgl. auch den vorausgehenden Vers. (Thus emended; Ch reads साधस्था; cf. TS 5, 7, 7, 1; cf. also the preceding verse.)

**येन सहस्रं वहसि येनाग्ने सर्ववेदसम्[^611_8]।  
तेनेमं यज्ञं नो वह स्वर्देवेषु गन्तवे॥**

[^611_8]: So corr. Ch सर्वसम्; vgl. oben 18, 18; TS 5, 7, 7, 3; MS 2, 12, 4; VS 15, 55; 18, 62. (Thus emended Ch सर्वसम्; cf. above 18, 18; TS 5, 7, 7, 3; MS 2, 12, 4; VS 15, 55; 18, 62.)

**येनाग्ने सुकृतः पथा मधोर्धारा व्यानशुः।  
तेनेमं यज्ञं नो[^611_9] नय[^611_10] स्वर्देवेषु गन्तवे॥**

[^611_9]: So corr. Ch यज्ञकु; vgl. TS 5, 7, 7, 3 = Corr. (Thus emended; Ch reads यज्ञकु; cf. TS 5, 7, 7, 3, which agrees with the emendation)

[^611_10]: So Ch; vgl. TS 5, 7, 7, 3 auch hier वह (Thus Ch; cf. TS 5, 7, 7, 3 here too वह)

**येनाग्ने दक्षिणावन्तं यज्ञं वहन्त्यृत्विजः।  
तेनेमं यज्ञं नो वह स्वर्देवेषु गन्तवे॥[^612_1]**

[^612_1]: Vgl. TS 5, 7, 7, 3. (Cf. TS 5, 7, 7, 3)

**प्रस्तरेण परिधिना स्रुचा वेद्या च बर्हिषा।  
ऋचेमं यज्ञं नो नय स्वर्देवेषु गन्तवे॥[^612_2]**

[^612_2]: Vgl. TS 5, 7, 7, 2. (Cf. TS 5, 7, 7, 2)

**यत्र धारा मधुमतीस्सदा स्यन्दन्ते अक्षिताः।  
तदग्निर्वैश्वकर्मणस्स्वर्देवेषु नो दधत्॥**

**अपूपकूला नद्यस्सदा स्यन्दन्ते[^612_3] अक्षिताः।  
तदग्निर्वैश्वकर्मणस्स्वर्देवेषु नो दधत्॥**

[^612_3]: So corr. Ch स्यन्दन्त; vgl. den folgenden Vers; cf. auch TS 5, 7, 7, 3. (Thus emended; Ch reads स्यन्दन्त; cf. the following verse; cf. also TS 5, 7, 7, 3.)

**उपक्षरन्ति मधुनो घृतस्य कुल्याः पूर्णास्तदमक्षीयमाणाः।  
तदग्निर्वैश्वकर्मणस्स्वर्देवेषु नो दधत्॥  
यास्ते अग्ने या वो देवाः॥**

**रोचय मा ब्राह्मणेष्वथो राजसु रोचय।  
रोचय मा विश्येषु शूद्रेषु मयि धेहि रुचा रुचम्॥**

स्वर्णघर्मस्स्वाहा स्वर्णशुक्रस्स्वाहा स्वर्णसूर्यस्स्वाहा स्वर्णार्कस्स्वाहा स्वर्णाग्निस्स्वाहा॥ ॥१३॥ cf. TS 5, 7, 7.
