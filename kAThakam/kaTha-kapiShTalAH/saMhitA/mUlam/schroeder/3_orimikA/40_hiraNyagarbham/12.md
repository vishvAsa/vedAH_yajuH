हव्यं प्रीणीहि हव्यँ श्रीणीहि हव्यँ श्रपय॥ हव्यं पच हव्यमसि हव्याय त्वा हव्यवाडसि हव्ये सीद॥

**स्वयं कृण्वाणस्सुगमप्रयावं तिग्मशृङ्गो वृषभश्शोशुचानः।  
प्रत्नँ सधस्थमनुपश्यमान आ तन्तुमग्निर्दिव्यं[^610_12] ततान[^610_13]॥**

[^610_12]: So corr. Ch ग्निन्दिव्यं ; vgl. MS 2, 13, 22 a. A .; TBr 2, 4, 2, 5. (Thus emended; Ch reads ग्निन्दिव्यं; cf. MS 2, 13, 22 at the beginning; TBr 2, 4, 2, 5.)

[^610_13]: So corr. Ch ततानि; vgl. MS 2, 13, 22. A. ; TBr. 2, 4, 2, 5. (Thus emended; Ch reads ततानि; cf. MS 2, 13, 22 at the beginning; TBr. 2, 4, 2, 5.)

**त्वं नस्तन्तुरुत सेतुरग्ने त्वं पन्था भवसि देवयानः।  
त्वयाग्ने पृष्ठं वयमारुहेमाथा देवैस्सधमादं[^611_1] मदेम॥**

[^611_1]: So corr. Ch सदमाद; vgl. MS 2, 13, 22; TBr. 2, 4, 2, 6. (Thus emended; Ch reads सदमाद; cf. MS 2, 13, 22; TBr. 2, 4, 2, 6)

**अतिसर्गं ददतो मानवाय स्वर्गं पन्थामनुपश्यमानाः[^611_2]।  
अजुषन्त मरुतो यज्ञमेतं वृष्टिद्यावानममृतँ स्वर्विदम्॥**

[^611_2]: So corr. Ch मानः; vgl. MS 2, 13, 22. (Thus emended; Ch reads मानः; cf. MS 2, 13, 22)

**आवर्तमानो भुवनस्य मध्ये प्रजा विकृण्वञ्जनयन्विरूपम्[^611_3]।  
संवत्सरः परमेष्ठी धृतव्रतो यज्ञं नः पातु रजसः परस्मात्॥**

[^611_3]: Etwas anders MS 2, 13, 22. (Somewhat differently MS 2, 13, 22.)

**प्रजां पिपर्तु परिवत्सरो नो धाता दधातु सुमनस्यमानः।  
बव्हीस्साकं बहुधा विश्वरूपा एकत्रता मामभिसंविशन्तु॥ ॥१२॥**  
cf. Mâitr. S. 2, 13, 22; TBr. 2, 4, 2, 5.6.
