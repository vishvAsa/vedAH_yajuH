अथैते परसामानस्तेषां परसाम्नां यत्प्रथमं तदुत्तमं यदुत्तमं तत्प्रथमं यन्मध्ये मध्य एव तत्तद्येनैवैते यन्ति तेनामुतः पुनरायन्त्येषां लोकानाँ सन्तत्यै प्रतिज्ञात्यै ते विश्वजित उपरिष्टात्प्रत्यवरोहिणस्स्तोमानुपयन्ति तदाहुर्जितं वा एते पराजयन्ते निर्वृत्तान्प्रत्यवरोहिणस्स्तोमानुपयन्ति निवर्तन्ते स्वर्गाल्लोकात्प्रत्यञ्चमु यज्ञं तन्वत इति ते तथा पञ्च मासो यन्ति षष्ठस्य च मासस्त्रीनभिप्रवान्द्धे[^501_1] चाहनी गोआयुषी ते पृष्ठान्युपयन्ति पृष्ठानि वै यज्ञस्य दोहो यज्ञं दोहामहै पशुँश्चामृत[^501_2] च प्राञ्चमु यज्ञं तनवामहा इत्यृतवो[^501_3] वै पृष्ठान्यृतुष्वेव तत्प्रतितिष्ठन्तो यन्ति स्वर्गो वै लोकः पृष्ठानि स्वर्ग एव तल्लोके प्रतितिष्ठन्तो यन्ति॥ देवक्षत्रं वा आयुषस्स्तोमा[^501_4] देवक्षत्रमेव तदभ्यारोहन्तो यन्ति ते छन्दोमानुपयन्ति पशवो[^501_5] वै छन्दोमाः पशूनेवावरुन्धते ते दशममहरूपयन्ति प्रजननं प्राजापत्यं प्रतिष्ठां प्रजननमेव तत्प्रजां प्रतिष्ठामवरुन्धते ते महाव्रतीयमहरुपयन्ति तदाहुर्विषुवान्वा एतदहर्यन्महाव्रतीयं विषुवत्युपेत्यमित्यथाहुः प्राजापत्यं वा एतदहर्यन्महाव्रतीयं तदुत्तमार्धे[^501_6] संवत्सरस्योपेत्यमिति यो वै षण्मास्यो जायते यस्सप्तमास्यः प्र वै स मीयते न तेन भोगमश्नुते॥ संवत्सरे खलु वाव रेतो हितं प्रजायते तद्यदुत्तमार्धे संवत्सरस्य महाव्रतीयमहरुपयन्ति संवत्सर एतद्रेतो हितं प्रजनयन्ति यथर्त्वेवर्तून्कल्पयन्ति यथापूर्वं प्रजां प्रजनयन्ति ते पञ्चविँशँ स्तोममुपयन्ति पुरुषस्तोमं दश हस्त्या अङ्गुलयो दश पद्या द्वौ बाहू द्वे सक्थ्या[^501_7] आत्मा पञ्चविँशो यदेतँ[^501_8] स्तोममुपयन्ति स्वादेव तत्स्तोमात्सत्त्रिण आत्मानं प्रजनयन्ति भूत्यै तदाहुः प्राजापत्यं वा एतदहर्यन्महाव्रतीयं तस्मिन्सर्वे यहा ग्रहीतव्यास्सर्वमिव हि प्रजापतिर्विव्याचेत्येको ग्रहीतव्य[^501_9] एको हि प्रजापतिस्त्रयो ग्रहीतव्यास्त्रय इमे लोका एष्वेव लोकेष्वृध्नुवन्ति॥ पञ्च ग्रहीतव्याः पाङ्क्तो[^501_10] यज्ञो यज्ञमेवावरुन्धते सप्त ग्रहीतव्यास्तप्त ग्राम्याः पशवस्तानेवावरुन्धते नव ग्रहीतव्या नव[^501_11] प्राणाः प्राणेष्वेव प्रतितिष्ठन्ति पञ्चदश ग्रहीतव्याः पञ्चदशार्धमासस्य रात्रयो ऽर्धमासशस्संवत्सर आप्यते ऽर्धमासश एव तत्संवत्सरमाप्नुवन्ति सप्तदश ग्रहीतव्याः प्रजापतिस्सप्तदशः प्रजापतिमेवाप्नुवन्त्येकविँशतिर्ग्रहीतव्या असा आदित्य एकविँशो ऽमुमेवादित्यमाप्नुवन्ति सप्तविँशतिर्ग्रहीतव्यास्त्रिणवा[^502_1] इमे लोका एष्वेव लोकेष्वृध्नुवन्ति त्रयस्त्रिँशद्ग्रहीतव्यास्त्रयस्त्रिँशद्देवता देवतास्वेव प्रतितिष्ठन्ति॥८॥

[^501_1]: Ch नभिप्रवां द्वे; cf. Böhtlingk, Sanskrit-Wörterbuch in kürzerer Fassungs.s.v. अभिप्रव (Ch reads नभिप्रवां द्वे; cf. Böhtlingk, Sanskrit-Wörterbuch in kürzerer Fassung, s.v. अभिप्रव)

[^501_2]: So corr. Ch पशूञ्चाº (Thus emended; Ch reads पशूञ्चाº)

[^501_3]: So corr. Ch इत्यॄवो (Thus emended; Ch reads इत्यॄवो)

[^501_4]: So corr. Ch आयुजº (Thus emended; Ch reads आयुजº)

[^501_5]: So corr. Ch पशवे (Thus emended; Ch reads पशवे)

[^501_6]: So corr. Ch तदुत्तेसार्धे (Thus emended; Ch reads तदुत्तेसार्धे)

[^501_7]: So corr. Ch सक्त्या (Thus emended; Ch reads सक्त्या)

[^501_8]: So corr. Ch यदेत (Thus emended; Ch reads यदेत)

[^501_9]: So corr. व्या (Thus emended from व्या)

[^501_10]: So corr. Ch पाङ्क्त्ते (Thus emended; Ch reads पाङ्क्त्ते)

[^501_11]: So corr. Ch व्या र्धप्राणाः (Thus emended; Ch reads व्या र्धप्राणाः)

[^502_1]: So corr. Ch णव (Thus emended; Ch reads णव)

इति श्रीमद्यजुषि काठके चरकशाखायामोरिमिकायां सत्त्राणि नाम त्रयस्त्रिंशं स्थानकं सम्पूर्णम्॥
