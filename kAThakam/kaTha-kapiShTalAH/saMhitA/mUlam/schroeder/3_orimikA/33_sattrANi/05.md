प्रथमे मासि पृष्ठान्युपयन्ति मध्यम उपयन्त्युत्तम उपयन्ति यत्प्रथमे मासि पृष्ठान्युपयन्त्यस्मिँस्तेन लोके प्रतितिष्ठन्ति यन्मध्यम उपयन्त्यन्तरिक्षे तेन प्रतितिष्ठन्ति यदुत्तम उपयन्त्यमुस्मिँस्तेन[^497_5] लोके प्रतितिष्ठन्ति मासि मासि पृष्ठान्युपेत्यानीत्याहुः पृष्ठानि वै यज्ञस्य दोह वै इति तदाहुरेकं वा एतद्देवानामहर्यत्संवत्सरो यां वै त्रिरेकस्याहू उपसीदन्ति[^497_6] दह्रँ सापराभ्यां दोहाभ्यां दुहे तत्कुतस्सा[^497_7] धोक्ष्यति यां द्वादश कृत्व उपसीदेयुरिति सकृत्पृष्ठान्युपेयुरुत्तमे मासि समुद्रं खलु वा एते ऽनवारमपारं प्रस्नान्ति ये संवत्सरमुपयन्ति बृहद्रथन्तराभ्यामेतव्यं बृहद्रथन्तरे वै देवानां प्लवस्तद्देवानां प्लवेन समुद्रमर्णवं तरन्ति यथा मध्ये समुद्रस्य प्लवमन्वर्जेयुरेवं तद्यत्पुरा संवत्सराद्बृहद्रथन्तरे उत्सृजेयुरनुत्सर्गं[^498_1] बृहद्रथन्तराभ्यां गत्वा प्रतिष्ठां गत्वा सकृत्पृष्ठान्युपेयुरुत्तमे मासि सर्वेभ्यो वै कामेभ्यस्सन्धिर्दुहे[^498_2] तत्सर्वान्कामान्यज्ञं पृष्टानि संवत्सराद्द्रुहे[^498_3]॥५॥ cf. TS 7, 5, 3.

[^497_5]: So corr. Ch यदुत्तममुपयन्त्यमुष्मिन्तेन (Thus emended; Ch reads यदुत्तममुपयन्त्यमुष्मिन्तेन)

[^497_6]: So corr. Ch तप (Thus emended; Ch reads तप)

[^497_7]: So corr. Ch तक्त्तुतस्सा; cf. TS 7,5,3,1. (Thus emended; Ch reads तक्त्तुतस्सा; cf. TS 7,5,3,1)

[^498_1]: So corr. Ch उत्सजेº (Thus emended; Ch reads उत्सजेº)

[^498_2]: So corr. Ch सन्धिर्मुहे; TS 7, 5, 3, 2 = Corr. (Thus emended; Ch reads सन्धिर्मुहे; TS 7, 5, 3, 2 agrees with the emendation)

[^498_3]: So corr. Ch रान्मुहे (Thus emended; Ch reads रान्मुहे)
