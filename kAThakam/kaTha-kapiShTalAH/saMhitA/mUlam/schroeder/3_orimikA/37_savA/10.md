बोधश्च[^556_16] मा प्रतीबोधश्च पुरस्ताद्गोपायतामस्वप्नश्च मानवद्राणश्च[^556_17] दक्षिणतो गोपायतां गोपायमानश्च मा रक्षमाणश्च पश्चाद्गोपायतां जागृविश्च मारुन्धती चोत्तराद्गोपायताम्॥

[^556_16]: Dies Capitel beruht wieder bloß auf Ch; für den Anfang vgl. AV 8, 1, 13. (This chapter rests again solely on Ch; for the beginning cf. AV 8, 1, 13.)

[^556_17]: So corr. Ch माणवद्राणश्च (Thus emended; Ch reads माणवद्राणश्च)

**अनमित्रं नो अधरागनमित्रमुदक्कृधि[^557_1]।  
इन्द्रानमित्रं नः[^557_2] पश्चादनमित्रं पुरस्कृधि॥**

[^557_1]: So corr. Ch मुदङ्कृधि (Thus emended; Ch reads मुदङ्कृधि)

[^557_2]: So corr. Ch इन्द्रानमित्रान्नः; cf. AV 6, 40, 3. (Thus emended; Ch reads इन्द्रानमित्रान्नः; cf. AV 6, 40, 3)

अनमित्रैरहोभिस्सचीमहि विश्वे देवा अनमित्रा न उषसस्सन्तु निम्रुचः॥ याष्षडुर्वीः पञ्च प्रदिशस्ता नः[^557_3] पान्तु मित्रधा नो मित्रे दधाता अभयं नो अस्तु॥

[^557_3]: So corr. Ch न पान्तु (Thus emended; Ch reads न पान्तु)

**ये रात्रीमनुतिष्ठथ ये च भूतेषु जागृथ।  
पशून्ये सर्वान्रक्षथ[^557_4] ते न आत्मसु[^557_5] जागृत॥**

[^557_4]: So corr. Ch न्रक्ष्यथ; cf. AV 19, 48, 5. (Thus emended; Ch reads न्रक्ष्यथ; cf. AV 19, 48, 5)

[^557_5]: So corr. Ch आत्मस्व; cf. AV 19, 48, 5. (Thus emended; Ch reads आत्मस्व; cf. AV 19, 48, 5)

बोध प्रतीबोधास्वप्नानवद्राण गोपायमान रक्षमाण[^557_6] जागृवेऽरुन्धति ये देवास्तनूपास्स्थ ते म इह तन्वं पात बोध प्रतीबोधेत्यसौ वा आदित्यो बोधो ऽग्निः प्रतीबोधो[^557_7] ऽस्वप्नानवद्राणेति चन्द्रमा वा अस्वप्नो यः[^557_8] पवते सो ऽनवद्राणो गोपायमान रक्षमाणेत्यहर्वै गोपायमानो रात्री रक्षमाणो जागृवे ऽरुन्धतीति यज्ञो वै जागृविर्दक्षिणारुन्धत्येते[^557_9] वै देवा राष्ट्रभृतस्तानेवेट्ट आत्मनो गोपीथाय॥१०॥

[^557_6]: So corr. Ch रक्षमान (Thus emended; Ch reads रक्षमान)

[^557_7]: So corr. Ch प्रतीबोधस्वप्ना° (Thus emended; Ch reads प्रतीबोधस्वप्ना°)

[^557_8]: So corr. Ch यय्यः (Thus emended; Ch reads यय्यः)

[^557_9]: So corr. Ch जागृविं द° (Thus emended; Ch reads जागृविं द°)
