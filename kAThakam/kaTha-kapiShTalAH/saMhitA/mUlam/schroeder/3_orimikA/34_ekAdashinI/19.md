**अग्निं नरो दीधितिभिररण्योर्हस्तच्युती जनयन्त प्रशस्तम्।  
टूरेदृशं गृहपतिमथर्युम्॥  
अग्निनाग्निस्समिध्यते कविर्गृहपतिर्युवा।  
हव्यवाड् जुव्हास्यः॥**

**सप्त ते अग्ने समिधस्सप्त जिह्वास्सप्तर्षयस्सप्त धाम प्रियाणि।  
सप्त होत्रा अनु विद्वान्सप्त योनीँरापृणस्वा घृतेन॥**

**मनो ज्योतिर्जुषतामाज्यस्यारिष्टं यज्ञँ समिमं तनोतु।  
इमं यज्ञँ सप्ततन्तुं ततं न[^516_4] आ देवा[^516_5] यन्तु सुमनस्यमानाः[^516_6]॥**

[^516_4]: So corr. Ch तन्तुं तन्न (Thus emended; Ch reads तन्तुं तन्न)

[^516_5]: So corr. Ch देव (Thus emended; Ch reads देव)

[^516_6]: So corr. Ch मानः (Thus emended; Ch reads मानः)

**त्रयस्त्रिँशत्तन्तवो यान्वितन्वत इमं यज्ञँ स्वधया ये ददन्ते।  
तेषां छिद्रं प्रतिदध्मो यदत्र स्वाहायं यज्ञो अप्येतु देवान्॥**

**यन्मे मनसश्छिद्रं यद्वाचो यच्च[^516_7] मे हृदः।  
अयं देवो बृहस्पतिस्सं तत्सिञ्चतु राधसा॥**

[^516_7]: So corr. Ch यश्च (Thus emended; Ch reads यश्च)

**विश्वकर्मा हविरिदं जुषाणस्सन्तानैर्यज्ञँ समिमं तनोतु।  
या व्युष्टा उषसो याश्च निम्रचस्तास्सन्दधातु हविषा घृतेन॥**

**अयाश्चाग्रे ऽस्यनभिशस्तिश्च सत्यमित्वमया असि।  
अयास्तन्मनसा[^516_8] कृतो ऽयास्मन्हव्यमूहिषे[^516_9] ऽया नो धेहि भेषजम्॥**

[^516_8]: So corr. Ch अयासा म॰ (Thus emended; Ch reads अयासा म॰)

[^516_9]: So corr. Ch मूहि (Thus emended; Ch reads मूहि)

**त्वं नो अग्ने वरुणस्य विद्वान्देवस्य हेडो ऽवयासिसीष्ठाः।  
यजिष्ठो वह़ितमश्शोश्रुचानो विश्वा द्वेषाँसि प्रमुमुग्ध्यस्मत्[^517_1]॥**

[^517_1]: So T₇ fol. 14<sup>b</sup>; Ch स्मात् (Thus T7 fol. 14b; Ch स्मात्)

**स त्वं नो अग्ने ऽवमो भवोती[^517_2] नेदिष्ठो अस्या उषसो[^517_3] व्युष्टौ।  
अवयक्ष्व नो वरुणं रराणो वीहि मृडीकँ[^517_4] सुहवो न एधि॥१९॥**  
cf. Kap. S. 48, 1 (enthält meist nur die Versanfänge). (cf. Kap. S. 48, 1 (contains mostly only the verse beginnings).)

[^517_2]: So corr. Ch भवती; auch T₇ fol. 14<sup>b</sup> भवती; cf. RV 4, 1, 5. (Thus emended; Ch भवती; also T₇ fol. 14<sup>b</sup> भवती; cf. RV 4, 1, 5.)

[^517_3]: So corr. Ch उषस (Thus emended; Ch reads उषस)

[^517_4]: Ch मुडीको

इति श्रीमद्यजुषि काठके चरकशाखायामोरिमिकायामेकादशिनी नाम चतुस्त्रिंशं स्थानकं सम्पूर्णम्॥[^517_5]

[^517_5]: So die Unterschrift des Capitels in Ch. (Thus the colophon of the chapter in Ch)
