**व्रजं कृणुध्वँ स हि वो नृपाणो वर्म सीव्यध्वं बहुला पृथूनि।  
पुरः कृणुध्वमायसीरधृष्टा मा वस्सुस्रोच्चमसो[^579_8] दृँहता तम्॥**

[^579_8]: So corr. Ch, hier wieder das einzige Ms., liest वासुश्रोश्चमसो; aber vgl. RV 10, 101, 8. (Thus emended; Ch, here again the only ms., reads वासुश्रोश्चमसो; but cf. RV 10, 101, 8.)

**अजीजनन्नमृतं[^579_9] मर्त्यासो ऽस्रेमाणं तरणिं वीडुजम्भम्।  
दश स्वसारो अग्रुवस्समीचीः पुमाँसं जातमभिसंरभन्ताम्[^579_10]॥**

[^579_9]: So corr. Ch अजीजनन्धमृतं; vgl. RV 3, 29, 13. (Thus emended; Ch reads अजीजनन्धमृतं; cf. RV 3, 29, 13)

[^579_10]: So Ch; RV 3, 29, 13 रभन्ते (Thus Ch; RV 3, 29, 13 reads रभन्ते)

**साकँ हि शुचिना शुचिः प्रशास्ता क्रतुनाजनि।  
विद्वाँ अस्य व्रता ध्रुवा वया इवानुरोहति[^580_1]॥**

[^580_1]: So Ch; RV 2, 5, 4 रोहृते (Thus Ch; RV 2, 5, 4 reads रोहृते)

**अ᳓पास्म᳓देतु[^580_2] निर्ऋतिर्ने᳓हा᳓स्या अ᳓पि किं᳓ चन᳓।  
अगो᳓तां नाष्ट्रां᳓[^580_3] पाप्मा᳓नँ स᳓र्वं त᳓द᳓पहन्महे॥**

[^580_2]: Von hier ab wiederum ein Stück in T1 vorhanden; darnach accentuirt. (From here on, a portion is again present in T1; accented after it.)

[^580_3]: So meine Correctur ; Ch अगोत्वान्राष्ट्रं; T1 अगो᳓तान्राष्टां᳓ (Thus my correction; Ch अगोत्वान्राष्ट्रं; T1 अगो᳓तान्राष्टां᳓)

**अ᳓पास्य नैर्ऋता᳓न्पा᳓शान्मृत्यो᳓रे᳓कशतं चये।  
अ᳓पास्य ये᳓[^580_4] सिनाः᳓ पा᳓शा मृत्यो᳓रे᳓कशतँ सुवे[^580_5]॥**

[^580_4]: Accent von mir gesetzt; in T1 ये ohne Accent. (Accent placed by me; in T1 ये without accent.)

[^580_5]: So T1 सिनाः᳓ etc.; in Ch सिनापापाशा मृत्यूनेकशतं सुवे (Thus T1 सिनाः᳓ etc.; in Ch सिनापापाशा मृत्यूनेकशतं सुवे)

**ये᳓ ते पा᳓शा ए᳓कशतं मृ᳓त्यो म᳓र्त्याय ह᳓न्तवे।  
ताँ᳓स्ते[^580_6] यज᳓स्य माय᳓या स᳓र्वान᳓वयजामहे॥**

[^580_6]: So T1; in Ch तँस्ते (Thus T1; in Ch तँस्ते)

**देवी᳓महं᳓ नि᳓र्ऋतिं[^580_7] बा᳓धमानः पि᳓ते᳓व पुत्रं᳓ दमये[^580_8] व᳓चोभिः।  
या᳓ जा᳓यमानस्य जायमानस्य[^580_9] शि᳓रो देवी᳓ प्र᳓ति सूरि᳓र्वि᳓चष्टे॥[^580_10]**

[^580_7]: Ch न्निनृतिं

[^580_8]: So Ch, ohne Accent; T1 पुत्रा᳓न्दम; aber TS 4, 2, 5, 4 पुत्रं᳓ दसये (Thus Ch, without accent; T1 reads पुत्रा᳓न्दम; but TS 4, 2, 5, 4 reads पुत्रं᳓ दसये)

[^580_9]: Accent corrigirt. In T1 auch das 2. जा᳓यमानस्य accentuirt; in Ch ist dasselbe durchstrichen, erscheint also del. (Accent emended. In T1 the second जा᳓यमानस्य is also accented; in Ch the same is crossed out, thus appearing deleted.)

[^580_10]: Hier bricht T1 ab. (Here T1 breaks off.)

**शं नो देवीरभिष्टय आपो भवन्तु पीतये।  
शं योरभिस्रवन्तु नः॥[^580_11]**

[^580_11]: Vgl. AV 1, 6, 1. (Cf. AV 1, 6, 1)

**ऊर्जं बिभ्रद्वसुवनिस्सुमेधा गृहाणां[^580_12] मोदमाना सुवर्चाः।  
अघोरेण चक्षुषाहँ शिवेन गृहाणां[^580_13] पश्यन्वय उत्तिरामि॥**

[^580_12]: So corr. Ch गृहानान्॥ मो° (Thus emended; Ch reads गृहानान्॥ मो°)

[^580_13]: So corr. Ch गृहानां (Thus emended; Ch reads गृहानां)

**गृहाणामायुः[^580_14] प्र वयं तिराम गृहा अस्माकं प्रतिरन्त्वायुः।  
येन देवा ज्योतिषोर्ध्वा उदायन्येनादित्या वसवो येन रुद्राः।**  
**येनाङ्गिरसो महिमानमानशुस्तेनैतु यजमानस्स्वस्ति॥**

[^580_14]: So corr. Ch गृहानामायुः (Thus emended; Ch reads गृहानामायुः)

**स्योना पृथिवि भवानृक्षरा निवेशनी।  
यच्छा नश्शर्म᳓[^580_15] सप्रथाः[^580_16]॥**

[^580_15]: So corr. Ch न शर्म; aber cf. RV 1, 22, 15; MS 4, 12, 2. (Thus emended Ch न शर्म; but cf. RV 1, 22, 15; MS 4, 12, 2.)

[^580_16]: So Ch; RV 1, 22, 15 सप्र᳓थः ; desgl. MS 4, 12, 2. (Thus Ch; RV 1, 22, 15 सप्र᳓थः; likewise MS 4, 12, 2.)

वाक्त्वा समुद्र[^581_1] उपदधातु प्रजावनिं रायस्पोषवनिं मह्यं वाजिनाय मही ध्रुवा सलिलासि ज्योतिष्मती सा स्वर्गं लोकं प्रजानीहि प्रजापतिः प्रजापतौ सादयतु तयाङ्गिरस्वद्ध्रुवा सीद॥१३॥

[^581_1]: So corr. Ch समुद्रा (Thus emended; Ch reads समुद्रा)
