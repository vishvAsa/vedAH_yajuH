**समिद्धो अग्निरश्विना तप्तो घर्मो विराट् सुतः।  
दुहे धेनुस्सरस्वती सामँ शुक्रमिहेन्द्रियम्॥**

**तनूपा भिषजा सुते ऽश्विनोभा सरस्वती[^574_3]।  
मध्वा रजाँसीन्द्रियमिन्द्राय पथिभिर्वहान्[^574_4]॥**

[^574_3]: So corr. Ch स्सर° (Thus emended; Ch reads स्सर°)

[^574_4]: So auch VS 20, 56; dagegen MS 3, 11, 3 वह (Thus also VS 20, 56; on the other hand MS 3, 11, 3 वह)

**इन्द्रायेन्दुँ सरस्वती नराशँसेन नग्नहुम्[^574_5]।  
अधातामश्विना मधु भेषजं भिषजा सुते॥**

[^574_5]: So corr. Ch नग्नहुः; MS 3, 11, 3 und VS 20, 57 = Corr. (Thus emended; Ch reads नग्नहुः; MS 3, 11, 3 and VS 20, 57 agree with the emendation.)

**आजुह्वाना सरस्वतीन्द्रायेन्द्रियाणि वीर्यम्।  
इडाभिरश्विना इषँ समूर्जँ सं रयिं दधुः॥**

**अश्विना नमुचेस्सुतँ सोमँ शुक्रं परिस्रुता।  
सरस्वती तमाभरद्बर्हिषेन्द्राय पातवे॥**

**कवष्यो न व्यचस्वतीरश्विभ्यां न दुरो दिशः।  
इन्द्रो न रोदसी दुघे[^574_6] दुहे कामान्सरस्वती॥**

[^574_6]: Für दुघे haben MS 3, 11, 3 und VS 20, 60 उभे᳓; aber VS 21, 34 auch दु᳓घे (For दुघे, MS 3, 11, 3 and VS 20, 60 have उभे᳓; but VS 21, 34 also has दु᳓घे)

**उषासा नक्तमश्विना दिवेन्द्रँ सायमिन्द्रियैः।  
सञ्जानाने सुपेशसा समञ्जाते सरस्वत्या॥**

**पातं नो अश्विना दिवा पाहि नक्तँ सरस्वति[^574_7]।  
दैव्या होतारा भिषजा पातमिन्द्रँ सचा सुते॥**

[^574_7]: So corr. Ch सरस्वती; cf. MS 3, 11, 3; VS 20, 62. (Thus emended; Ch reads सरस्वती; cf. MS 3, 11, 3; VS 20, 62)

**तिस्रस्त्रेधा सरस्वत्यश्विना भारतीडा[^575_1]।  
तीव्रं परिस्रुता सोममिन्द्रायासुषवुर्मदम्[^575_2]॥**

[^575_1]: So corr. Ch तीड (Thus emended; Ch reads तीड)

[^575_2]: So corr. Ch यासुषवर्म°; VS 20, 63 य सुषुवुर्म᳓° ; MS 3, 11, 3 या᳓सुषुवुर्म᳓° ; aber Padap. richtiger इन्द्राय। सुषुवुः। (Thus emended; Ch यासुषवर्म°; VS 20, 63 य सुषुवुर्म᳓°; MS 3, 11, 3 या᳓सुषुवुर्म᳓°; but Padapāṭha more correctly इन्द्राय। सुषुवुः।)

**अश्विना भेषजं मधु भेषजं नस्सरस्वती।[^575_3]  
गोभिर्न सोममश्विना मासरेण परिस्रुतम्[^575_4]।  
समधाताँ सरस्वत्या स्वाहेन्द्रे सुतं मधु॥ ॥८॥[^575_5]**  
cf. Mâitr. S. 3, 11, 3; VS 20, 55-66; TBr. 2, 6, 12.

[^575_3]: Die zweite Hälfte dieses Verses fehlt in Ch. (The second half of this verse is missing in Ch.)

[^575_4]: So Ch; in MS 3, 11, 3 und VS 20, 66 परिस्रु᳓ता (Thus Ch; in MS 3, 11, 3 and VS 20, 66 परिस्रु᳓ता)

[^575_5]: Die Bezeichnung für den Abschluß von Cap. 8 fehlt in Ch; ich habe denselben gesetzt nach Analogie der Theilung von MS 3, 11, 3 und 3, 11, 4, welch letzteres Capitel ebenfalls mit अ᳓श्विना हवि᳓रिन्द्रियं᳓ beginnt. (The mark for the conclusion of ch. 8 is missing in Ch; I have placed it by analogy with the division of MS 3, 11, 3 and 3, 11, 4, which latter chapter likewise begins with अ᳓श्विना हवि᳓रिन्द्रियं᳓.)
