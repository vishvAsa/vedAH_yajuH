**आ चर्षणिप्रा वृषभो जनानां राजा कृष्टीनां पुरुहुत इन्द्रः।  
स्तुतश्श्रवस्यन्नवसोप मद्रिग्युक्त्वा[^573_7] हरी वृषणा याह्यर्वाक्[^573_8]॥**

[^573_7]: So corr. Ch वसोम मद्रिम्युक्त्वा ; cf. MS 4, 14, 18; RV 1, 177, 1. (Thus emended; Ch reads वसोम मद्रिम्युक्त्वा; cf. MS 4, 14, 18; RV 1, 177, 1)

[^573_8]: So corr. Ch वार्ट् ; MS 4, 12, 3 = Corr.; RV 3, 32, 14 वा᳓र्ङ् (Thus emended Ch वार्ट्; MS 4, 12, 3 agrees with the emendation; RV 3, 32, 14 वा᳓र्ङ्)

**विवेष यन्मा धिषणा जजान स्तवै पुरा पार्यादिन्द्रमहूः[^573_9]।  
अँहसो यत्र पीपरद्यथा नो नावेव यान्तमुभये हवन्ते॥**

[^573_9]: So corr. Ch पायदिं°; cf. MS 4, 12, 3; RV 3, 32, 14. (Thus emended; Ch reads पायदिं°; cf. MS 4, 12, 3; RV 3, 32, 14)

**तँ सध्रीचीरुतयो[^573_10] वृष्ण्यानि पौँस्यानि[^573_11] नियुतस्सश्चुरिन्द्रम्[^573_12]।  
समुद्रं न सिन्धव उक्थशुष्मा[^573_13] उरुव्यचसं गिर आविशन्ति॥**

[^573_10]: So corr. Ch रुतयो; cf. RV 6, 36, 3; MS 4, 14, 18 (die Saṃh. Mss. hier = Káth.!). (Thus emended; Ch reads रुतयो; cf. RV 6, 36, 3; MS 4, 14, 18 (the Saṃh. mss. here agree with Káth.!).)

[^573_11]: So corr. Ch पौस्यानि (Thus emended; Ch reads पौस्यानि)

[^573_12]: So corr. Ch सच्चु° (Thus emended; Ch reads सच्चु°)

[^573_13]: So corr. Ch उक्तशुष्मा (Thus emended; Ch reads उक्तशुष्मा)

**सत्यमित्तन्न त्वावाँ अन्यो अस्तीन्द्र देवो न मर्त्यो ज्यायान्।  
अहन्नहिं परिशयानमर्णो ऽवासृजो अपो अच्छा समुद्रम्॥[^573_14]**

[^573_14]: RV 6, 30, 4; MS 4, 14, 18.

**प्र ससाहिषे पुरुहूत शत्रूञ्ज्येष्ठस्ते शुष्म इह रातिरस्तु।  
इन्द्राभर दक्षिणेना वसूनि पतिस्सिन्धूनामसि रेवतीनाम्॥[^574_1]**

[^574_1]: RV 10, 180, 1; MS 4, 12, 3.

**स शेवृधमधिधा द्युम्नमस्मे महि क्षत्रं जनाघाडिन्द्र तव्यम्।  
रक्षा च नो मघोनः पाहि सूरीन्राये च नस्स्वपत्या इषे धाः॥  
॥७॥** cf. Mâitr. S. 4, 14, 18; 4, 12, 3; TBr. 2, 6, 9.
