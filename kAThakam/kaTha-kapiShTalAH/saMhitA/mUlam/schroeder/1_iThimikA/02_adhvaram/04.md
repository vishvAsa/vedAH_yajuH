व्रतं[^12_5] कृणुत तच्छकेयम्॥ **दैवीं धियं[^13_1] मनामहे सुमृडीकामभिष्टये।  
वर्चोधां विश्वधायसँ सुतीर्था नो असद्वशे॥**

[^12_5]: So corr. Ch वतङ् ; cf. das व्रतं चरत Mâitr. 1, 2, 3 a. A (Thus emended; Ch reads वतङ्; cf. the व्रतं चरत Mâitr. 1, 2, 3 at the beginning)

[^13_1]: So corr. Ch दिवेन्धियम° (Thus emended; Ch reads दिवेन्धियम°)

ये देवा मनुजाता मनुयुजस्सुदक्षा दक्षपितरः। ते नः पान्तु ते नोऽवन्तु तेभ्यस्स्वाहा॥

**अग्ने त्वँ सु जागृहि वयँ सु मन्दिषामहे।  
गोपाय नो अप्रयुच्छन्प्रबुधे नः पुरस्कृधि॥  
त्वमग्रे व्रतपा असि देव आ मर्त्येष्वा।  
त्वं यज्ञेष्वीड्यः॥**

पूषा सनीनाँ सोमो राधसां रास्वेयत्सोमा भूयो भर देवस्सविता वसोर्वसुदावा मा पृणन्पूर्त्या विराधिष्ट माहमायुषा वर्चसा विराधिषि॥ देवीरापो अपां नपाद्य ऊर्मिर्हविष्य[^13_2] इन्द्रियावाँस्तं वो मा क्रमिषँ सक्षेमहि या ते यज्ञिया तनूस्तयारोह॥

[^13_2]: So corr. Ch नपाठ्यर्थमिहविष्ये (Thus emended; Ch reads नपाठ्यर्थमिहविष्ये)

**अयं ते योनिर्ऋत्वियो यतो जातो अरोचथाः।  
तं जानन्नग्न आरोह ततो नो वर्धया रयिम्॥  
एदमगन्म देवयजनं पृथिव्या यत्र देवा अजुषन्त विश्वे।  
ऋक्सामाभ्याँ सन्तरन्तो[^13_3] यजुर्भी रायस्पोषे समिषा मदेम[^13_4]॥॥४॥**

[^13_3]: So corr. Ch भ्यामन्तरन्तो (Thus emended; Ch reads भ्यामन्तरन्तो)

[^13_4]: So corr. Ch सदेम (Thus emended; Ch reads सदेम)

cf. Mâitr. S. 1, 2, 3 ; Kap. S. 1, 16.
