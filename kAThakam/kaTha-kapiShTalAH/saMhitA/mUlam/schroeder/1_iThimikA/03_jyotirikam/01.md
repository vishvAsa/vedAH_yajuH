ज्योतिरसि[^25_7] विश्वरूपं मरुतां पृषती[^25_8] देवेभ्यस्त्वा यज्ञियेभ्यो गृह्णामि॥

[^25_7]: Dies Kap. nur nach Ch. (This chap. is based only on Ch.)

[^25_8]: So corr. Ch पृशतो (Thus emended; Ch reads पृशतो)

**त्वँ सोम तनूकृद्भो द्वेषेभ्यो[^25_9] ऽन्यकृतेभ्यः।  
उरु यन्तासि वरूथम्॥**

[^25_9]: So Ch. (Thus Ch.)

स्वाहा जुषाणो अप्नुराज्यस्य वेतु स्वाहा॥ **अग्ने नय सुपथा[^26_1] राये अस्मान्विश्वानि देव वयुनानि विद्वान्।  
युयोध्यस्मज्जु[^26_2]हुराणमेनो भूयिष्ठां ते नमउक्तिं विधेम॥  
उरु विष्णो विक्रमस्वोरु क्षयाय नस्कृधि।  
घृतं घृतयोने पिब प्र प्र यज्ञपतिं तिर॥**

[^26_1]: So corr. Ch स्वपथा (Thus emended; Ch reads स्वपथा)

[^26_2]: So corr. Ch स्माज्जु° (Thus emended; Ch reads स्माज्जु°)

स्वाहोर्वन्तरिक्षं वीह्यदित्यास्त्वगस्यदित्यास्सदने सीद॥ ॥ देव सवितरेष ते सोमस्तं रक्षस्व मा त्वा दभन्नेतत्त्वं देव सोम देवानुपागा इदमहं मनुष्यान्सह प्रजया सह रायस्पोषेण नमो देवेभ्यस्स्वधा पितृभ्यो निर्द्रुहो निर्वरुणस्य पाशान्मुक्षीय स्वरभिव्यख्यं ज्योतिर्वैश्वानरमग्ने व्रतपा अस्मे व्रतपास्त्वे[^26_3] व्रतपा व्रतिनां व्रतानि याग्ने मम तनूस्त्वय्यभूदियँ सा मयि या तव तनूर्मय्यभूदेषा सा त्वयि यथायथं नो व्रतपा व्रतिनां व्रतानि स्वाहा यज्ञं मनसि[^26_4] स्वाहा दिवि स्वाहा पृथिव्याँ स्वाहोरा अन्तरिक्षे[^26_5] स्वाहा वाते वाचि विसृजे[^26_6]॥१॥ cf. Mâitr. S. 1, 2, 13; Kap. S. 2, 8.

[^26_3]: So corr. Ch व्रतपासस्मे व्रतपास्थे ; aber cf. oben 2, 8. (Thus emended; Ch व्रतपासस्मे व्रतपास्थे; but cf. above 2, 8.)

[^26_4]: So corr. Ch यज्ञस्सनसि ; aber cf Kap. S. 2, 8 यज्ञं मनसि (Thus emended; Ch यज्ञस्सनसि; but cf Kap. S. 2, 8 यज्ञं मनसि)

[^26_5]: So corr. Ch °रिक्षं (Thus emended; Ch reads रिक्षं)

[^26_6]: Kap. S. 2, 8 विसृजेत्
