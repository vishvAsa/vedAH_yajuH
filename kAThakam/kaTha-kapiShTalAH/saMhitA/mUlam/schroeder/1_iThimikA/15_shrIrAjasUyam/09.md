सावित्रो ऽष्टाकपालश्श्येतो दक्षिणा सारस्वतश्चरुः पष्ठौह्यग्रवीता दक्षिणा पौष्णश्चरुश्श्यामो दक्षिणा बार्हस्पत्यश्चरुश्शितिपृष्ठो दक्षिणैन्द्र एकादशकपाल ऋषभो दक्षिणा वारुणो यवमयो दशकपालो बभ्रुर्महानिरष्टो[^214_3] दक्षिणा त्वाष्ट्रो ऽष्टाकपालश्शुण्ठो दक्षिणाग्नेयो ऽष्टाकपालस्सौम्यश्चरूर्वैष्णवस्त्रिकपाल आग्नेयो ऽष्टाकपालो हिरण्यं दक्षिणैन्द्र एकादशकपाल ऋषभो दक्षिणा॥ वैश्वदेवश्चरुर्धेनुः पिशङ्गी दक्षिणा मैत्रावरुण्यामिक्षा वशा दक्षिणा बार्हस्पत्यश्चरुश्शितिपृष्ठो दक्षिणाग्नेयो ऽष्टाकपालस्सौम्यश्चरुस्सावित्रो ऽष्टाकपालो बार्हस्पत्यश्चरुरग्नये वैश्वानराय द्वादशकपालस्त्वाष्ट्रो ऽष्टाकपालो[^214_4] दक्षिणो रथवाहनवाहो दक्षिणा सारस्वतश्चरुः पौष्णश्चरुर्मैत्रश्चरुर्वारुणश्चरुरदित्यै[^214_5] चरुः क्षेत्रस्य पतये चरुरितरो रथवाहनवाहो दक्षिणा सवित्रे द्वादशकपालो ऽश्विभ्यां पूष्ण एकादशकपालस्सरस्वत्यै सत्यवाचे चरुस्विसृधन्वँ शुष्कदृतिर्दण्ड उपानहौ तद्दक्षिणाश्वो वा शोणकर्णः[^214_6]॥९॥ cf. Mâitr. S. 2, 6, 13.

[^214_3]: So corr. Ch बभ्रुमेहा°; D बदुर्महा° (Thus emended; Ch reads बभ्रुमेहा°; D reads बदुर्महा°)

[^214_4]: So corr. Ch त्वाष्ट्राष्टाक°; D त्वाष्ट्रो क° (Thus emended; Ch reads त्वाष्ट्राष्टाक°; D reads त्वाष्ट्रो क°)

[^214_5]: So D = Mâitr. S. 2, 6, 13; Ch रादित्यो (Thus D = Mâitr. S. 2, 6, 13; Ch रादित्यो)

[^214_6]: D शैणकर्णः
