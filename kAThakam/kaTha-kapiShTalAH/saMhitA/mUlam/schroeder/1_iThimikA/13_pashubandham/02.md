वारुणं कृष्णं त्वमेकशितिपादमालभेतामयावी ज्योगामयावी प्रजापतिः प्रजा असृजत ता एनमत्यचरँस्ता अतिचरन्तीर्वरुणेनायाहयत्ता जिह्नाः पन्ना अशेरत वरुणगृहीतास्ताः कृष्णः पेत्व आप्रवत तस्याभिहाय[^179_12] पादमगृह्णात्स[^179_13] प्रावृह्यत स एकशितिपादभवत्त्राः प्रजापता अनाथन्त सो ऽपश्यद्यो ऽयमवरुणगृहीतस्तेनैना वरुणान्मुञ्जानीति तं वारुणमालभत तेनैना वरुणादमुञ्चद्वरुणगृहीत[^179_14] एष य आमयावी यद्वारुणो[^179_15] वरुणादेवैनं मुञ्चति॥ द्वीपे[^179_16] यजेतापो वै वरुणस्समक्षमेवैनं[^179_17] वरुणान्मुञ्चति प्रजापतिः पशून्सृष्ट्वा वरुणं वरमभ्यसृजत्स एतमवृणीत तस्माद्वरुणदेवत्यः[^180_1] पाप्मनैष गृहीतो य आमयावी कृष्ण इव पाप्मा यत्कृष्णः पाप्मानमेवापहते यदेकशितिपाद्वरुणपाशमेव तेन प्रमुञ्चत आग्नेयमजमालभेत वारुणं कृष्णं पेत्वं बुभूषन्नृड्व्या एवाग्नेयो वरुणगृहीत एष यो ऽलं भूत्यै सन्न भवति यद्वारुणो वरुणादेवैनं मुञ्चत्यर्धं वै पुरुषस्याग्नेयमर्धं वारुणमस्थान्याग्नेयानि माँसान[^180_2] वारुणानि तयोरेवैनं भागधेयेन निष्क्रीणाति॥ सो ऽनृणो भूत्वा भवत्येव वारुणं कृष्णं वृष्णिमभिचरन्नालभेत[^180_3] मृत्युर्वै वरुणी मृत्युनैवैनं ग्राहयत्येतद्वै पाप्मनो रूपं कृष्ण इव पाप्मा यत्कृष्णः पाप्मनैवैनमभिषुवति॥

[^179_13]: So Ch; D पदम° (Thus Ch; D reads पदम°)

[^179_14]: D वारुणाद°

[^179_15]: So Ch; D यद्वरुणो (Thus Ch; D reads यद्वरुणो)

[^179_16]: D द्वोमे

[^179_17]: D सपक्ष

[^180_1]: So Ch; D देवत्याः (Thus Ch; D reads देवत्याः)

[^180_2]: So D; Ch सोमानि (Thus D; Ch reads सोमानि)

[^180_3]: Ch वृष्णोम°

**पशुं बध्नामि वरुणाय राज्ञ इन्द्राय[^180_4] भागमृषभं केवलो हि।  
गात्राणि देवा अभिसंविशन्तु यमो गृह्णातु[^180_5] निर्ऋृतिस्सपत्नान्॥**

[^180_4]: D इन्माय

[^180_5]: D गृह्णात

इत्येता वै देवताः पुरुषस्येशते[^180_6] ताभ्य एवैनमधिनिष्क्रीय मृत्युर्यमो मृत्युनैवैनं ग्राहयति॥२॥ cf Mâitr. S. 2, 5, 6.
