**देव सवितः प्रसुव[^194_6] यज्ञं प्रसुव[^194_6] यज्ञपतिं भगाय।  
दिव्यो गन्धर्वः केतपूः केतं[^194_7] पुनातु वाचस्पतिर्वाचमद्य स्वदाति नः॥**

[^194_6]: D प्रसुवा

[^194_7]: D केतं प्रकेतं

**वाजस्य न प्रसवे मातरं महीमदितिं नाम वचसा करामहे।  
यस्यामिदं विश्वं भुवनमाविवेश तस्यां नो[^194_8] देवस्सविता धर्मँ साविषत्॥**

[^194_8]: Ch तस्यान्नां

**अप्स्वन्तरमृतमप्सु भेषजमपामुत प्रशस्तिषु।  
अश्वा भवथ वाजिनः॥**

<details><summary>टिप्पणी (अनङ्किता 9)</summary>

- **9.** So Ch; D भवति ; cf. RV 1, 23, 19 भवत (Thus Ch; D भवति; cf. RV 1, 23, 19 भवत)

</details>

**वायुर्वा त्वा मनुर्वा त्वा गन्धर्वास्सप्तविँशतिः।  
ते अग्रे[^195_1] अश्वसयुञ्जँस्ते अस्मिञ्जवमादधुः॥**

[^195_1]: D अग्ने

**अपां नपादाशुहेमन्य ऊर्मिः प्रतूर्तिः ककुद्मान्[^195_2]।  
वाजसास्तेन[^195_3] वाजँ सेषम्॥**

[^195_2]: D ककुद्माम्

[^195_3]: Ch सस्तेन

देवस्य सवितुः प्रसवे सत्यसवस्य वर्षिष्ठं नाकं रुहेयं देवस्य वयँ सवितुः प्रसवे सत्यसवनस्य बृहस्पतेर्वाजिनो वाजजितो[^195_4] वाजं जेष्म॥ वाजं वाजिनो जयताध्वनस्स्कभ्नुवन्तो योजना मिमानाः काष्ठां[^195_5] गच्छत॥

[^195_4]: Ch वाजञ्जितो

[^195_5]: So corr. Ch कष्टां; D काष्टं (Thus emended; Ch reads कष्टां; D reads काष्टं)

**शं नो भवन्तु वाजिनो हवेषु देवताता मितद्रवस्स्वर्काः।  
जम्भयन्तो ऽहिं वृकं रक्षाँसि[^195_6] सनेम्यस्मद्युयवन्नमीवाः॥**

[^195_6]: Ch हि वृकाँसि

**वाजे वाजे ऽवत वाजिनो नो धनेषु विप्रा अमृता ऋॄतज्ञाः।  
अस्य मध्वः पिबत मादयध्वं तृप्ता यात पथिभिर्देवयानैः॥**

**ते नो अर्वन्तो हवनश्रुतो हवं विश्वे शृण्वन्तु वाजिनो मितद्रवः।  
सहस्रसा मेधसाता सनिष्यवो महो ये धना समिथेषु जभ्रिरे॥**

**एष स्य वाजी क्षिपणिं तुरण्यति ग्रीवासु बद्धो अपिकक्ष आसनि।  
क्रतुं[^195_7] दधिक्रा अनुसँसनिष्यदत्पथामङ्काँस्यन्वापनीफणत्[^195_8]॥**

[^195_7]: Ch क्रतुर्द°; cf. TS 1, 7, 8, 3.

[^195_8]: Ch पणीफणत्

**उत स्मास्य द्रवतस्तुरण्यतः[^195_9] पर्णं न वेरनुवाति प्रगर्धिनः[^195_10]।  
श्येनस्येव द्रवतो अङ्कसं परि[^195_11] दधिक्राव्णस्सहोर्जा तरित्रतः॥॥१४॥**

[^195_9]: So corr. Ch द्रवतस्भुर°; D द्रवभस्तुर° (Thus emended; Ch reads द्रवतस्भुर°; D reads द्रवभस्तुर°)

[^195_10]: So corr. Ch प्रगधिनः; D प्रगविनः; (Thus emended Ch प्रगधिनः; D प्रगविनः;)

[^195_11]: Mss. अङ्कसस्परि (Mss. read अङ्कसस्परि)

cf. Mâitr. S. 1, 11, 1. 2.
